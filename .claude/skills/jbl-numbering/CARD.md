# 취향 카드 — 작성자·검수자·채점자가 문제 묶음마다 **맨 먼저** 읽는 한 쪽(다른 문서와 다르면 이것이 이김)

근거: 사용자 원자료(교정·임구내 DOCX·1Q PDF) 단서 기제 ≈ 소리·말장난 60% · 답의 말 그대로 39% · **다른 소재 대응물 1% 미만**(10-11 재분석).

## 금 사례(원문 — 이 급만 통과)
1. [사용자가 고친 판] `[D1급 슈퍼카 샀는데] / 차가 바닥에 착 붙고(접촉면적), / 안정감(일차 안정성) 최고야! / 차체도 짧아(짧은 길이) / 근데 피가 안 통해서(혈액공급 감소) / 엔진이 과열되고(과도한 열), / 구멍 뚫림(Drill hole)` — 무대 = 문제어 'D1'을 등급으로 비튼 것. 단서 6개 전부 **답의 말 그대로**(차에는 피가 없다 — 그 엉뚱함이 고리). 차 말(바닥·차체·엔진)은 배경일 뿐.
2. [승인] 크루즈(Crouzon) 타고 피자(Pfeiffer) 먹다가 앞에(Apert) 새 차(Saethre-Chotzen)가 나타났어! 차 안에 카펫(Carpenter)이 깔려 있길래 문(Muenke)을 열었더니 트레저(Treacher Collins)가 가득! — 7/7 소리.
3. [승인] 햇볕(UV)에 탄 채 생일(Chronologic aging) 케이크 초에 담배(Smoking)로 불을 붙였어. 거울에 비친 엄마와 똑같은 주름(Genetics)을 보고는 케이크 대신 샐러드(Diet)를 집어 들었지. — 답의 뜻 그대로 + 비틀린 행동.
4. [사용자가 고친 판] `[캐릭터 만들기] 3D 스캔(CBCT data) / 첫인상(impression) 보고 모델 캐스팅(dental cast model) / 옆모습 엑스레이 / 셀카 / 포즈 취하게 함(positioning) / 와 게임 가이드 같네(wa, guide) [플레이] 시뮬레이션 했는데 / 와.. 가이드가 / 플랜 다 짜줘서 / 내비게이션 보고 / 마킹할 수 있었어` — 답의 외래어 그대로 + 동음이의(첫인상·캐스팅) + 소리(와 = wafer). 사용자가 **대응 소품(커플 팔찌 = plates·웨하스 선물·엔딩 보상)을 지움**.
5. [사용자 자료 · 당뇨 구강 합병증] 당 떨어진 상태에서 합병증) / 엑셀(accel) 밟고 / Dry 드라이브 하다가 / Ab 본 사이에 / Car 쾅 / 상처 힐링도 안되고 감염 심각한데 / Ul can 어떤 얼간이야 / Numb 번호 따감 — 소리 사슬 + 엉뚱한 사고 사건 + 감정.
6. [사용자 자료 · 결핵 증상] 사인받으려면.. / la ma 라인 맞춰서 / 안쪽에서 / weight(wait!) 기다려 / night 밤까지.. 그래도 / F 줘서 / per cou 빡꾸받고 / dys 디스당한다..? — 문제어 비틀기(signs → 사인회) + 소리·동음이의.

## 거절 사례(원문 + 이유 — 이 기제가 하나라도 보이면 전제부터 버림)
1. `[자연치 = 서스펜션 SUV, 임플란트 = 서스펜션 없는 카트] SUV는 쿠션(치주인대)이 충격을 먹어 주고(응력 흡수) / 카트는 옆에서 밀면 위쪽(치조골 상방)을 축으로 휘청(회전 중심) / … 차체 깨지고(상부 구조물의 파절) 나사 풀리고 바닥까지 꺼져(치조골의 흡수)` — 단서가 차 부품 **대응물**(쿠션·차체·바닥) · 이야기가 생역학을 **다시 설명** · 제목이 대응표 · 소리 0.
2. `[날림 공사 브릿지가 무너진 이유] 기둥은 몇 개 없고(number) 짧고(length) 가늘고(diameter) / 강 아무 데나(Location) 박았어 / … 맞은편 강둑(opposing arch)마저 무너져 있었어` — bridge를 진짜 다리로 되돌림 → 대응물(기둥·강·강둑) + 번역 형용사 나열.
3. `[철사 클립 구부렸다 폈다, 결국 똑] 바이오 클립(biomaterial)이 구불구불한 모양(marcrogeometry)인데 / 힘줘서 세게(force magnitude) 꺾고 / 사이클 돌리듯 계속(number of cycles) 꺾었더니 결국 똑` — 같은 원리(금속 피로)를 다른 재료로 **재연** · '구불구불한 모양'으로 macrogeometry 안 떠오름.
4. `[시린 이 = 게임 몬스터 공략] 패시브 스킬(Passive)은 너프 패치 / 플레이타임 다운(Reduce time), 판수 다운(Reduce frequency), 데미지 다운(Reduce concentration)` — 같은 뜻을 게임 말로 갈아 끼운 **의상 번역**(외울 때 한 번 더 풀어야 함) · '다운'×3 구별 안 됨.
5. `[인레이 vs 때우기 고민] 재료 성질(Physical properties) / 남은 치아 양 / 예쁨 / 의사·환자 취향 / 돈` — 장면·이음말·소리 없는 뜻 명사 **덩어리**.

## 절대 규칙(작성·검수·채점 모두 이 일곱 개로 판단)
1. **단서 말 = 답의 말 그대로(원어·답의 우리말·사전 뜻) 또는 그 소리.** 괄호를 가리고 단서에서 답의 말까지 **한 걸음**(같은 말·같은 소리)이어야 함. **두 걸음**(무대의 대응물 → 뜻 → 원어: 쿠션 = 치주인대, 기둥 = 임플란트, 판수 = frequency)이면 그 단서는 실패.
2. **무대는 문제어를 다른 뜻으로 비틀어 고른다**(D1급 슈퍼카 · 카스 점집 · 부전승 · 사인회 · 압도당함 · 개방적 기자회견). **기전이 닮은 세계**(서스펜션·건축·금속 피로·게임 밸런스·잔디 이식)나 **문제어의 비유 원뜻**(bridge → 진짜 다리)은 금지 — 그 세계가 대응물을 불러온다. 무대 말은 배경일 뿐 단서 자리에 오지 않는다.
3. **답의 말은 무대에 '어색하게라도' 그대로 얹는다**(피가 안 통하는 차 · Ex = 전 애인 · 조직 = 회사 · class = 반 친구). 무대 사람이 실제로 쓸 말로 고치면 그것이 대입.
4. **이야기는 답의 원리를 다시 설명하지 않는다.** 엉뚱한 일상 사건(사고·이별·꾸중·소개팅·사인회·먹방)이 일어나야 한다. 답을 다른 무대로 옮겨 다시 말하면 여전히 답 요약.
5. **대응표를 만들지 않는다.** 제목에 '답 항목 = 물건'(자연치 = SUV) 금지 — '='는 '문제 = 장면'(교정기 떼는 날 = 졸업날)에만. 항목마다 대응 상황을 하나씩 늘어놓지 않는다. 답을 대신하는 **무대 소품**(외워야 할 물건)도 금지.
6. **덩어리를 만들지 않는다.** 말하는 사람·이음말·감정(아크!!·하 쒸·킹받네)이 있는 한 사건. **소리 단서가 뼈대**(머리글자는 아는 낱말·이름으로, 숫자는 정확히, 동음이의가 가장 좋음).
7. **검사·보류.** 두 걸음 단서가 하나면 그 단서만 바꾸고, 절반이거나 1·2·4·5를 어기면 **소재와 사건을 통째로 버리고** 새로. 3번 안에 안 되면 억지로 대입하지 말고 **미완성(보류)** + 원인 기록 — 기준을 낮춰 통과시키지 않는다.

# 사례 — 사용자 승인 / 거절 / 참고 자료 분석

**사용자가 직접 승인한 것만 '성공'.** 모델이 통과시킨 것, DOCX·PDF에 들어 있다는 것만으로는 승인이 아니다.

## A. 사용자 승인 성공 사례(기준 — 이 수준 이상만 통과)

### A1. CDS(두개골 조기 유합 증후군 7개) — 소리 단서의 인과 사슬
> 크루즈(Crouzon) 타고 피자(Pfeiffer) 먹다가 앞에(Apert) 새 차(Saethre-Chotzen)가 나타났어! 차 안에 카펫(Carpenter)이 깔려 있길래 문(Muenke)을 열었더니 트레저(Treacher Collins)가 가득!

- 7개 단서가 모두 **평범한 말**(크루즈·피자·앞에·새 차·카펫·문·트레저)이고 첫 음절 소리가 원어와 맞음.
- 사건이 **공간을 따라 이어짐**: 크루즈에서 → 앞에 차가 나타나고 → 차 안 → 문 → 안에 든 보물. 괄호를 빼도 한 장면.
- 짧음(2문장). 외울 새 이름 없음. 탈것을 따라 하라는 게 아니라 **인과·공간 사슬**을 본받을 것.

### A2. D1 골 분류 — 소품 하나 + 장점→단점 결과
> D1급 슈퍼카 샀는데 차가 바닥에 착 붙고, 안정감 최고야! 차체도 짧아서 주차하기 편해. 근데 피가 안 통해서 엔진이 과열되고, 구멍 뚫어서 수리하려니까 너무 단단해서 안 뚫려!

- 문제어(D1)가 첫 단서 → G8 고리.
- 한 물건(슈퍼카)이 장점(착 붙음·안정감·짧아 주차 편함) 다음 단점(피가 안 통해 과열·단단해서 안 뚫림)을 **물리적 결과로** 겪음. 의미 비유도 한 물건 안에서 일관하면 강함.
- 사용자가 준 원문 그대로 옮김(괄호 없음) — 앞으로 만드는 완성본은 단서 뒤에 원문 최단 핵심어 괄호를 단다.

### A3. 노화 요인(UV) — 한 가족 생일 장면 + 비틀기
> 햇볕(UV)에 탄 채 생일(Chronologic aging) 케이크 초에 담배(Smoking)로 불을 붙였어. 거울에 비친 엄마와 똑같은 주름(Genetics)을 보고는 케이크 대신 샐러드(Diet)를 집어 들었지.

- 77문제 배치에서 사용자가 **유일하게** 받아들인 것. 나머지 49개는 거절(길고 의학적).
- 햇볕에 탄 생일 → 담배로 초 → 거울 속 엄마 주름 → 케이크 대신 샐러드: 짧고 낯선 행동 하나하나가 단서.
- 의미 단서(햇볕·생일·담배·엄마·샐러드)도 **한 장면 안에서 일어나는 행동**이면 통과 — 단, 정답 번역 나열과는 다름(행동이 비틀려 있고 서로 이어짐).

### A0. 사용자가 직접 고친 판(10-11 · 가장 높은 기준 — 이 꼴·밀도를 그대로 따라 함)
```
[D1급 슈퍼카 샀는데]
차가 바닥에 착 붙고(접촉면적),
안정감(일차 안정성) 최고야!
차체도 짧아(짧은 길이)
근데 피가 안 통해서(혈액공급 감소)
엔진이 과열되고(과도한 열),
구멍 뚫림(Drill hole)
```
```
[캐릭터 만들기]
3D 스캔(CBCT data)
첫인상(impression) 보고 모델 캐스팅(dental cast model)
옆모습 엑스레이(cephlometric x-ray)
셀카(facial photos)
포즈 취하게 함(positioning)
와 게임 가이드 같네(wa, guide)

[플레이]
시뮬레이션 했는데(simulation)
와.. 가이드가(wa guide)
플랜 다 짜줘서 (presurgical / virtual surgical)
내비게이션 보고(navigation)
마킹할 수 있었어(markings)
```
- 내가 만든 판(A4 '가상 연애 게임' 13항목·235자)을 사용자가 이렇게 줄임: 데이트·커플 팔찌·엔딩 보상 같은 **꾸밈 소품을 통째로 버리고** 장면 제목 [캐릭터 만들기]/[플레이] 둘 + 한 줄 2~6낱말.
- **괄호도 더 짧게**: 원문의 가장 짧은 조각이면 낱말 일부도 됨(wa = wafer, markings = screw hole markings) · 비슷한 두 항목은 한 줄 한 괄호에 `/`·`,`로(presurgical / virtual surgical · wa, guide).
- 같은 소리를 두 번 써도 됨('와' = wafer — 감탄사 소리 말장난이 그대로 단서).
- 꼴: 첫 줄 `[장면]` → 짧은 줄 → 장면이 바뀌면 빈 줄 + 새 `[장면]`.

## C. 참고 자료 교차 분석(장치 출처 — 일괄 승인 아님)
자료: 교정 JB 넘버링(26 update) · 임상구강내과 넘버링(26 update) · 임구내 내과 1Q 넘버링(PDF). 사용자가 쓰거나 모은 넘버링이지만 **줄마다 승인한 것은 아님**.

### C1. 빌려 쓸 장치(좋은 예)
- **문제 고리 제목**(교정 전반): 압하 → '압도당함)', space closure → '썸녀와 거리 좁히기)', debonding → '교정기 떼는 날 = 졸업날)', 개방교합 → '개방적 기자회견)', torque → '브라이덜 샤워 이후 토크)', retention → '헤어지고 나서 유지가 필요한 이유)'. 문제어를 비틀어 장면을 정하니 문제 → 이야기가 바로 떠오름(G8). 제목 줄은 선택 — 첫 문장에 녹여도 됨.
- **소리 + 행동 사슬**(임구내 EBV): EDM 페스티벌 → 머리(hair) 가리려고 버킷(Burkitt)모자 → '너 뭐니(mononucleosis)?' 소리 들음. 3개 단서가 이어지는 행동이고 끝이 대사 펀치라인 — A1과 같은 계열.
- **숫자 읽기**(임구내 당뇨 기준): '굶었는데도(FBS) 이리(12) 육중(6)하다니 · PT 200번 · 66사이즈를 55사이즈(6.5)로'. 숫자를 정확히 맞추면서 일상 말.
- **의미 공명 소리**(1Q 혈액응고): VIP 매일(Vascular·Platelet) → 코피나(Coagulation·Fibrinolytic) — 소리이면서 '출혈' 주제와 맞음. 펫올림픽(Petechiae·Lymphadenopathy).
- **감정 터지는 대사**(교정 torque): 'CP 씨파 진짜 빡치네 / 알바 왜 자꾸 센터로 서지?' — 속어·짜증이 장면을 살림(단, 대사가 항목 목록이 되면 안 됨).
- **숫자를 장면 속 사실로**(교정 debonding 목표): '6년 간의 class 친구들'(six keys Class I) · '0.5mm도 보정하지 않았어요'(기자회견 부인 화법이 실제 수치 단서).
- **장점/단점·두 집단 대비를 한 쌍의 인물로**(임구내 갑상선 기능 항진/저하): '넌 hype 되었는데 나는 sl pu 슬퍼 / 넌 몸무게 줄고… 난 살찌고 변비야' — 대비 구조는 좋음(단 이 줄은 정답 번역이 많아 G3 경계).

### C2. 따라 하지 말 꼴(자료 안의 약한 예 — 승인 기준 미달)
- **머리글자·음절 줄**: '오 / 아빠 / 맨이다 / 머쓸'(학파 4개), 'US SC DR ConJun', 'FABSIOKCPSFR… 쉬팔', 'GCS랑 go ch syphi / PG 피지 / Tri Cho', '면역 억제 CAP쳐~' → 줄 자체를 외워야 함(G6) · 사건 없음(G1).
- **번호별 말장난 목록**(1Q PDF 대부분): '1)pet 2)lym: 펫림픽 / 3)gin large: 진짜 커 / 4)gingi: 진지하게…' → 제목 아래 항목마다 따로 노는 말장난 = 목록(G1). 좋은 말장난은 C1처럼 사건으로 이어 붙여 살림.
- **정답 번역 나열**(임구내 우울증·조현병·폭식증, 교정 retention): '체중(weight) 빼는데 / 초조(psychomotor agitation)하고 / 피곤(fatigue)하게…', '과장(exaggeration)이 아니고…', 'peri 빨리 시간을 줘 / unstable한데 pressure 지속적으로…' → 장면 이름만 붙인 답안 풀어쓰기(G3) — CAS 장점 실패와 같은 기제.
- **긴 대본·두 판본**(임구내 간질 치과 주의사항 15줄+'short ver'): 이야기 자체가 두 번째 교과서(G7·G6).
- **뜻 없는 소리**(교정 '근육 역전', 임구내 'Pro 들이 cytokine 싸커킥'): 장면이 그려지지 않거나 단서가 원어 그대로라 떠올리는 힘이 없음.
- **원어를 그대로 괄호 없이 늘어놓기**: 'Row 줄 맞추자! Ma bu 마법처럼 Over하던 Occ 애들이…'(ABO 8개) — 장면은 있으나 'Over·Occ'처럼 원어 일부를 그대로 둔 곳은 단서가 아니라 답 조각.

### C3. 정리 — 사용자 취향의 핵심
짧다 · 평범한 말이 소리로 정답을 부른다 · 장면이 실제로 '일어난다'(이어지는 행동·물리적 결과·반전) · 학생의 일상과 감정 · 숫자는 정확한 말장난 · 문제와 장면 사이 고리 · 외울 이름·암호 없음.

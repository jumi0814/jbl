# JSON 형식 — JBL '내 넘버링'과 주고받기(기존 기능 그대로 씀)

## 들어오는 것: JBL 내보내기(사이드바 'ChatGPT로 내보내기')
```json
{"format":"jbl-numbering","v":1,"sid":"CONS","subject":"임상치과보존학","batch":"mfx2k1","part":"1/1","n":12,
 "rules":[…ChatGPT용 안내 — 이 스킬은 쓰지 않음(PRINCIPLES.md가 이김)…],
 "lecs":[{"lec":"강의 이름","items":[{"id":"jb:CONS:Q01","q":"문제 맨글","a":"정답 맨글","story":"","s0":"0"}]}]}
```
- `id` 문제 고유 키(JBL 저장 키) · `q`·`a` 원문 맨글(번호·표 칸 ' | '·[그림]) · `story` 기존 스토리(내보낼 때 '이미 쓴 스토리도 넣기'를 켠 경우만) · `s0` 내보낼 때 JBL 스토리의 지문(FNV — 스토리가 없으면 `"0"`).
- **스토리가 있는 문제 = `story`가 있거나 `s0 ≠ "0"`**(스토리를 빼고 내보내도 지문으로 앎) → 세션에서 `keep`(보호).
- 기본 내보내기 설정은 '미작성(스토리 없음)만' → 보통 전부 `todo`.

## 나가는 것: JBL '결과 가져오기'에 넣는 JSON(`nb.py export`)
```json
{"format":"jbl-numbering","v":1,"sid":"CONS","subject":"…","batch":"mfx2k1","part":"1/1","n":2,
 "made_by":"claude:jbl-numbering","session":"…","note":"검수 통과 스토리만 · …",
 "lecs":[{"lec":"강의 이름","items":[{"id":"jb:CONS:Q01","q":"(원본 q 그대로)","story":"스토리 맨글","s0":"0"}]}]}
```
- 들어가는 문제 = **자체 검수 통과 + 독립 블라인드 검수 통과만**(`--no-blind`로 낸 것은 note에 표시). 보류는 `out/hold.md`에만.
- `id`·`q`·`s0`는 원본에서 **한 글자도 바꾸지 않고** 복사(도구가 함 · `verify`가 다시 확인). `a`·출처·연도 칸은 넣지 않음 — JBL 가져오기는 **스토리만** 바꾸고 문제·답안·출처·연도·태그는 그대로 둔다.
- `story`: 맨글 · 줄바꿈(`\n`) = 문단 · JBL이 `**굵게**`·`==형광펜==`을 서식으로 바꿔 주지만 이야기에는 보통 쓰지 않음(PRINCIPLES 6).

## JBL이 가져올 때(num.js aiParse·aiPlan·applyStories — 바꾸지 않음)
- 파일(.json·.txt) 또는 **채팅 답 글 전체 붙여 넣기**(코드 블록 ```json … ``` 째도 됨) → '미리 보기' 먼저(바로 바뀌지 않음).
- 분류: **새 스토리**(JBL에 스토리 없음 · 미리 골라 둠) / 바꿈(지문이 같은 기존 스토리 — 고르지 않음) / **충돌**(내보낸 뒤 JBL에서 스토리를 고침·지움 — 고르지 않음) / 변경 없음 / 비어 있음 / 맞는 문제 없음 / 같은 id 여러 번 / 목록에서 뺀 문제 / 문제 글 다름(id 엉킴 의심) / 형식 오류.
- 적용은 한 번에(트랜잭션 — 하나라도 저장 실패면 모두 되돌림) · 적용 뒤 [되돌리기] · 문제마다 ⋯ '마지막 수정 전으로'.
- 미리 보는 사이 다른 창에서 바뀐 문제는 건너뜀.

## 채팅으로 줄 때
- 파일: `work/numbering/<세션>/out/JBL_가져오기_<세션>_<n>문제.json`(클라우드 세션이면 SendUserFile로 보냄 · 맥이면 경로 안내).
- 채팅: `nb.py export … --print`의 JSON을 ```json 코드 블록 하나로 그대로 — 사용자가 블록째 복사해 JBL '결과 가져오기' 칸에 붙여 넣음. 길면(약 40KB 넘음) 파일을 주로, 채팅은 나눠서(각 조각도 완전한 JSON — 강의별 export) .

## 체크포인트(이어하기)
`nb.py checkpoint` → `{"format":"jbl-numbering-session","v":1,"source":…,"state":…}` 한 파일. 새 세션·다른 기기에서 `nb.py start --from 파일`. 클라우드 세션은 `work/`가 사라지므로 중간에 멈출 때 이 파일을 사용자에게 보낸다. 또 하나의 이어하기: 통과본을 JBL에 넣은 뒤 다시 '미작성만' 내보내면 남은 문제만 온다.

# 넘버링 품질 원칙 (최종형 — 문서끼리 다르면 이 파일이 이김)

**최우선 순위: 각 문제 하나하나의 넘버링 완성도.** 문제 수·속도·토큰 절약·묶음 세계관보다 위. 부족한 스토리는 내지 않는다(보류로 따로).
넘버링 = 문제를 보면 장면이 떠오르고, 장면을 떠올리면 **정답의 모든 필수 항목이 순서대로·정확하게** 나오는 짧은 이야기. 이야기 자체를 따로 외울 필요가 없어야 한다.

## 1. 관문(하나라도 실패하면 통과 아님 — 점수로 덮지 않음)

| | 관문 | 통과 기준 | 대표 실패 |
|---|---|---|---|
| G1 | **괄호 뺀 자연성** | 괄호를 모두 지워 읽어도 생생하고 자연스러운 한 장면·사건. 각 행동이 앞 사건에서 **이어져 나옴**(인과·공간 이동·한 소품의 결과·대비 반전). 주제(촬영장·이사)가 같다는 것만으로는 연결이 아님 | CAS 촬영장(시뮬레이션→계획→가이드→… 차례만 있음) |
| G2 | **블라인드 복원** | 정답을 가리고 문제 + (괄호 뺀) 스토리만 보고 **필수 항목을 하나씩** 떠올릴 수 있음(순서는 G5 규칙대로). 항목마다 **자기만의 단서**(소리·숫자·이미지·의미)가 이야기 본문에 있음 — 괄호 라벨만 있는 항목은 실패. 단서가 둘 이상의 답으로 읽히면 실패 | 즉시하중 이삿짐(항목이 라벨로만 존재) |
| G3 | **의미 리셋(풀어쓰기 금지)** | 장면은 의학 내용과 **무관한 일상·황당 상황**에서 먼저 발상. 실패 = ① 이야기 전체가 정답 번역의 나열(초조하고·피곤하게·쓸모없게…) ② 의학 절차·기전을 순서대로 다시 말함 ③ 기술 용어가 사람·물건 배역만 맡음(의상). 단서 **하나**가 의미 단서인 것은 괜찮음 — 그 말이 장면 안에서 실제로 일어나는 일상 행동·사물이고 비틀림이 있을 때(UV의 '담배로 초에 불'·'케이크 대신 샐러드'). 단서 대부분이 정답 직역이면 실패 | CAS 장점 '컴퓨터가 결과 예측 → 상악·분절·TMJ 위치 찾고 → 하악 후퇴 선택'(답 번역) |
| G4 | **괄호 = 원문 최단 핵심어** | 괄호에는 정답 **원문 글자 그대로의 가장 짧은 구별 핵심어**만, 그 단서 바로 뒤에. 답안 문장·설명 절·번역 금지. 괄호가 단서를 **대신하면** 안 됨(라벨일 뿐) | `(Developmental delay: mental and motor)` |
| G5 | **완전·정확·순서** | 시험에 나올 항목 전부(빠짐 0) · 숫자·단위·방향 정확 · 순서가 의미 있는 답(단계·분류 차례·순위·연대)은 원문 순서 그대로 · 순서 의미 없는 나열(금기·특징·원인)도 **원문 순서가 기본**, 이야기가 분명히 나아질 때만 바꾸고 기록에 '순서 바꿈(이유)' · 구별에 필요한 한정어(1차/2차, 상악/하악, severe)는 단서에 반영 · 정답에 없는 사실 추가 금지 | 항목 누락 · 숫자 흐림 |
| G6 | **추가 암기 금지** | 외워야 할 새 이름·인물표·약자 줄·암호 문자열을 만들지 않음. 이야기를 '또 하나의 목록'으로 외워야 하면 실패 | CAS 시상식(맥스·티미제이·만두 마스코트) · 'FABSIOKCPSFR' |
| G7 | **간결** | **괄호 뺀 글 기준** 대개 60~140자·1~4문장(CDS 60·UV 72·D1 100자 — 괄호 포함은 영어 키워드 때문에 더 길어짐). 항목이 많으면(8+) 짧은 장면 두 개(장점/단점, 1형/2형)까지 — 긴 대본·두 판본 금지(도구: 괄호 뺀 글이 max(150, 항목×24)자를 넘으면 경고) | 77문제 배치(길고 의학적) |
| G8 | **문제와 이어짐** | 문제를 보면 그 장면이 떠오를 고리가 있음: 질문 핵심어를 비튼 설정(개방교합 → '개방적 기자회견', 토크 → '브라이덜 샤워 이후 토크(talk)'), 문제 단어로 시작하는 첫 단서(D1급 슈퍼카), 자연스러운 연상(노화 → 생일). 고리가 없으면 다른 문제 이야기와 섞임 | 같은 과목 비슷한 장면 둘이 서로 바뀜 |

G1·G2·G3은 특히 단단한 관문 — 자체 점수가 높아도 이 셋 중 하나라도 걸리면 그 안은 버린다.

## 2. 발상 방식(사용자 취향 — 승인 예시·DOCX에서 뽑은 장치, 틀이 아니라 도구 상자)
- **소리 조각을 평범한 말·물건으로**: Crouzon→크루즈, Pfeiffer→피자, Apert→앞에, Saethre-Chotzen→새 차, Carpenter→카펫, Muenke→문, Treacher Collins→트레저. 첫 1~2음절이 맞고, 그 말이 장면 안에서 **원래 뜻대로 자연스럽게 쓰임**이 핵심(뜻 없는 음절 나열 금지).
- **소리 조각은 한 낱말 안에**: 원어 소리를 두 낱말에 쪼개 붙이면(퍼먹었더니 + 옥수수 사이드 = peroxide) 괄호 없이 안 읽힘 — 한 낱말이 소리를 다 싣게(10-11 시험 실행 독립 검수에서 걸림).
- **구별 한정어도 제 단서**: vertical·severe·primary처럼 답을 가르는 한정어는 따로 또렷한 단서가 있어야 함(‘버티던 멘탈’ → Vertical은 독립 검수가 못 읽고 지식으로 채움).
- **한·영 섞기**: 영어 용어 일부를 그대로 소리 낸 한국어 말(Ti A Ro → 티아라, Va fi → 바람 핌, burkit → 버킷모자, mono → 너 뭐니?) — 말이 되는 곳에서만.
- **일상 외래어는 좋은 단서**: 영어 용어가 한국 일상 외래어로 따로 쓰이면(에나멜 구두·펄프 주스·라지 사이즈·레스토랑·크래커) 그 **일상 뜻으로** 장면에 쓰는 것은 좋은 단서. 뜻 없는 답 조각을 그대로 두는 것(Over·Occ)과 다름.
- **숫자 말장난**: 숫자를 한국어 읽기(12·6 → 이리 육중), 숫자 달린 일상물(66사이즈 → 55사이즈 = 6.5, PT 200번), 정확한 숫자를 그대로 맞춰야 함.
- **소품 하나 + 결과 사슬**(D1): 한 물건이 장점 → 단점을 차례로 겪음(바닥에 착 붙음 → 짧아 주차 편함 → 피가 안 통해 과열 → 너무 단단해 안 뚫림). 의미 비유가 한 물건 안에서 **물리적으로 일관**할 때 강함. 가르는 기준: 물건에 **실제로 일어나는 물리적 결과**면 좋은 비유(D1) · 사람이 의학 절차를 흉내 내면 의상(이삿짐 인부의 토크 조이기 = 실패).
- **한 장면 + 반전 행동**(UV): 햇볕에 탄 채 생일 → 담배로 초에 불 → 거울 속 엄마와 같은 주름 → 케이크 대신 샐러드. 일상 장면에 작은 비틀기(담배로 불붙이기)가 기억을 붙잡음.
- **공간·시간 이동**: 다가가서 → 안을 보고 → 문을 열고 → 안에 든 것(CDS). 순서가 있는 답에 잘 맞음.
- **감정·구어·대사**: 짜증·감탄·속어·짧은 대사(아크!!, 킹받네, "너 뭐니?") — 장면을 살리지만 대사가 체크리스트가 되면 안 됨.
- **학생의 일상 세계**: 썸·이별·졸업·오디션·데뷔·먹방·카페·원내생·시험 — 사용자에게 바로 그려지는 장면. 낯선 고유명사·밈은 피함.
- **의미 공명 보너스**: 소리 단서가 그 문제 뜻과도 살짝 맞으면 더 좋음(혈액응고 단계 → '코피나', 출혈 → 펫올림픽의 Petechiae).
- 장치를 섞어도 되고 새 장치를 만들어도 된다. **같은 틀을 문제마다 찍어내지 않는다**(전 과목이 '촬영장'·'오디션'이면 서로 간섭 — 같은 세션의 통과 이야기 장면과 겹치지 않게).
- **문제 고리 말에는 괄호를 달지 않음**(크레이지 → Cracks 같은 문제어 고리는 정답 항목이 아님 · 도구는 정답 원문에 있는 말만 괄호로 받음). 정답 항목이기도 하면 그 항목 괄호만.

## 3. 만드는 순서(문제 하나씩 끝까지 — REVIEW.md가 자세한 검수 절차)
1. **분해**: 문제·정답 전부를 읽고 시험에 나올 항목을 원문 순서대로 뽑음(해설·참고·예시는 따로 표시 · 숫자·한정어 표시 · 묶음(장점/단점) 표시 · 문제 속 출제 메모('20년엔 항목만')·연도 괄호는 단서 대상 아님). 답이 모호하거나 빠졌으면 지어내지 않고 보류.
2. **단서 캐기**: 항목마다 단서 후보를 여러 개 — 소리(한국어·영어·섞기), 숫자 읽기, 물리 이미지, 의미 비유. 가장 또렷한 것에 표시.
3. **전제 3개 이상**: 서로 **진짜 다른** 세계·작동 방식(같은 장면의 말 바꾸기는 1개로 침). 의학 뜻은 내려놓고, 단서들이 차례로 '일어날 수 있는' 장면을 찾음. 각 전제는 한 줄로 시험해 보고, 가장 나은 버린 전제 하나는 초안까지 써서 비교.
4. **초안**: 짧은 한국어 장면, 단서 바로 뒤 괄호에 원문 최단 핵심어.
5. **검수**: G1~G8을 증거와 함께(REVIEW.md 틀) — G2는 정답을 가리고 단서만으로 항목 목록을 실제로 적어 봄.
6. **결함 원인 → 재창작**: 막힌 관문과 **원인 기제**를 한 줄로 이름 붙인 뒤(예: '3번 단서가 pressure의 번역 = G3') 결함 크기에 맞게 —
   (가) **국소 결함**(단서 하나가 흐림·소리 순서 뒤바뀜·간섭 단어·인과 접착 하나) → 그 단서만 **다른 방식**(소리↔숫자↔사물)으로 바꿈, 전제는 유지 가능.
   (나) **구조 결함**(사건 사슬이 없음·전제 자체가 답 번역·인물표·복원 2개 이상 실패·목록꼴) → **전제부터** 새로.
   어느 쪽이든 같은 단서를 말만 바꾼 것·자체 점수만 오른 것은 개선이 아님.
7. **비교 → 판정**: 남은 안끼리 비교해 가장 나은 것 하나 → **승인 예시 옆에 놓기**(괄호 뺀 글을 CDS·D1·UV와 나란히 — 같은 급인가? 관문은 다 넘어도 한 급 아래면 재창작 또는 보류 '기준 미달'). 구조 결함 재창작 3번에도 못 넘으면 **보류**(이유·최선안은 결과 JSON 밖).

## 4. 관련 문제 연결(선택)
- CAS 장점·단점처럼 같은 소재·겹치는 키워드는 연결을 **검토**만: 각각 따로 만든 것보다 기억이 실제로 좋아지고, **모든** 개별 스토리 품질이 그대로거나 나아질 때만 연결. 조금이라도 억지·혼동이면 분리.
- 공통 세계관 때문에 단서를 억지로 끼우면 실패(NSCS 범죄 추격). 연결해도 각 이야기는 혼자 읽혀야 함.
- 같은 과목·같은 강의 안에서 **같은 단서 말이 다른 답**을 가리키지 않게(간섭 검사 — `nb.py next`의 '관련 문제' 참고).

## 5. 원본·사실
- 문제·정답·id·출처·연도는 절대 고치지 않음. 정답에 없는 내용·약어를 스토리 단서로 추가하지 않음(우리 지식으로 답을 보충 금지).
- 정답이 해설과 섞여 있으면 시험에 나올 핵심 항목만 단서로(해설은 넣지 않음) · 판단 근거를 검수 기록에.
- 사용자가 쓴 기존 스토리는 사용자가 고치라고 한 것만(세션 `--revise`). 거절된 스토리는 다시 내지 않음.

## 6. 쓰는 꼴(JBL에 들어가는 글)
- 맨글. 줄바꿈 = 문단(장면이 둘이면 줄을 나눔) · 서식은 거의 쓰지 않음(JBL이 `**굵게**`·`==형광펜==`을 바꿔 주지만 이야기에는 보통 필요 없음) · HTML·이모지·번호 목록(1) 2))은 쓰지 않음(목록처럼 보이면 G1 실패 신호).
- 괄호는 반각 `( )` · 단서 바로 뒤 · 원문 철자 그대로(대소문자는 원문 따름).
- 길이 기준은 G7 — 380자를 넘으면 도구가 경고, 700자를 넘으면 저장 거부.

## 7. 점수에 대해
- 비교용 감각 점수(생생함·단서 선명도·간결·재미)는 써도 되지만 **관문을 덮지 못함**. 모델의 '통과'는 잠정 판정이고, 사용자 승인만 승인이다. 사용자가 거절하면 그 이야기는 실패 사례가 되고 문제는 다시 연다.

### 결정적 차이 — 규칙 6개
1. **단서 = 답의 말 그대로이거나 그 소리.** 항목마다 그 항목을 가르는 낱말(치주인대 · macrogeometry · frequency · opposing arch)이 본문에 있어야 한다. 원어든, 답의 우리말이든, 사전 뜻 그대로든, 소리 조각이든 된다. 그 자리를 **무대 세계의 대응물(쿠션 · 바닥 · 기둥 · 강둑 · 판수 · 데미지 · 구불구불한 모양)**이 차지하면 실패다. 시험: 괄호를 가리고 단서에서 답의 말까지 **한 걸음**(같은 말이나 같은 소리)인지 본다. **두 걸음**(대응물 → 뜻 → 원어)이면 실패다.
2. **무대는 문제어를 '다른 뜻'으로 비틀어 고른다.** 개방교합 → 개방적 기자회견, torque → talk, 매독 → 독해지는, 심부전 → 부전승, signs → 사인회. **의학 기전과 닮은 세계(서스펜션 · 건축 · 금속 피로 · 게임 밸런스)**나 **문제어의 비유 원뜻(bridge → 진짜 다리)**으로 가면, 그 세계가 대응물을 불러와서 규칙 1에서 바로 실패한다.
3. **답의 말은 무대에서 '두 번째 뜻'으로 읽히거나 엉뚱하게 얹힌다.** class = 반 친구, 조직 = 회사, Ex = 전 애인, PD = 프로듀서, 첫인상 = impression, 피가 안 통하는 차. 무대가 그 병 자체이면(우울증 연예인이 우울 증상을 겪음) 재진술이다. 무대 사람이 실제로 쓸 말로 고치면(냉각수 · 서스펜션 · 판수) 그것이 대입이다.
4. **이야기가 답의 원리를 다시 설명하면 안 된다.** 응력 흡수 · 회전 중심 · 피로 파절을 다른 재료로 재연하면 '이해'는 되지만 단서는 생기지 않는다. 사용자 자료의 인과는 늘 엉뚱한 일상이다(바디프로필이라 버거 X, 사고 낸 얼간이가 번호 따감, 바람 피워서 잡아둬야).
5. **대응표를 만들지 않는다.** 제목에 '답 항목 = 무대 물건'(자연치 = SUV, 시린 이 = 몬스터)을 쓰거나, 항목마다 대응 상황을 하나씩 늘어놓으면 외울 표가 하나 더 생긴다. 사용자 말대로 "각 항목이 다른 상황에 대응한다는 사실만으로 암기법이 되는 것은 아니"다. 사용자의 '='는 **문제 = 장면**(교정기 떼는 날 = 졸업날, 꼴 = goal)뿐이다.
6. **답의 말이라도 덩어리면 실패다.** 사용자가 답의 말을 그대로 쓴 줄에는 언제나 말하는 사람과 감정이 있는 한 문장이 있다(졸업 다짐 · 기자회견 부인 · 원내생 꾸중 · 연인 싸움). 명사만 줄 세우면 거절 5가 된다. 거절 1~4는 소리 단서가 0~2개인데, 좋은 줄은 대개 절반 이상이 소리다.

### D1이 차를 쓰는데도 통과한 이유(정확히)
- 차를 고른 이유가 기전이 닮아서가 아니다. **문제어 'D1'이 등급 이름처럼 읽혀서**다(D1급 슈퍼카). 무대 = 문제 고리다.
- 항목을 가르는 말이 **모두 답의 말**이다: 접촉면적 → 착 붙고, 일차 안정성 → 안정감, 짧은 길이 → 짧아, 혈액공급 감소 → 피가 안 통해서, 과도한 열 → 과열, Drill hole → 구멍 뚫림. 차 말(바닥 · 차체 · 엔진)은 배경일 뿐이고, 단서 자리에 차 부품이 들어간 곳은 한 군데도 없다.
- 그래서 엉뚱하다. **차에는 피가 없다.** 차 세계에 맞췄다면 '냉각수가 안 돌아서'(대응물)가 됐을 것이고, 그것이 바로 거절 1의 꼴이다. 이 엉뚱함이 답의 말을 그대로 옮겨 왔다는 표시이고 기억 고리다.
- 사용자가 고친 판이 이를 증명한다. 차 세계 쪽 살('주차하기 편해' · '수리하려니까 너무 단단해서 안 뚫려')은 지우고 답의 말(짧아 · 구멍 뚫림)만 남겼다. CAS에서도 대응 소품(데이트 · 커플 팔찌 · 웨하스 선물 · 엔딩 보상)을 지우고 외래어로 된 답의 말만 남겼다.
- 물건 하나에 '근데' 반전과 감탄(최고야!)이 붙은 한 사건이다. 목록이 아니다.
- 결론: D1의 성공 기제는 '물리적으로 일관된 비유'가 아니다. **문제어로 고른 무대 위에 답의 말을 그대로 얹은 것**이다.

4. **어긋남 — 용어까지 버리라는 지시.** 옛 SKILL ②: "Discard the original medical mechanism **and terminology** while inventing the scene." 옛 원칙 7: "terminology appears only as brief verification labels." 용어까지 버리라고 하니 작성자가 답의 말 대신 무대의 대응물을 찾게 된다. 의상 번역의 뿌리다. 사용자 자료와 A0은 답의 말(외래어 · 우리말)을 본문에 그대로 둔다. 지금 G3의 "단서 대부분이 정답 직역이면 실패"도 A0(D1은 6/6 직역, CAS는 외래어 그대로)과 부딪친다. → '**기전은 버리고, 말과 소리는 살린다**'로 고치고, 실패 조건은 '직역이 의학 사건 재진술 안에 있거나 명사 덩어리일 때'로 좁힐 것.
5. **빠짐 — 설명 머리말.** 옛 원칙 9: "without an arbitrary character roster or **explanatory preamble**." 지금 꼴 규칙은 첫 줄 '[장면·문제 고리]'를 권하지만, 제목에 대응식이나 설명을 넣지 말라는 말은 없다. 거절 1(자연치 = SUV, 임플란트 = 카트)과 거절 4(시린 이 = 게임 몬스터 공략)의 제목이 대응표다. → '대괄호 제목에는 문제 고리만 쓰고, 답 항목 = 물건은 쓰지 않는다'를 넣을 것.

(옛 스킬과 지금 스킬 어디에도 없는 장치. 원자료에서 새로 보인 것이라 EXEMPLARS C1에 더할 만하다: 동음이의(Ex · 복수 · 조직 · PD · weight → wait) · 우리말 답의 첫 음절을 관용어나 속어로(골치아프군 · 오지게 · 고고흡당 · 손가락질) · 글자를 학점으로(C·D·F, D·E) · 소리 조각의 뜻(pig → 돼지, tetra → 4회, X → 10) · 실화나 누구나 아는 이름에 기대기(MC몽 · 티아라 · 라스베가스 · 알리 익스프레스).)

**거절 사례(원문 + 한 줄 이유)**
1. "[자연치 = 서스펜션 SUV, 임플란트 = 서스펜션 없는 카트] SUV는 쿠션(치주인대)이 충격을 먹어 주고(응력 흡수) / 카트는 옆에서 밀면 위쪽(치조골 상방)을 축으로 휘청(회전 중심) / … 차체 깨지고(상부 구조물의 파절) 나사 풀리고(나사 풀림) 바닥까지 꺼져(치조골의 흡수)" — 단서가 차 부품 대응물(쿠션 · 차체 · 바닥)이고, 이야기가 생역학을 다시 설명함. 제목이 대응표이고 소리 단서는 0.
2. "[날림 공사 브릿지가 무너진 이유] 기둥은 몇 개 없고(number) 짧고(length) 가늘고(diameter) / 강 아무 데나(Location) 박았어 / … 맞은편 강둑(opposing arch)마저 무너져 있었어" — bridge를 진짜 다리로 되돌려 대응물(기둥 · 강 · 강둑)을 씀. 나머지는 번역 형용사 나열.
3. "[철사 클립 구부렸다 폈다, 결국 똑] 바이오 클립(biomaterial)이 구불구불한 모양(marcrogeometry)인데 / 힘줘서 세게(force magnitude) 꺾고 / 사이클 돌리듯 계속(number of cycles) 꺾었더니 결국 똑" — 금속 피로라는 같은 원리를 다른 재료로 재연함. '구불구불한 모양'으로는 macrogeometry가 떠오르지 않음.
4. "[시린 이 = 게임 몬스터 공략] 패시브 스킬(Passive)은 너프 패치 / 플레이타임 다운(Reduce time), 판수 다운(Reduce frequency), 데미지 다운(Reduce concentration) …" — 같은 뜻을 게임 말로 갈아 끼운 의상 번역이라 외울 때 한 번 더 풀어야 함. '다운'×3은 서로 구별되지 않음.
5. "[인레이 vs 때우기 고민] 재료 성질(Physical properties) / 남은 치아 양 / 예쁨 / 의사·환자 취향 / 돈" — 장면 · 이음말 · 소리가 없는, 뜻 명사 덩어리.

**절대 규칙**
1. **단서 말 = 답의 말 그대로(원어 · 답의 우리말 · 사전 뜻) 또는 그 소리.** 무대 세계의 대응물(쿠션 = 치주인대, 기둥 = 임플란트, 판수 = frequency)이 단서이면 실패.
2. **무대는 문제어를 다른 뜻으로 비틀어 고른다**(D1급 슈퍼카 · 카스 점집 · 부전승 · 사인회 · 출장). 기전이 닮은 세계(서스펜션 · 건축 · 금속 피로 · 게임 밸런스)나 문제어의 비유 원뜻(bridge → 다리)은 쓰지 않는다. 무대 말(엔진 · 차체)은 배경일 뿐이다.
3. **답의 말은 무대에 '어색하게라도' 그대로 얹는다**(피가 안 통하는 차, Ex = 전 애인, 조직 = 회사). 무대 사람이 실제로 쓸 말로 고치면 그것이 대입이다. 사용자는 CAS 판에서 커플 팔찌(= plates) · 웨하스 선물 · 엔딩 보상을 지웠다.
4. **이야기는 답의 원리를 다시 설명하지 않는다.** 엉뚱한 일상 사건(사고 · 이별 · 꾸중 · 소개팅 · 사인회)이 일어나야 한다.
5. **대응표를 만들지 않는다.** 제목에 '답 항목 = 물건'을 쓰지 않고, 항목마다 대응 상황을 하나씩 늘어놓지 않는다. '='는 문제 = 장면에만 쓴다.
6. **덩어리를 만들지 않는다.** 말하는 사람 · 이음말 · 감정(아크!! · 하 쒸 · 킹받네)이 있는 한 사건으로 쓴다. 소리 단서가 뼈대다(머리글자는 아는 낱말이나 이름으로, 숫자는 정확히, 동음이의가 가장 좋다).
7. **검사한다.** 괄호를 가리고 단서마다 답의 말까지 '한 걸음'인지 본다. 두 걸음인 단서가 하나면 그 단서를 바꾸고, 절반이면 전제부터 다시 쓴다. 그래도 안 되면 억지로 대입하지 말고 보류한다(사용자도 '단순암기'로 남김).

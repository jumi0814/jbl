# JBL 허브 — 폴더 구성

```
JBL_HUB/
  JBL_HUB.html            허브 본체 (과목 홈·정리본·JB 문제·도구·검색·백업)
  packs/<과목>.js          과목 팩 본문 (정리본·문제·비교표·예상·대장)
  packs/<과목>.img.jb.js   JB 원본 쪽 이미지 (JB 원본을 열 때만 로드)
  packs/<과목>.img.<강의>.js 강의별 슬라이드 이미지 (그 강의를 열 때만 로드)
```

- 새 과목이 오면 `packs/` 에 그 과목의 파일들만 추가하면 됩니다. 허브 본체는 그대로 둡니다.
- 과목 코드: OMS1 구강악안면외과학1 · CONS 임상치과보존학 · IMPL 치과임플란트학 · ANAT 임상두경부해부학 · GERI 노인치과학 · PHARM 임상치과약물치료학 · ESTH 심미치과학
- 형광펜·빈칸·메모·채점·이해함·공부시간은 브라우저(localStorage)에 저장됩니다. 폴더를 옮기거나 다른 브라우저로 가면 안 보이니 위쪽 **백업**을 가끔 받아 두세요.
- 파일을 `file://` 로 열어도 동작합니다. 단, 브라우저가 저장소를 비우면 표시가 사라지니 백업이 안전합니다.

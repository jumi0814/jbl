# 4Q 자료 보내는 법 (11-04 · 11-15 맥 폴더 정리판)

## 맥에서 — 명령은 두 개뿐

**① 처음 한 번 (자리 만들기)** — 터미널에서 jbl 폴더로 간 뒤:
```
git pull && sh tools/push_materials.sh
```
- jbl 폴더로 가는 법: 터미널에 `cd ` (cd 다음 한 칸 띄움)까지 치고 Finder의 jbl 폴더를 터미널 창에 끌어다 놓은 뒤 엔터.
- 처음 돌리면 아래 자리가 생기고, 옛 3Q 파일이 3Q 칸으로 옮겨집니다(지우는 것 없음). 넣은 파일이 아직 없으면 '새로 올릴 것 없음'으로 끝나요.

**② 파일을 넣을 때마다 (넣고 → 같은 한 줄)**:
```
git pull && sh tools/push_materials.sh
```
- 끝에 `4Q 자료 올렸어: RAD HINS …` 한 줄이 나옵니다 → **그 줄을 그대로 Claude 대화창에 보내 주세요.** 나머지(정리본·기출 해설·예상문제·검사·배포)는 Claude가 합니다.
- 올리기 전에 무엇이 올라갈지만 보려면: `sh tools/push_materials.sh --dry`

## 어디에 넣나
```
jbl/
├─ materials/
│  ├─ 3Q/<과목>/        ← 3Q 강의자료(보관 — 처음 돌릴 때 옛 자리에서 저절로 옮겨짐)
│  └─ 4Q/<과목>/        ← ★ 4Q 강의자료: PDF·PPTX, 받은 이름 그대로(예 261104_최용석_파노라마.pdf)
├─ jb/
│  ├─ 3Q/               ← 3Q JB: '2026 3Q <과목> JB.pdf' (3Q 26판 7개도 여기)
│  └─ 4Q/<과목>/        ← ★ 4Q JB: 판본마다 PDF 한 개 · 이름 아무거나 + 연도 네 자리(예 '2025 구강외과2 JB.pdf', '영상 기출 2024.pdf')
└─ (두 폴더 안의 '여기에_넣는_법.txt' = 이 요약)
```
- **강의자료**: 26 강의자료+필기(필기는 PDF 주석·손글씨 그대로) · 26 수업이 아직 없는 강의는 25 강의자료 · 교수님이 교과서에서 내시면 그 교과서 쪽 PDF. 25·26이 같이 있어도 됩니다(파일 이름 앞 날짜로 가립니다).
- **JB**: 과목마다 가진 판본 전부(23·24·25·26판). 같은 해 판이 두 파일(문제·답안 따로 등)이면 하나로 합쳐 주세요 — 두 파일이면 하나만 풀고 알려 줍니다.
- 사진(JPG·HEIC)·한글(hwp)은 PDF로 바꿔 넣거나, 대화창에 바로 첨부해 주세요.
- **2026 3Q 실제 기출 복원(임상치과보존학 엑셀 등)은 폴더에 넣지 말고 대화창에 첨부**해 주세요(학생 이름이 들어 있어 저장소에 올리지 않음 — 이름은 어디에도 옮기지 않습니다).

## 한 줄 명령이 하는 일(tools/push_materials.sh)
0. 폴더 정리 `tools/folders.py` — 자리 만들기 · 옛 `materials/<3Q 과목>/` → `materials/3Q/` · 옛 `jb/` 바로 아래 3Q JB → `jb/3Q/` · 4Q 표준 이름 JB → `jb/4Q/<과목>/` · 옮길 자리에 같은 이름이 있으면 옮기지 않고 알림 · 과목별 파일 수 보여 줌
1. 강의자료 추출 `tools/matx.py` — 쪽 이미지·글·필기·OCR(이미 뽑은 쪽은 건너뜀 · 빈 과목 폴더도 괜찮음)
2. JB 풀기 `tools/jbx.py` — `jb/` 아래 전부(3Q·4Q) · 이미 푼 판은 건너뜀 · 알아보지 못한 파일(연도 없음 등)은 `?` 줄로 알림
3. `cloud-materials` 브랜치에 아직 없는 추출본만 올림(원본 PDF는 올리지 않음)
4. 대화창에 보낼 한 줄을 보여 줌
- 회귀 `tools/tests4/q_folders.py`(옛 맥 모양 → 정리 · NFD 이름 · JB 하위 폴더·연도·중복 · 다시 돌리기 · 빈 과목 폴더).

# 예상문제 답(해설)의 필기 최소화(10-27)

사용자(10-27 원문): "더불어 앞으로 예상문제의 해설을 쓸 때 필기 내용은 정말 강조나 필수적인 내용 제외하곤 최소화해줘! 정식 답안 자체는 보통 피피타 강의자료 안에 답이 있는거니까, 필기 내용까지 같이 수록하면 필수적인 경우 제외는 너무 헷갈려!"

## 원칙 — 예상문제 답 = 강의자료(PPT 슬라이드) 글이 정식 답
필기(`{n:…}` 조각 · '(필기)'·'26 필기:'·'25 필기 p.N'·'필기 "…"' 꼬리·인용)는 아래 셋일 때만 남긴다. 나머지는 지운다(정리본 카드에는 그대로 있으니 공부할 땐 거기서 봄).
- **K1 강조·시험 예고**: 필기가 '시험'·'중요'·'꼭'·'외우'·'기억'·'빈출'·'나온다'·'강조'처럼 교수님 강조를 적은 것, 또는 원고 `{e:}`(26 강조)·`P:`(💬 교수 강조)와 같은 내용 → **한 줄로 짧게**(필기 글자 그대로 — 앞뒤를 덜어 내는 것만, 낱말을 바꾸지 않음).
- **K2 필수**: 슬라이드에 답 글이 없고 필기(또는 JB 답)에만 답이 있을 때(그림·사진뿐인 쪽의 이름·라벨, 기출 답이 필기를 근거로 한 것, 슬라이드가 낱말만 있고 문제가 묻는 뜻은 필기에만) → 답에 필요한 낱말만.
- **K3 경고**: 슬라이드·필기·JB가 서로 어긋나 틀리기 쉬운 곳(⚠ 줄) → 한 줄.
지우는 것: 이해용 풀이·비유·부연·우리말 옮김·예시·일화 · 슬라이드 글을 다시 말한 필기 · 25 필기와 26 필기가 같은 말을 두 번 · 필기 출처 설명.

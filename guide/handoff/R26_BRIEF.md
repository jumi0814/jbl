## 1. 복원 읽는 법 — 문항 하나로 합치기
- 복원자 91명이 문항 약 25개를 **복원번호 순서대로 돌아가며** 맡음(뒷번호 = 앞 문항을 다시) → '문제' 칸(교수·번호)과 본문으로 문항마다 묶음(같은 교수·같은 번호 = 같은 문항). '문제' 칸이 비었거나 틀린 줄(다른 문항 글을 잘못 붙여 넣음 · '1.0'처럼 숫자만)은 본문으로 판단 — 어느 문항인지 모르면 버리고 보고에 줄 번호.
- 문항마다: 가장 온전한 복원 하나를 **글자 그대로**(줄바꿈만 정리 — 끊긴 줄 이어 붙임 · 보기 한 줄에 하나) Q:로. 여러 복원을 섞어 새 문장을 만들지 않음. 보기·수치·낱말이 복원마다 다르면 V:에 다른 쪽 글을 그대로 짧게 + '복원 n명 중 m명'.
- 답: 복원자 풀이(선택 칸) 중 강의자료와 맞는 것 하나를 글자 그대로 A:로 — 'GPT에 의하면'·출처 없는 바깥 지식 줄은 빼고(줄 단위로만 · 빼면 '(일부 줄 생략 — 자료 밖 인용)') · 풀이가 없거나 모두 자료와 다르면 `A: (복원 답 없음)`. T/F·객관식 답이 복원자끼리 갈리면 둘 다 적고 강의 근거로 어느 쪽인지 H:에.
- 복원자가 적은 '(짤)'·'(탈)'·'2025 JB 12번' 같은 메모는 판단 참고(그대로 믿지 않음 — ref로 확인).
- 학생 이름·출석번호·사진 링크 주소는 어디에도 옮기지 않음.

## 2. 쓸 것 ① `tools/<sid>/r26.txt` (3Q 사이트 '2026 출제' 자료 — 메인이 빌드에 넣음)
```
# 2026 3Q <과목> 실제 출제 — 학생 복원 정리(11-05 · 복원 n명 → 문항 m개) · 원본 엑셀은 커밋 안 함 · 형식 guide/handoff/R26_BRIEF.md 2절
@Z01 prof=<교수> no=<그 교수 몇 번 — 복원 표기> fmt=<서술형|넘버링|단답형|빈칸|객관식|T/F> st=<짤|변형|탈> jb=<같은 문제의 기존 JB id — 짤·변형만> rel=<비슷하지만 다른 기존 id들(쉼표)> lk=<강의 키> p=<[[KEY:쪽]] — 원고에서 찾은 쪽 · 모르면 비움> n=<이 문항 복원 수> conf=<확실|불확실>
Q: <문제 — 복원 글 그대로(여러 줄이면 다음 줄들도 Q 다음에 그대로)>
A: <답 — 복원 풀이 글 그대로 · 또는 (복원 답 없음)>
V: <다른 복원의 다른 표현·보기 — 없으면 줄 없음>
H: <판정 한 줄 — 짤: 'Q51(25) 같은 문제 · 25 상대적 → 26 절대적(낱말 뒤집기)' · 탈: '같은 강의 p.N 표 다른 행' · 답 근거 '원고 lec_<KEY> p.N과 일치/불일치'>
```
- id = Z + 시험 순서 두 자리(Z01…) — 문항 순서 = 복원 표의 교수·번호 순(복원번호 1~25 순서가 보통 시험 순서).
- st: 짤 = 기존 JB와 같은 문제(글이 거의 같음) · 변형 = 같은 기출 축인데 낱말·수치·꼴이 바뀜(jb=에 그 축) · 탈 = 기출 없던 자리(jb= 없음 · 가까운 것은 rel=).
- jb=는 ref_<SID>.md의 카드 id만(현 교수 카드에 없으면 annot.txt에서 찾아 id 확인 · 없으면 rel=도 비움).
- lk = 그 내용이 있는 강의 키(subject.py LECMAP) — 교수 담당 강의와 다르면 H:에.

## 3. 쓸 것 ② `work/<SID>/hit26/HIT_<SID>.md` — AGENTS.md 'HIT' 그대로
- 표(문항마다): Z id · 교수 · 꼴 · 강의·쪽 · 짤/탈(기존 id) · 우리 예상 판정 = **짤 축 적중**(같은 기출 축의 예상·N제 있음 — 꼴 같음/다름) / **탈 자리 적중**(기출 없던 자리를 예상·N제가 덮음 — 같은 쪽·같은 표·같은 목록) / **놓침** + 놓친 꼴(같은 쪽 다른 칸 · 표 다른 행 · 목록 다른 항목 · 수치 빈칸 · TF 낱말 뒤집기 · 꼴 바꾸기 · 교과서 · 필기 예고 · 26 새 쪽 · 그림) · 맞힌 예상의 aid(또는 Q 첫 30자)·pr(상/중/하)·N제 여부.
- 교수마다 합계: 문항 수 · 짤 n/m · 꼴 분포 · 적중(짤 축 + 탈 자리) n/m · 상만 봤을 때 n/m · N제 적중 · 놓친 꼴 순위 · 우리 TREND(trend26)와 맞았는지 한 줄.
- 끝 절: **RULES 11 후보**(놓친 꼴에서 배운 규칙 한 줄씩 — 일반 규칙으로) · **프로필 몫**(교수마다 README 형식 2·3·4·6·7절에 들어갈 줄 — 근거 id 붙여) · **3Q 사이트 넣기 메모**(r26 문항마다 '기존 카드에 2026 더함(jb=)' / '새 카드' — 이상한 점).
- 판정마다 근거(예상 aid 또는 Q 첫 30자 · JB id) — 추측 금지, 애매하면 '불확실'.

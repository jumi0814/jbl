# S3 — 예상문제 화면(우선순위·근거·그림·보관) + 넘버링 연동 + 그림빵 (10-15)

사용자(10-15 원문):
- "3. 예상문제 ↔ 넘버링 따기 연동 — 예상문제를 넘버링 따기로 가져올 때 출제 우선순위·관련 JB·출제 근거를 확인하고 높은 우선순위 문제부터 간편하게 선별할 수 있도록 개선. 기존 검색·필터 기능과 자연스럽게 통합하고, 태그는 짧고 직관적으로 표시하되 상세 근거는 필요할 때 확인하도록 구성. 문제보다 태그가 길어지지 않게 할 것. 그림이 포함된 JB·예상문제를 가져올 때는 이미지도 함께 연결되어 문제 풀이와 복습에서 확인할 수 있도록 할 것. 가져온 뒤에도 출처·우선순위 정보는 유지하되, 사용자가 수정한 문제·답안·넘버링 스토리와 복습 기록을 자동 갱신으로 덮어쓰지 말 것. 문제 갱신으로 기존 넘버링과 학습 기록의 연결이 깨지지 않도록 처리."
- "4. 교수별 그림빵 대비 기능 — 실제 그림·빈칸 출제 이력이나 명확한 출제 근거가 있는 교수·강의에만 그림빵 기능을 제공. 필요 없는 강의에 별도 탭을 만들지 말 것. 기출 그림빵: 원본 JB 그림과 실제 출제된 빈칸·번호·정답을 최대한 보존해 복습. 예상 그림빵: 교수의 그림 출제 방식과 26년도 PPT를 분석해, 기출에 없던 다른 그림에서도 출제 가능성이 높은 문제를 선별. 그림 빈칸·번호를 가리고 개별/전체 정답을 확인하는 등 효율적인 복습 방식을 제공하고, 일반 빈칸빵에서도 필요한 그림을 활용할 수 있도록. 강의 정리본·JB·예상문제·넘버링과 자연스럽게 연결하고, 유용하다면 그림빵 모아 풀기도 제공. 기존 이미지 데이터와 처리 기능은 효율적으로 재사용. 과거 교수의 그림 기출과 현재 예상 그림을 구분하고, 26년도에서 빠진 그림은 과거 JB 대비용임을 명시."
- "불필요한 반복 분석·전면 재작성·과도한 UI 추가·장황한 중간 보고를 피할 것." · 페이지 구성(CLAUDE.md '페이지 구성')은 유지.

## 할 일
1. **예상문제 카드**(build4 + shell): 머리 = `예상` 배지 + 우선순위 칩(상/중/하 — 짧게, 색 3단계 · 명암 감사 통과) + 유형(짧게) + 관련 기출 칩(b 전부 — 지금 '관련 기출 연도 · 요지' 칩 꼴, 여러 개면 연도만) + '근거' 작은 버튼(누르면 why 한 줄 펼침 — 기본 접힘). 태그 줄이 문제 글보다 길어지지 않게(좁은 화면 820에서 한 줄). f= 그림은 문제 아래(쪽 이미지 지연 로드 · 누르면 크게 — 기존 그림 모달 재사용). oid가 있으면 data-aid·data-id에 oid(사용자 ✓·✗·★·넘버링 연결 유지). x=1은 예상 탭 맨 아래 '보관된 예상문제 n개 ▸'(접힘 · 플래시카드·개수·모아보기에서 빠짐 — 기록은 그대로 보임).
2. **예상 탭 필터**(shell predBar): 우선순위(전체 · 상 · 상+중)·유형 — 기존 필터 막대에 자연스럽게(새 줄 늘리지 말고). 과목 홈·강의 카드의 '예상 n'은 활성만.
3. **넘버링 가져오기**(tools/num/num.js importDlg·parseJB 근처): 예상문제 행에 우선순위·유형·관련 기출 연도 짧은 태그, '근거'는 펼쳐서. 필터 막대에 우선순위(상만·상+중·전체)와 정렬 '우선순위 높은 순'. 가져올 때 문제 그림(JB img.fig·예상 f= 쪽 이미지(지연 로드 → 가져올 때 실제 이미지로 받아 넣기)·그림빵 이미지)을 문제 쪽에 함께(지금 JB img.fig 처리와 같은 꼴). 가져온 항목에 출처 메타(우선순위·유형·근거·관련 기출)를 저장(사용자 글과 별도 필드 — 다시 가져오기·사이트 갱신 때 사용자 문제·답·스토리·복습 기록은 절대 덮어쓰지 않고 메타만 갱신 가능). 연결 키 = data-aid(oid 덕분에 고쳐 쓴 문제도 같은 키). 이미 가져온 문제가 사이트에서 고쳐졌으면 지금의 '충돌/같음' 미리 보기 규칙 그대로(자동 덮어쓰기 없음).
4. **그림빵**(근거 있는 강의만):
   - 강의 탭: 그 강의에 (a) 그림 기출(그림 조각이 있는 JB 문항 — 연결 강의 기준) 또는 (b) `t=그림빵` 예상이 있을 때만 '그림빵' 탭(없으면 탭 없음 — docTabs). 탭 = 기출 그림빵(JB 그림 조각 + 원래 문제 글 + 답 — 답 번호마다 하나씩 펼치기·전체 펼치기 · 교수·연도 배지 · 옛 교수 기출이면 '옛 교수 기출' · 26에서 빠진 그림이면 '과거 JB 대비용') → 예상 그림빵(쪽 이미지 위에 m= 상자를 번호 붙인 가림막으로 · 상자 눌러 하나씩 · '전체 보기/가리기' · 답 목록 · 우선순위·근거 칩).
   - 과목 메뉴에 '그림빵 모아 풀기'(`#/<S>/_fig` — 그 과목 모든 강의의 기출·예상 그림빵, 강의·교수 필터) — 과목에 그림빵이 하나도 없으면 메뉴 없음.
   - 학습 탭 카드의 F: 그림·JB 카드와 서로 이동(그림빵 항목의 '📖 정리본'·'JB 문제' 칩 — 기존 칩 재사용).
   - 일반 빈칸빵(자동 빈칸 모드)에서 카드 그림이 그대로 보이는지 확인(안 보이면 보이게).
   - ✓·✗ 채점과 기록 키: 예상 그림빵은 그 예상문제 aid(기존 예상 기록 꼴) · 기출 그림빵은 JB 문항 id(기존 채점과 같은 기록 — 새 키 만들지 않음).
5. 검사·테스트: build4 → `tools/sync_common.py` → 과목 빌드(메인이 지정하는 것만) → `JBL_HTTP=1 .venv/bin/python tools/verify.py` · `tools/audit_design.py`(명암·긴 덩어리·가로 넘침 — 820·1180·1280) · 새 회귀 `tools/tests/ux16_pred.py`(우선순위 칩·근거 펼침·필터·보관 접힘·oid 기록 이어짐·f 그림) · `ux17_fig.py`(그림빵 탭 있는 강의/없는 강의 · 가림막 하나씩·전체 · 모아 풀기 · 채점 기록) · `ux18_numpred.py`(넘버링 가져오기 우선순위 필터·태그·그림 가져옴·다시 가져오기에서 사용자 글 안 덮음) + 기존 tests 중 예상·넘버링·플래시카드 관련 전부 통과. tools/full_check.sh에 새 테스트 추가. tools/SPEC.md·guide/넘버링_따기.md에 절 추가.

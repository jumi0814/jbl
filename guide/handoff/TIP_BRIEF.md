# 과목 홈 강의 박스 '📌 공부 전략' 쓰기 (10-03 사용자 요청)

사용자(10-03): "과목별 페이지에서 각 강의자료 박스 나열된 곳에 교수님 예고나 수업 필기가 짤탈 비율 아래 적혀져있는데, 그건 … 정리본 누르고 들어갔을 때 교수님 예고·강조 란 … 으로 충분하고, 원래 박스 나열된 곳에선 너가 분석한 공부전략, 최적의 효과적 추천하는 공부방식이나 팁을 써놓는걸로 해줘! 모든 과목의 각 강의자료 박스에 다 적용"

## 할 일 — 맡은 과목의 모든 강의 원고 `tools/<sid>/lec_<키>.txt`
- `#LEC` 줄 바로 다음(이미 `@TIP`이 있으면 그것을 고침)에 **`@TIP <글>` 한 줄**을 넣는다. 박스에 "📌 공부 전략 <글>"로 보인다(짤/탈 비율 줄 아래).
- 길이: **90~150자**(박스에서 2~3줄). 한 강의에 `@TIP` 한 줄만.
- 내용 = **이 강의를 가장 효율적으로 공부하는 순서·방법**. 근거는 이 강의의 JB 출제 기록과 원고에서만:
  1. 어디부터: 많이 나온 주제(⭐·2회 이상·완짤) — 카드 주제 이름으로("Indications·Contraindications 카드 먼저").
  2. 어떻게: 출제 형식에 맞는 공부법 — 서술·나열이면 "항목 수와 순서까지 그대로 써 보기", 빈칸·단답이면 "⚡ 암기 줄 빈칸으로", 객관식 T/F면 "함정 선지(⚠)만 따로", 그림 문항이면 "그림 이름 가리고 말하기", 비교면 "비교표로".
  3. 짤/탈 성격: 짤 위주면 "기출 답을 원문 그대로", 탈이 많으면 "교수 강조·시험 예고 쪽(정리본 📣 칸) 전체를 한 번 더".
  4. 새 연도 자료 반영 강의(26)는 바뀐 점이 있으면 한 마디(예: "26 필기 시험 예고 p.36-41 추가 — 와동형성 원리 5가지").
- 확인할 곳: 원고 `!` 머리말의 '출제 경향'·'공부 전략' 줄, 카드의 E:(⭐) 줄 수·연도, `work/<SID>/review/questions.md`(문항별 '출제' 연도·형식), 정리본 머리의 교수님 예고·강조.
- **자료·JB에 없는 사실을 쓰지 않는다**(공부 방법 제안은 되지만 의학 내용은 원고에 있는 것만). 문항 id(Q12 등) 글자 금지. 화면 글자는 한국어 중심, 과목 용어는 원고 표기 그대로. 쉼표보다 ' · '와 '→'로 짧게.
- 다른 줄은 바꾸지 않는다. 빌드·커밋 금지.

# 10-24 디자인 v3 — 폰 위 고정 영역 + 전면 디자인·인터페이스 개편 (내용 불변)

사용자(10-24, guide/피드백기록.md 맨 끝 줄): 폰 예상 탭 스크린샷 — "폰 화면의 상단 절반을 위 탭으로 가리고 있는 이 오류 고쳐주고 전반적으로 색감 탭, 배치 구조 인터페이스 등 모든게 다 밤티야 즉 old fashioned … 내용과 형식 이런건 다 그대로 절대 내용물은 바꾸지 않으면서 … 전반적인 디자인 및 인터페이스를 가장 최적으로 효과적 효율적으로 전면적 획기적으로 업데이트"

## 원인(폰 오류)
- 폰에서 위에 붙는 것이 상단 막대(☰·검색·시계·? + 경로 줄로 두 줄) → 강의 탭 줄(탭 + ✎ 넘버링 줄바꿈 + 도구·집중·시계 줄) → 예상 거르기 막대(#ppills 2~3줄)까지 모두 `position:sticky` — 합치면 화면 위 40~50%.

## 바꾼 것
1. 색 바꾸기 `tools/design/v3_palette.py`(한 번 — shell.html의 style·script, tools/num/num.js): 따뜻한 저채도 색(종이 베이지·갈색 글자·크림 바탕, OKLCH 채도 < 0.03 · 색상 45~110°, 아주 밝은 색은 < 0.018)을 **같은 밝기(L)의 차가운 회색**으로(명암비 그대로) · 아주 밝은 크림 → 흰색 · 순수 회색도 같은 회색 줄로. 의미 색(빨강·초록·보라·금색·파랑·형광펜·과목 색)은 채도가 높아 그대로.
2. shell.html `<style>` 맨 끝 '10-24 디자인 v3' 묶음(v2 뒤 — v2보다 이김):
   - 토큰: 바탕 `--v-bg #F3F4F6` · 판·카드 흰색 · 옅은 면 `--v-tone #F0F2F5`(보조 단추·꺼진 칸) · 선 `--v-line #E3E6EA` · 먹 `--v-ink #111827`(4단계) · **brand = 먹색**(주 단추·켜진 칸 채움 — 색은 의미에만) · 모서리 10/16/999 · 그림자 2단.
   - 앱바: 흰 반투명 + 흐림 · 로고 먹색 사각 · 바로 가기·검색·시계·? = 옅은 면 알약.
   - 사이드바: #FAFBFC · 지금 항목 = 흰 카드 + 가는 선(+ 과목 색 선택 막대 그대로).
   - 탭 줄: 흰 바탕 · 꺼진 탭 회색 글자 · 지금 탭 먹 + 과목 색 밑줄 2px.
   - 단추: 보조 = 옅은 면(테 없음) · 주(답 보기·시작하기) = 먹 채움 · 맞음/틀림/★ 글자 색 + 표시하면 옅은 초록/빨강/금 바탕(상태 규칙 .qc.mk-ok … 그대로 이김).
   - 거르기 칸(.tg): 꺼짐 = 옅은 면 알약 · 켜짐 = 먹 채움 흰 글자(JB #jbbar·예상 #ppills·플래시카드·과목 화면 모두).
   - 칩: 연도 칩 금색 #FFF7E0(2회↑ #FFEDB8) · 출처 칩 흰 바탕 가는 선 · 예상 파랑 그대로.
   - 카드: 흰 바탕 · 가는 선 · 옅은 그림자(마우스를 올리면 조금 진하게) · 🔑 상자 #F5F7FA + 먹 왼쪽 띠 · ⭐ 시험포인트 옅은 금 바탕.
   - 아래 도구 막대(#kit): 떠 있는 어두운 알약(흐림 · 흰 글자).
3. 폰(≤600):
   - 앱바 한 줄: ☰ · 로고(글자 없이) · 과목 점 · 지금 화면 이름(굵게, 넘치면 …) · 검색(돋보기 — 누르면 앱바 전체로 펼침) · 시계 · ?.
   - **아래로 밀면 앱바가 숨음**(body.hdrhide → measure()가 --toph 0 → 탭 줄이 맨 위) · 위로 조금 밀면 다시 · 맨 위 64px 안·서랍·집중 모드·검색 중엔 늘 보임 · 바꾼 직후 450ms 스크롤은 무시(탭 아래 도구 줄이 접히며 생기는 브라우저 스크롤 보정이 숨김↔보임을 되풀이하던 것).
   - 탭 줄: 탭 한 줄 가로 밀기(지금 탭 가운데) · 도구 줄(카드 n/N·보기·✎ 도구·집중)은 그 아래 둘째 줄 — 앱바가 숨을 때 같이 접힘.
   - 거르기 막대(#ppills·.sumbar·.tbltoc·.hlbar·.cbmtabs)는 위에 붙지 않음 · 예상·JB 거르기 = 한 줄 가로 밀기 · JB는 내렸을 때 작은 막대(.mini) 한 줄만 붙음.
   - 결과(393×852): 내린 뒤 위에 남는 것 = 탭 한 줄 49px(JB 화면은 거르기 한 줄 78px) — 전에는 ~400px.
4. 글꼴: Pretendard CDN은 넣었다가 뺌(클라우드 브라우저가 프록시 인증서를 믿지 않아 콘솔 오류 — 사용자 기기의 시스템 고딕(Apple SD Gothic Neo)이 이미 깔끔) · 글꼴 묶음 첫머리 'Pretendard Variable'(설치된 기기에서만).
5. theme-color #FFFFFF(폰 주소창 색).

# CONS(임상치과보존학) JB 전수 검토 — 2026-10-24

검토 범위: JB 23·24·25·26판 **75쪽 전부**(텍스트층 전 쪽 읽음 + 그림 쪽 23판 4·8·12, 24판 5·13·16, 25판 3, 26판 2·3·10·11·26·28·33 이미지 직접 확인) ↔ 사이트 카드 71개(현 교수 69 + 손호현 참고 C01·C02).

검증 방법(스크립트로 한 것 — 모두 통과):
1. 원문 쪽 텍스트를 순서대로 이어 붙여 150개 블록이 덮는지 대조 → 블록 밖에 남는 글은 머리말·학습부 멘트·교수 칸 제목·'수고하셨습니다'뿐(문항 줄 0).
2. 150블록 전부 사이트 카드에 연결됨: 출처 71 + '다른 판본' 79 = 150.
3. 카드 본문(문제 + JB 답) = 출처 블록 원문, 공백 제외 글자 비교 71/71 일치(Q46·Q60은 사이트 안내문 한 줄 덧붙인 것만 다름).
4. 카드의 '다른 판본' 원문 79개도 블록 원문과 글자 일치.
5. 배지 연도 = (모든 판 괄호 연도 ∪ 실린 연도 칸) 71/71 일치. 실리지 않은 해를 붙인 카드 0.

→ **JB 원문에 있는데 사이트에 없는 문항(A)은 0건.** 아래 B~F는 판단이 필요한 것(합칠지·링크·표기)과 JB 원문 자체의 공백이다.

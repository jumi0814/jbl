# FRONT_BRIEF — 앞면이 가장 최신 JB 판으로 바뀐 카드의 annot K·A·N 손질 (10-25c · 과목 하나 · annot.txt만)

사용자 10-25(원문): "모든 jb문제에 대해서 해당 문제가 기재된 가장 최신 jb판의 해설과 페이지를 인용해줬으면 좋겠어. … 이런식으로 답의 변화를 기재한건 좋지만, 이때 기준은 해설은 최신 jb판의 답이어야 하고, jb원본도 해당 문제가 수록된 가장 최신판이어야하고, 다만 이전 답이나 참고할 만한 내용을 아래 추가로 적어주면 되는거야!"

build4가 저절로: 카드 앞면(문제·JB 답안·'JB 원본 n쪽') = 그 문제가 실린 가장 최신 판(같은 판이면 가장 최근 해 칸) · 옛 답 = 답 바로 아래 '📜 이전 답'(접힘, 원문 그대로) · 문제 꼴이 바뀌었으면 문제 아래 '이전 출제 꼴'. 그래서 옛 앞면 기준으로 쓴 annot가 낡는다.

## 입력
- 메인이 만든 `work/_tmp/front_review_<SID>.md`(카드마다 새 앞면 글 · 옛 앞면 글 · 지금 annot 블록과 줄 번호) — 없으면 `JBL_FRONT_ONLY=1 .venv/bin/python tools/<sid>/build4.py` → `work/<SID>/front_auto.json`(`front[]`: id·auto·qsame·asim·new·old · `skip[]`)에서 `asim < 0.97`(답이 바뀜) 또는 `qsame == false`(문제 꼴이 바뀜)인 카드.
- "이미 front="인 카드는 빠르게 확인만, "자동"을 중심으로.

## 할 일(그 카드들만, tools/<sid>/annot.txt만)
1. `A:` 첫 줄 '정답 요지 — "…"'·'일치 — …'의 JB 답 인용 = **새 앞면 답 글 그대로**(공백만 정리). 강의자료 대조 부분은 새 답과 어긋날 때만 고침.
2. `K:` 🎯 요점 = **최신 답 먼저**. ✗ `답의 뼈대: <옛 답> / 최신 JB 답: <새 답>` → ✓ `답의 뼈대: <새 답> / 이전 판 답(<옛 판>판까지): <옛 답 한 마디>`. {r:}는 최신 답의 핵심어.
3. `N:` '26판: … 답을 채움(25판까지 …)' 꼴 → `JB 앞면 = <판> <칸> n번(가장 최신 판) · <옛 판>까지 답은 … — 답 아래 📜 이전 답`(새 답을 N에 다시 옮겨 적지 않음). 연도 근거(연도 줄·yrs=)는 바꾸지 않음.
4. 새 앞면의 보기 번호·순서·T/F 순서가 다르면 K·A·M의 정답 번호를 새 앞면에 맞춤.
5. 고칠 것이 없으면 그대로.
6. 자동 앞면이 **다른 문제**(합쳐진 묶음·변형·'n번 중복' 가리킴)면 고쳐 쓰지 말고 그 카드 `@ID | …` 머리에 `front=0`(자동 끔) + 보고.

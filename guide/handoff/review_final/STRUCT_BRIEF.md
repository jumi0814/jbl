# 이어지는 내용이 따로 떨어져 보이는 곳 — 구조만 정돈(과목 하나 담당, 10-08)

사용자(10-08 원문): "두번쨰 사진 보면 자가골 채취: 구내 symphysis·ramus·tuberosity * 구외 hip·rib·fibular·tibia 이런식으로 구내 파트랑 구외 파트가 줄바꿈이 되어있는데 실질적으로는 자가골채취라는 큰 틀안에 구내랑 구외로 나뉜건데 구외가 줄바꿈 되어있어서 다른 구분된 내용처럼 보인단 말이지. 그렇게 줄바꿈으로 인해 윗줄과 연결되는 내용인데 독립적으로 분리된 핵심 및 암기파트가 여럿 있는데, 구분점이나 글머리기호를 여러개 사용하던지, 줄바꿈이나 들여쓰기 탭 같은걸 적절히 활용하면서 비슷한 오류들이 있는 곳을 너가 모조리(모든 강의자료, 모든 jb문제 해설 등 모든 곳)에서 찾아서 너가 최적으로 효과적 효율적으로 가독성 좋게끔, 정돈되게끔 해줘! 내용은 절대 건드리지 말고 구조만 정돈해주면 되는거야."

## 렌더러가 이미 자동으로 하는 것(메인이 고침 — 원고를 고칠 필요 없음)
- ⚡ `M:` 한 줄에서 ' / '로 나뉜 조각: **첫 조각이 라벨(`X: …`)이고 뒤 조각에 라벨이 없으면** → 굵은 머리 `X:` + 들여 쓴 하위 목록(◦). 뒤 조각에 자기 라벨(`Y: …`)이 있으면 거기서 새 바깥 줄(•)이 시작하고, 그 뒤 라벨 없는 조각은 `Y` 아래로 들어감.
  - 예 `M: 자가골 채취: 구내 {r:…} / 구외 {r:…} / ramal bone…` → `• 자가골 채취:` 아래 `◦ 구내 …` `◦ 구외 …` `◦ ramal bone…`
- 본문 `-` 줄·🔑 `=` 줄도 같음(첫 조각만 라벨 → 머리 + 들여 쓴 목록).
  - 함정: 하위 조각에 콜론이 있으면(`구외: …`) 새 바깥 •가 됨 → 합칠 때 그 콜론은 빼도 됨(struct_diff는 콜론을 구조 기호로 봄). 머리 라벨이 MLAB 꼴이 아니면(라벨 안 `=`·`→`·`/`·따옴표, 32자 넘음) 묶이지 않음 → render_line으로 확인하고, 안 되면 보고.
  - annot 190자 넘는 줄(astruct)은 첫 조각 라벨이 그 줄 모든 조각의 머리가 됨(뒤 라벨이 있어도 새 바깥 줄이 아님) → 라벨이 다른 내용은 다른 K:/A:/M: 줄로(2번 '떼기').
- 줄간격 3층(서로 다른 ⚡ 줄 8px > 같은 줄 조각 3px > 안쪽 번호·하위 1~2px)은 CSS.

## 맡은 일 — 렌더러가 못 잡는 것을 원고 구조로
대상: 맡은 과목 `tools/<sid>/lec_*.txt`(모든 줄 종류) · `annot.txt`(K: 🎯 요점 · A: 대조 · 주변부 줄) · `tables.txt` · `pred.txt`.
화면 덤프 `work/review_breaks2/<SID>_lec.md`(정리본 학습·정리표·강의 비교표) · `<SID>_jb.md`(JB 카드 해설·🎯·대조·주변부·예상·과목 비교표)를 처음부터 끝까지 읽고, **위아래로 이어지는 내용인데 화면에서 따로 떨어진(같은 층 • 로 나란한) 곳**과 **반대로 다른 내용이 한 머리 아래 잘못 묶인 곳**을 모두 찾는다. ⚑ 표시가 없는 덩어리도 다 본다.

고치는 방법(구조만):
1. **다음 줄이 앞 줄의 이어짐** → 두 줄을 한 줄로 합침(앞 줄 머리 그대로, ' / '로 이음). 예 `M: 자가골 채취: 구내 X` + `M: 구외 Y` → `M: 자가골 채취: 구내 X / 구외 Y`. 같은 카드·같은 종류 줄끼리만. 본문 `-`는 `- 머리:` + `  - 하위` 줄(RULES 4)로 해도 됨 — 하위 조각이 길면(60자↑) 이쪽.
2. **한 줄 안에서 조각이 엉뚱한 머리 아래** → 같은 줄 안에서 조각 순서를 옮겨 제 머리 뒤로(예 `고령화: A / 25 자료: B / C(고령화 이야기)` → `고령화: A / C / 25 자료: B`) 또는 그 조각을 따로 한 줄로 뗌.
3. **한 사실이 ' / '에 찢김**(뒤 조각이 앞 문장 중간·'→'·조사로 이어짐) → ' / ' 대신 ' · ' 또는 붙여 씀. 반대로 ' · '로 붙은 서로 다른 사실이 한 줄에 길게 늘어서면 ' / '.
4. **머리 없이 나란한 하위 항목**(예 `구내 X / 구외 Y`만 있고 앞 줄이 머리) → 1번처럼 머리 줄과 합침. 머리 낱말이 원고에 없으면 새로 만들지 않음(그대로 둠 — 보고에 적음).
5. 번호 나열(①②③)이 두 줄로 갈라진 것(앞 줄 ①②, 다음 줄 ③④) → 한 줄로.

- **낱말·글자 바꾸기/빼기/더하기 금지**(라벨·머리 낱말 새로 만들기도 금지) — 검사 `tools/struct_diff.py`가 띄어쓰기·구분 기호(/ · • ①~⑳ :)·줄 머리·줄 나눔·조각 순서 말고 글자가 하나라도 다르면 ✗.

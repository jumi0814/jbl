## 찾아서 고칠 것 (이것만)
1. **표에 들어갈 값을 줄글로 늘어놓은 줄** — '같은 표의 …칸', 'Table n의 … 행', 'A +·+++ / B ++·+ / C …', 'A: x, B: y, C: z'처럼 셋 이상(또는 둘이라도 속성 여러 개)을 같은 기준으로 견주는 `-`·`U:`·`P:` 줄.
   - 바로 위·아래(같은 카드)에 같은 대상의 표가 있으면 → **그 표에 열·행을 덧붙이고** 줄은 지움(기존 칸 글자는 그대로 두고 칸만 덧붙이는 쪽 우선).
   - 표가 없으면 → 그 자리에 작은 표를 새로 만들고 줄은 지움(머리 = 비교 기준, 행 = 대상).
2. ~~①②③ 나열 나누기~~ **하지 않음**(10-04 정정 — 화면 lecparse.split_enum이 ①②③ 3개 이상 줄을 자동으로 목록으로 나눔). 옛 지시: **①②③…를 한 `-` 줄에 몰아 쓴 나열**(항목이 셋 이상이거나 줄이 길어 한눈에 안 들어옴) → 한 줄에 하나씩 `-` 로 나눔. 글자는 그대로(나누기만).
3. **같은 내용이 표와 줄글에 두 번** 있으면 표 쪽만 남김(줄글에만 있는 덧말은 표 칸 '비고' 등으로 옮김).
4. 줄글로 길게 '…는 …이고, …는 …이며, …는 …' 식 3개 이상 비교 → 표.
- 이미 읽기 쉬운 곳(짧은 나열, 둘 비교 한 줄, ⚡ M: 암기 줄, ⭐ E: 줄, 카드 머리·`>`·`=` 줄, @MAP·@G·@TIP, `!` 머리말)은 **건드리지 않는다.** E: 줄 안의 JB 원문 인용은 절대 바꾸지 않음.

## 지킬 것
- 내용은 원고·강의자료에서만 — 표 칸 값은 지울 줄의 값 그대로, 헷갈리면 쪽 이미지(`work/<SID>/mat/<파일>/i/` · 강의 키 ↔ 파일 `work/<SID>/review/materials.md`)를 Read로 확인. 새 사실 금지 · 자료에 없는 약어 금지.
- `{r:…}` 빨간 핵심어·`==…==`·`**…**` 표시는 옮긴 칸에서도 유지. 쪽 번호 `(p.27)` 같은 출처는 표 머리줄 앞 `-` 한 줄이나 '비고' 칸에 남김.
- 사용자 표시 보존: 카드 나누기·합치기·제목·순서 바꾸기 금지, 카드 머리줄 그대로. 고친 줄 수는 꼭 필요한 만큼만.
- 표는 화면 폭을 생각해 열 7개 이하(넘으면 표 두 개로 나누거나 행·열 바꿈).

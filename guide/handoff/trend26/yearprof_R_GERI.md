# R_GERI — 노인치과학 출제 연도별 출제 교수 (10-16 · YEARPROF_BRIEF)

- 고친 파일: `tools/geri/subject.py` 하나. 맨 끝에 `YEAR_PROF`(강의 7개)와 `YEAR_PROF_Q`(문항 1개)를 덧붙였음. 빌드와 커밋은 하지 않았음.
- 검사: `.venv/bin/python -c "import sys;sys.path[:0]=['tools/geri','tools'];import subject as S;print(len(S.YEAR_PROF), len(getattr(S,'YEAR_PROF_Q',{})))"` 결과 `7 1`, 오류 없음.
  - 교수 이름은 모두 PROFS·PROF_LEC에 있는 글자 그대로임.
  - 강의 키는 모두 LECMAP 키(HARD·OHQ·ENDO·BLE·SAL·PAIN·PSY)임.
- 판과 시험 해의 대응: 26판 = 2025~2022 칸(연도 기준), 25판 = 2024~2022 칸, 24판 = 2023~2021 칸(학번 +2), 23판 = 2022~2020 칸(학번 +2).
- GERI의 `q['prof']`는 JB 블록 교수 머리(`[○○○ 교수님]`)에서 옴(assemble.py `prof0`). 그래서 대부분은 이미 맞고, 실제로 화면이 바뀌는 칸은 아래 1절뿐임.

## 3. 사용자 확인 필요
1. **PSY P01·P02의 2018 이전 7개 해가 지금 화면에 '박지은'으로 보임.**
   - 19학번 멘트에 따르면 박지은 교수님은 2020부터 맡았고, 바로 앞 담당은 **이동영** 교수님임. 그래서 이 해들은 박지은 출제가 아닐 가능성이 큼.
   - 2018 이전이 모두 이동영 교수님인지는 근거가 없음. 이동영은 PROFS에도 없는 이름이라 적지 않았음.
   - 고를 수 있는 길:
     - (a) 그대로 둠. 빈 해는 박지은으로 보임.
     - (b) `YEAR_PROF['PSY']`에 2018 이전을 '이동영'으로 넣음. 멘트는 바로 앞 담당만 말하므로 일부는 추측이 됨.
     - (c) 연도별 칩에 '미상'처럼 따로 표시함. 이건 build4 쪽 일임.
   - 26판 멘트 "박지은 교수님은 21 년도 이전에 들어오셨으므로"는 2020~2021과 맞음.
2. **2019(HARD·BLE·SAL)는 멘트 해석에 기댐.**
   - 20학번 멘트(2022 JB) "이 강의를 제외하고 최근 3년 동안 강의하신 교수님은 모두 동일 … 20년도(18학번)때에는 이재일 교수님이 …"에서 "최근 3년"을 2019~2021로 읽었음.
   - 이렇게 읽은 까닭:
     - "강의하신"이 과거형이고, 2022 수업은 "강의 예정"이었음.
     - 3년 칸 JB(23판 = 2020~2022)와 같은 꼴임.
   - 2020~2022로 읽으면 2019는 근거가 없어짐. 그때 2019를 빼면 Y01 2019는 '유연지'(`q['prof']`)로 보임. 유연지 교수님은 2023부터라 이건 틀린 표시임.
   - BLE·SAL은 2019를 빼도 화면은 같음(금기연·고홍섭).
3. **BLE 2023 = 유연지.**
   - 23판 p.2 수업 표(2023 계획)에는 "231012(예정) 노인치아의 미백 … 금기연"으로 되어 있음.
   - 실제 출제는 유연지 교수님임. 세 판(24·25·26)의 칸 메모가 그렇게 적고 있음.
   - 강의 단위로 2023 = 유연지로 적었음. 문항은 K02 하나뿐임.
4. **SAL·ENDO의 2018 이전 해**(G04 2009~2017 · G11 2018 · E03 2018)는 근거가 없어 뺐음. 화면에는 지금 교수(고홍섭·이우철)로 보임. 실제로도 같을 수 있지만 JB에 교수 근거는 없음.
5. H16(26판 2025 칸 한동헌 5번 "중복복원이기에 올해 강조하신 파트 예상문제")은 학습부 예상문제이고 실제 시험 문항이 아님. 칸이 2025 한동헌이라 한동헌으로 둠.

## 4. 참고 — 이번 일 범위 밖에서 본 것(고치지 않음)
- 24판 p.8 2023 칸 `[장지희 교수님]` **20번**("Nonverbal pain indicator에는 facial expression, [ 1 ] …")이 `parse_geri.py`에서 블록으로 잡히지 않음.

  - J01의 2023 배지는 괄호 "(22,23,24)"로 유지됨.
  - 대장(LEDGER)에도 이 블록이 없음.

2. 화면이 실제로 바뀌는 칸: Y01 22~19 유연지 → 백승호 · C01~C04 2023(+C02·C03 22, C04 21) 한동헌 → 조현재 · K02 2023 금기연 → 유연지. 나머지는 지금 교수와 같음.
3. 근거는 4개 판의 연도 칸 교수 머리와 칸 메모, 수업 표(2023·2024·2025), 학습부 멘트(19·20·21·22학번)임.
4. 2018 이전(E03·G04·G11·P01·P02)은 근거가 없어 뺐음. 2019는 20학번 멘트 "최근 3년 … 모두 동일"을 2019~2021로 읽어 넣었음.
5. 확인 필요 1순위: P01·P02 2018 이전 7개 해가 '박지은'으로 보이지만, 19학번 멘트상 박지은 교수님은 2020부터였고 앞 담당은 이동영 교수님임.

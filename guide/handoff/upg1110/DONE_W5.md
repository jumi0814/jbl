### 3 C2 넘버링 복습 평가 지움·바꿈 — 고침(num.js markSet·hNorm·hLive·rNorm·rLast·rFix · shell.html mergeData num.r 가지)

- 처음 한 번 중복 정리(`rFix`): 과목 복습을 열 때 '같은 회차 두 줄'이 있으면 자동 백업('넘버링 복습 평가 중복 정리 전')을 남긴 뒤에만 저장소에 고쳐 씀(백업 실패 = 화면에서만 한 줄로 보고 저장소는 그대로).

### 3 E3·E4 GitHub 403/429·Gist 목록 — 고침(shell.html `gh`·syncTick catch·syncConnect·`syncList`·`SYNC_PGMAX`)
- `gh`: 403·429면 `x-ratelimit-remaining`·`x-ratelimit-reset`·`retry-after`·본문 글을 읽어 `e.kind` = 'limit'(남은 0 · retry-after 있음 · 429 · 본문 rate limit/abuse/secondary) 또는 'perm'(그 밖의 403 = 토큰에 Gist 권한 없음) · `e.until` = 언제 다시.
- 요청 한도: 글 'GitHub 요청 한도 — 14:32쯤 다시'(때를 모르면 '잠시 뒤 다시') · 풀리는 때까지 쉼(`SYNC.back` — 옛: retry-after 없으면 1분마다 다시 · 상한 65분).
- 권한 없음: 글 '토큰에 Gist 권한이 없어요 — gist 권한이 있는 토큰으로 다시 연결해 주세요' + 오류 알림 한 번 · **저절로 되풀이하지 않음**(`SYNC.perm` — 새 토큰 연결·[지금 동기화]·새로고침 때만 다시 · 성공하면 풀림).
- 연결할 때의 403도 한도면 'GitHub 요청 한도 — 잠시 뒤 다시 해 주세요'(옛: 늘 '토큰에 gist 권한이 없어요').
- E4 `syncList`: 짧은 쪽이 나올 때까지(옛 10쪽) · 상한 30쪽 — 상한에 닿으면 오류 알림 한 번 '동기화: GitHub Gist가 3,000개를 넘어 일부만 확인했어요 — GitHub에서 오래된 Gist를 정리해 주세요'.

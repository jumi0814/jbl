# JBL 전면 점검·개선 — 4Q 자료가 오기 전에 (11-10)

## Context
사용자 11-10: "자료를 주기 전에 … 탭의 연동, 자료 정리, 넘버링 문제, 예상문제, 각종 기능, 공부시간 계산, 하이라이트 등등 … 내가 언급하지 않은 것들 다 포함해서 … 가장 최적으로 효과적으로 업데이트".

그래서 세 갈래로 전체를 읽기 전용 점검했다(코드 2건 + 피드백 기록 350줄 전체). 결과:
- **기록을 잃거나 잘못 세는 것 4건**(공부 시간이 잠든 동안에도 최대 12시간 들어감 · 그림이 한 번 실패하면 다시 안 받음 · 두 쿼터가 저장 공간을 나눠 써 4Q에서 정리할 길이 없음 · 넘버링 복습 채점이 기기 사이에서 되살아남).
- **연동·이동 20여 건**(↩ 가 안 생기거나 자리를 잃는 곳, 검색 '더 보기'가 접힘, 빈 화면으로 가는 주소 등) + **4Q 빈 과목 10개의 어색한 화면**("기출을 다 맞혔어요" 등).
- **렉**(무거운 탭 0.4~1.1초 · 그림 메모리 129 → 254MB · 표 맞춤을 열 때마다 다시 함) — 11-04 "렉 절대 안 생기게끔".
- **4Q 내용 규칙의 빈틈**(적중 분석에서 배운 것 20여 줄이 담당 지시문에 안 옮겨짐 · '상' 비율 규칙이 서로 충돌 · 스킬 문서가 옛 배치를 가리킴).
- 피드백에서 3번 이상 반복된 불만: 줄바꿈(12번) · JB 해설 가독성 · 공부 시계 · 형광펜 · 동기화 · 렉 · "같은 지시 또 하게 하지 마".

사용자 답(11-10): 잠든 시간 = **자동으로 빼고 알림**(되돌리기 가능) · 새 기능 = 넣지 않음("시험직전모드는 필요없어 이것만 제외해줘!" — 고치는 일만).

목표: 4Q 자료가 들어오는 날, 허브는 기록이 안전하고 빠르며, 담당 지시문은 3Q에서 배운 것을 전부 담고 있게 한다. 묶음마다 따로 검사·배포(중간 배포).

### W3. 4Q 그림을 파일로(배포 2 — **첫 4Q 그림을 만들기 전에**)
- 왜 지금: 4Q는 아직 그림 0장 → 옮길 것이 없음. 나중에 바꾸면 그림 전부를 다시 올려 저장소가 약 300MB 늘어남.
- `build4.py`: `tools/quarters.json` `4q.img = "files"`일 때 `docs/packs/img/<SID>/<KEY>-<쪽>.<해시8>.webp`(화질·폭은 지금 그대로 · JB 원본 쪽은 JPEG 그대로) + 팩에 목록 `imgf` · `tools/<sid>/img_lock.json`(원본이 같으면 다시 만들지 않음) · 지난 판 파일 한 세대 남김(옛 팩을 든 기기 404 방지). 3Q는 키가 없어 지금 묶음 방식 그대로.
- 허브: 그림 주소 한 곳에서 정함(`IMGS` → `imgf` 주소 → 묶음) — `fillThumbs`·`openImg`·`host.img`(넘버링) · 파일이 없으면 한 번 다시 받고 같은 크기 자리 표시 + [다시] · 인쇄 전 미리 받기. 묶음 방식(3Q)은 강의를 떠나면 메모리에서 비움(최근 2개만).
- 효과: 첫 그림 2~4초 → 그림 한 장(약 50KB)만 · 메모리 증가 없음 · 그림 하나 바꿔도 5~8MB 묶음을 다시 올리지 않음.
- 검사: `verify.py`·`check_links.py`(목록의 파일이 다 있음) · `q_img`(시험용 사이트에서 한 과목을 파일 방식으로 바꿔) · `q_perf` 예산을 파일 기준으로.

### W4. 공부 시간(배포 3)
- **잠든 시간**(사용자 선택 = 자동으로 빼고 알림): 틱 사이가 90초 넘게 벌어지면 잠든 것으로 봄(`tstate.at` + `T.tk`).
  - 마지막 입력 뒤 **90분(되묻기 기준) 안**이면 지금처럼 셈 — 화면이 잠긴 채 책으로 공부하는 경우.
  - **그보다 길면** 마지막 입력 1분 뒤에서 끊고, 다시 열었을 때 "잠든 n시간 n분은 뺐어요 · 되돌리기"(되돌리기 = 그 시간을 다시 넣음). 12시간 상한 검사보다 먼저(`trTick`) · `sessFlush`가 간격을 먼저 기록하지 않게 · 시작 때(`boot`)도 같은 길 · 시계가 부푼 숫자를 잠깐도 안 보이게(`sessLiveFor`·`trSessMs`·`trFocusMs`).
  - 되묻기 '끄기'로 둔 경우는 지금 그대로.
- 시계를 뒤로 돌리면 자동 측정이 멈추던 것(`tFlush`) · 닫힌 표시 `cls`가 남아 멀쩡한 세션을 끝내던 것(`trTake`) · 시간 고침 기록 `tedit`가 끝없이 늘며 3분마다 동기화되던 것(같은 날·과목 줄임은 한 줄로 누적) · 3Q와 4Q 시계가 동시에 도는 것(쿼터 공용 채널) · 4Q 첫 실행 때 시계·자동 넘김 설정(`tauto`·`tgoal`·`sessAsk` 등)도 이어받기(`qimport2` — 없는 값만).
- 새 테스트 `q_timer`(가짜 시계: 100분 잠듦·8시간 잠듦·12시간·시계 뒤로) · 회귀 `ux3_timer`·`ux3_rest`·`ux3_fixes`·`ux3_tedit`·`ux5_sess`·`ux4g_A`.

### W5. 기록 — 저장·동기화·백업·넘버링·형광펜(배포 4)
- 저장 공간: 4Q 경고에 "3쿼터 기록 n MB — 3Q 허브에서 정리" 링크 · 꽉 찼을 때 밀린 쓰기를 14일 뒤 버리던 것 없앰(`lqReplay`) + 띠에 개수 표시.

- 형광펜: 글이 바뀐 뒤 후보가 하나뿐이면 문맥 확인 없이 엉뚱한 곳에 붙던 것 → 문맥이 안 맞으면 '위치 잃음' 목록으로(`pick`) · ★ 카드 수가 없어진 카드를 세던 것(`migrateAids`에 `cbm`·`lrd`).
- 새 테스트 `q_store`·`q_backup` · `q_sync` 확장 · 회귀 `ux_sync*`·`ux15_storage`·`ux12_numrev`·`ux2_jblock`·`kt*`·`ux22_markbridge`.

## What is already solid (measured, nothing to fix)

- **Errors.** I crawled 411 screens at each viewport: every subject doc, plus every lecture × every tab. Results: 0 pageerror, 0 console error/warning, 0 HTTP ≥400, 0 failed requests, 0 broken `<img>` among loaded ones. No `undefined`, `NaN` or `[object Object]` text, and no horizontal page scroll.
- **Counts.** Menu and tab counts (JB, 예상, N제, 비교표, lecture 기출/예상/비교표) match the rendered cards: 0 mismatches.
- **↩ stack.** A chain of 7 chip hops (JB → 📖 → peek "JB에서 풀기" → 예상 → 📖 → peek → N제 → 📖) capped at 5 entries. Pressing ↩ five times walked back in exact order.
- **Reading position.** Tab switch and browser back/forward restore the same card with the same offset (0–2 px) at Y = 3000 and 7000, on learn, jb, pred, _final and _jb. Hub "이어서" lands on the exact card.
- **Keeping the screen.** Subject switch keeps the screen (JB → JB, lecture tab → same tab, falling back to 학습). Switching lecture from the menu keeps the tab.
- **Search.** Esc, ✕ and browser back all return to the exact reading position.
- **Stress.** 40 random `openDoc` calls 40 ms apart, then 10 fast backs: no errors, and the state stays consistent.
- **Numbering.** Importing all 355 PHARM items renders in 0.77 s. Reopening takes 141 ms (one 92 ms long task).
- **Small things.** Ctrl+K opens in 13–42 ms. Scrolling stays at 60 fps (p95 17 ms) on all long pages.

## Checked but not counted as bugs

- On phone, the tool bar scrolls sideways (555 of 375 px) by design. The ↩ pill (722–766) sits above the bar (782–838) with no overlap, and on desktop the pill and bar don't overlap either.
- When the phone app bar is hidden, Playwright's own scroll-into-view made the search tap look like a 1,400 px jump. A real tap after revealing the bar keeps the position, so I discarded it as a test artifact.
- One-at-a-time mode cycles "답 보기 → 해설 더 ▾ → 답 접기 ▲" (`JB.bar`). List cards cycle "답 보기 ↔ 답 접기 ▲" with a separate [해설 더 ▾] inside the answer, as `togLabel` (3910) intends.
- The hub "3학년 3쿼터" label is now driven by `tools/quarters.json` (parent commit 91255f7).

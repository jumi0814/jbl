# 로컬(맥 — 강의자료·JB 원본이 있는 곳)에서 해야 하는 일

클라우드 세션에서 발견했지만 원본이 없어 못 한 일을 여기에 적는다(무엇을·왜·어느 파일). 맥 세션은 이 목록을 처리한 뒤 `sh tools/build_all.sh` → 검증 → 배포.

- **trend.py·build4.py — '짤 비율 n%'를 개수로** (사용자 09-29 '퍼센트 필요 없어'). 지금은 허브(shell `trendNoPct`)가 과목 홈 교수별 출제 경향 표·공부 순서 문구만 화면에 낼 때 바꿈. 팩 원문(`trends` 표의 '짤 비율' 열·tr title·공부 순서 guide '짤 비율 평균 n%'·강의 틀 '출제 경향' 줄의 '짤 비율 추이 20년 100% → …')을 짤 수/문항 수로 내도록 고치고 다시 빌드. 추이 줄은 해마다 '짤 j/n'으로.
- **build4.py — 옛 이름 문구** (ux4f B31·E98): 학습 필터 '안 읽은 것만' → '안 본 카드만', 정렬 '몰라요·안 읽은 것 먼저' → '몰라요·✓ 안 한 것 먼저', 정리표 주제 '2회↑' → '2회↑만'. 지금은 허브(`rvRelabel`·mount의 rep2 줄)가 화면에서만 바꿈 — 팩도 같은 말로 내면 그 두 줄은 아무 일도 안 함(지워도 됨).

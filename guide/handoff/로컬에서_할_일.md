# 로컬(맥 — 강의자료·JB 원본이 있는 곳)에서 해야 하는 일

> **10-03 갱신**: 아래 목록 중 trend·build4 %·옛 문구, 정리본 최종 검토 반영 빌드, '맥에서 확인할 것' 146건, ESTH 새 과목(원고·검토 2회차·중간 배포)은 **끝났다**. 남은 것 = 사용자 결정 43건(제안 절)·판단 불가 7건(review_final/M_<SID>.md). 10-03부터 클라우드도 작업용 추출본(`sh tools/cloud_materials.sh`)으로 자료 대조·전체 빌드를 하므로, 이 문서에는 **새 PDF 추출이 필요한 일**(26년도 새 자료·더 과거 자료 반영)만 적는다.

클라우드 세션에서 발견했지만 원본이 없어 못 한 일을 여기에 적는다(무엇을·왜·어느 파일). 맥 세션은 이 목록을 처리한 뒤 `sh tools/build_all.sh` → 검증 → 배포.

- **trend.py·build4.py — '짤 비율 n%'를 개수로** (사용자 09-29 '퍼센트 필요 없어'). 지금은 허브(shell `trendNoPct`)가 과목 홈 교수별 출제 경향 표·공부 순서 문구만 화면에 낼 때 바꿈. 팩 원문(`trends` 표의 '짤 비율' 열·tr title·공부 순서 guide '짤 비율 평균 n%'·강의 틀 '출제 경향' 줄의 '짤 비율 추이 20년 100% → …')을 짤 수/문항 수로 내도록 고치고 다시 빌드. 추이 줄은 해마다 '짤 j/n'으로.
- **build4.py — 옛 이름 문구** (ux4f B31·E98): 학습 필터 '안 읽은 것만' → '안 본 카드만', 정렬 '몰라요·안 읽은 것 먼저' → '몰라요·✓ 안 한 것 먼저', 정리표 주제 '2회↑' → '2회↑만'. 지금은 허브(`rvRelabel`·mount의 rep2 줄)가 화면에서만 바꿈 — 팩도 같은 말로 내면 그 두 줄은 아무 일도 안 함(지워도 됨).
- **정리본 최종 검토(클라우드 10-02) 반영 빌드** — 42강의 원고(tools/<sid>/lec_*.txt)를 고쳤다(⭐ 답을 JB 답 전문·원문 용어로, 빠진 나열 항목, 출제 형식·연도 태그, 빨강 과다 → 굵게, 한 줄 여러 사실 나누기 등 약 170건 — 사실을 새로 더하지 않음, 근거 = JB 답·원고 안). 클라우드에서 check_lec 6과목 ✗ 0·check_eyears(알려진 RX20 오탐 1건뿐) 확인. **맥에서 `sh tools/build_all.sh`로 팩에 반영**하고 verify·tests(특히 legacy_restore·kt_migrate — 글자가 바뀐 카드의 형광펜·빈칸 이관)를 볼 것.
- **'맥에서 확인할 것' 146건** — `guide/handoff/review_final/R_<SID>_<강의>.md`의 '맥에서 확인할 것' 절(슬라이드 철자·수치·필기 원문·그림 쪽 대조). 쪽 이미지(work/<SID>/lec)로 보고 원고를 고친 뒤 빌드.
- **사용자 결정이 필요한 제안 43건** — 같은 파일의 '제안' 절(같은 문항 ⭐가 여러 카드에 겹침, 국문 부제의 출제 이력 표기, @MAP 9단계, 카드 수가 많은 강의 합치기 등). 형광펜 위치가 바뀔 수 있어 클라우드에서는 손대지 않음.
- **[대기 1순위] ESTH(심미치과학) 새 과목** — 사용자 10-02: 모든 검증·배포가 끝난 뒤 '심미치과학 강의자료 정리본 작업'. 자료 넣는 곳(맥 저장소 — 커밋 안 됨, .gitignore): 강의자료 = `materials/심미치과학/`(26년도 우선, 없으면 25년도 — PDF 그대로), JB = `jb/`에 3개 판본(`2025 3Q 심미치과학 JB.pdf` · `2024 …` · `2023 …` 이름 그대로). 그다음 맥에서 Claude Code 세션을 열고 '심미치과학 작업해줘'(CLAUDE.md '과목 작업 절차' · /jbl-subject ESTH). 그 세션에서 위 정리본 반영 빌드와 함께 build_all.

강의자료·JB 원본은 **맥의 저장소 폴더에만** 있다(materials/·jb/ — 저작권 때문에 GitHub에 올리지 않음). 클라우드 세션은 그 파일에 닿을 수 없으므로, 아래 일은 맥에서 Claude Code를 열어 이어서 한다.

## 맥에서 시작하는 법
1. 터미널에서 저장소 폴더로 가서 최신으로 받기:
   ```
   cd ~/…/jbl            # 이 저장소를 받아 둔 폴더
   git fetch origin && git checkout main && git pull   # (배포 전이면 ux4-cloud-72p9dr)
   ```
2. 강의자료 확인: `materials/심미치과학/`(26년도 우선, 없으면 25년도 PDF) · `jb/`(심미치과학 JB 2023·2024·2025판).
3. Claude Code 실행 — 둘 중 하나:
   - 터미널: `claude remote-control` (이 폴더에서 실행 — 아이폰·웹 Claude Code 앱에서도 이어서 보고 지시할 수 있음) 또는 그냥 `claude`
   - Claude 데스크톱 앱에서 이 폴더를 열기
4. 첫 메시지로 아래 '시작 지시'를 그대로 붙여 넣는다.

# 교수 프로필 — `guide/prof/<교수>.md` (11-04 · RULES 14 c ①)

- 무엇: 교수 한 사람의 **출제 성향** — 과목·쿼터와 상관없이 한 파일(같은 교수가 여러 과목: 한정준 = OMS1·IMPL·ANAT · 명훈 = IMPL·ANAT·GERI · 이창하·서덕규 = CONS·ESTH …). 4Q TREND·예상문제·최종 N제의 형식·짤/탈·탈 출처 근거.
- 쓰지 않는 것: 답 사실·슬라이드 글(꼴·자리·비율만). 내용 근거는 늘 그 과목 강의자료·JB(RULES 0) — 다른 과목 내용을 빌리지 않음.
- 파일 이름 = **교수 이름 그대로**(`guide/prof/한정준.md` — subject.py `PROF_LEC`·`#LEC` 교수 칸과 같은 글자 · '교수'·띄어쓰기 붙이지 않음 · 한글 NFC로 저장(맥 NFD 주의)). 이름을 모르는 옛 출제자('이전 교수')는 프로필 없음 — 아는 교수 파일의 9절에 한 줄.
- 누가 쓰나: AGENTS **PROF**(만들기·이어 쓰기) · **HIT**(6·7절 — 2026 3Q 실제 출제·적중) · 메인(RULES 11에 넣은 '배운 것'을 8절에). 교수 하나 = 파일 하나 = 한 번에 한 담당(과목이 둘 이상인 교수의 HIT는 메인이 한 담당만 쓰게 정함).
- 언제 읽나: 4Q TREND(AGENTS T) **전** · PRED(P)·N제(FN·FNV) 담당 · 3Q 과목 예상을 다시 손볼 때.

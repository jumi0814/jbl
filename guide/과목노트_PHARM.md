## JB 특이사항
- 25판 = <주제> 칸 안에 [연도 – Pf.] 소칸, **연도마다 번호 재시작**, "N. 2024년 M번 중복" 포인터가 많음 → assemble이 자동으로 같은 문항에 연결
- 24판·23판은 주제·연도 구조 같으나 교수 표기 없음(주제로 추정). 24판은 지혈 뒤에 주제 헤더 없이 보톡스 <2023년>이 이어짐 → 연도가 다시 커지면 BT로 전환
- 23판 멘트 "괄호 숫자는 ’가 붙으면 연도, 없으면 학번"
- 정본은 **유사도 자동 매칭**(같은 주제, 줄기 정규화 ≥0.72)으로 25 → 24 → 23 순서로 만들어 155문항, 판본 간 연결 209
- 성호르몬(노상호)은 4Q 이전 → 제외
- 24년 우경미 신장투석 문항 3(PN05·06·07)은 논문 문장 → v=part

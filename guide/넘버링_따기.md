# 내 넘버링 (10-10 · 처음 이름 '넘버링 따기')

사용자 지시(피드백기록 10-10 '넘버링 따기 시스템 구현 최종 지시문')로 만든 1차 구현. **넘버링 복습은 아직 없음**(홈에 '추후 업데이트 예정'으로 비활성).
운영 반영(main 병합·배포)은 사용자의 명시적 최종 승인 뒤에만.

**운영 반영(10-10)**: 사용자 승인("작업 다 되면 진짜 jbl html에 해당 기능 그대로 업데이트") — 첨부 Word 2개는 참고용 예시라 사이트에서 뺌. 미리보기(claude.ai 아티팩트)는 앞으로 사용자가 따로 말할 때만 쓴다.

## 화면 (10-10 '내 넘버링' 개편 — 피드백기록 넘버링 3·4)
- 홈: 과목 표 위 **넘버링** 칸 — ① 내 넘버링(→ `#/_num/<과목>`) · ② 넘버링 복습(비활성 · 추후 업데이트 예정).
- 들어가면 **JBL 메뉴(#side)는 숨기고 넘버링 전용 사이드바**(body.v-num — 떠나면 JBL 메뉴 그대로): JBL 홈 · 접기(« — 아이콘 줄 56px, `num.cfg.side`에 기억 · Shift+M·☰도 이 메뉴) · 내 넘버링/넘버링 복습(추후) · 도구(새 문제·기존 문제 불러오기·Word 파일 가져오기) · ChatGPT·인쇄(내보내기·결과 가져오기·인쇄 · PDF) · 과목(접힌 목록) · **강의 바로 가기**(누르면 문서는 그대로 두고 그 강의 자리로 스크롤 · 지금 읽는 강의 표시) · 완성 진행률. 860px 아래는 서랍(위 ☰).
- 위 막대(스크롤해도 붙는 한 줄): (사이드바 접었을 때 '과목 › 강의' = 강의 바로 가기 메뉴) · 검색 · **필터**(누르면 패널: 제작 상태 미작성/작성 중/완성/⚠ 검토 · **강의만 보기**(필터) · 유형 · 출처 · 연도 · 정렬 · 모두 해제 — 적용 중 개수 배지) · 강의별/전체 목록 · 답안 가리기/스토리 가리기 · 선택(여러 개) · 저장 상태. 막대 아래 줄 = 적용 중 조건 칩(✕로 하나씩 풀기)·보이는 문제 수. 본문 폭 940px 아래면 보기·가리기·선택은 [보기] 단추 안으로.
- 문제 머리 한 줄: **표시 번호(지금 보이는 순서 1·2·3…, 정렬·필터 따라 다시)** + 문제 글 · 오른쪽 작은 태그 = 교수·출제 연도(24·23)만. 화면에서만 문제 글 앞머리의 원래 번호('1.')와 연도 태그와 똑같은 연도만 든 괄호('(23,24)')를 뺌(저장 글은 그대로 — '수정'을 누르면 원문 전체). JB 기출·유형·상태 칩·'문제' 라벨 없음 · 완성 = 번호가 초록 ✓ · 고친 작업본 = ✎(마우스를 올리면 설명) · '참고: 참고' 중복 정리.
- 그 아래 **왼쪽 답안 | 오른쪽 넘버링 스토리**(1 : 1.12 · 본문 폭 640px 아래면 위아래). 답안 가리기·스토리 가리기 = 연습·암기용(가린 칸을 누르면 그 문제 그 칸만 보임).
- 편집: 스토리 칸을 누르면 그 자리 편집 · 문제·답안은 '수정'(마우스를 올리면 보임 · ⋯ 메뉴에도) — 작업본만. **작은 떠 있는 도구 막대**(position:fixed — 본문을 밀지 않음 · 칸 오른쪽 위, 문제 칸은 오른쪽 아래 · 위 막대 아래로만 · 칸이 화면 밖이면 숨김): 굵게·밑줄·글자색·형광펜·번호·글머리표·⋯(기울임·서식 지우기·표 넣기/줄·칸 더하기·빼기·그림·실행 취소/다시)·완료. **취소선 없음**. 0.7초 쉬면 그 문제 키 하나만 저장, Esc·완료·바깥 누르기 = 편집 끝. 새 문제 대화창 칸도 같은 막대(완료 단추만 없음).
- ⋯ 메뉴: 완성 표시 · 문제 수정 · 답안 수정 · 출처·연도·태그·참고 · 위/아래로 · 다른 강의로 · 복사 · 마지막 수정 전으로 · 원본으로 · 목록에서 빼기(맨 아래 '뺀 문제'에서 다시 넣기).
- 확인·입력 창은 화면 안 대화창(`ask`) — 브라우저 confirm/prompt는 쓰지 않음.

## ChatGPT 주고받기(10-10 · 파일만 — AI 연결 없음)
흐름: (선택) → 사이드바·선택 막대 **ChatGPT로 내보내기** → .json 받기(많으면 30·50·100문제씩 나눠) → ChatGPT에 파일 + [안내문 복사] → ChatGPT가 돌려준 파일(또는 답 글 전체 붙여 넣기) → **ChatGPT 결과 가져오기** → 미리 보기에서 확인 → 고른 것·새 스토리만 적용.
- 내보내기 범위: 과목 전체 · 지금 보이는 문제(필터·검색) · 고른 문제 · 강의 / 제작 상태(기본 = 스토리 없는 문제만 · 고른 문제로 열면 모든 상태) / 이미 쓴 스토리 넣기(기본 끔 — 토큰 절약).
- 형식(v1): `{"format":"jbl-numbering","v":1,"sid","subject","batch","part":"1/3","n","rules":[…],"lecs":[{"lec":"강의 이름","items":[{"id","q","a","story","s0"}]}]}` — q·a = 저장된 글을 맨글로(글자 그대로 · 줄바꿈·번호 목록 '1.'/'•'·표 칸 ' | ' · 그림 [그림]) · id = 넘버링 문제 id(`jb:…`·`pr:…`·`u:…`·`w:…` — 번호·정렬과 무관) · s0 = 내보낼 때 저장된 스토리 HTML의 지문(FNV-1a, 없으면 '0') · 문제 한 줄씩.
- 가져오기(`aiParse` → `aiPlan` → `aiPreview` → `applyStories`): 코드 블록·앞뒤 설명 글이 섞여도 JSON만 골라 읽음 · format이 다르면·v가 더 크면·items가 없으면·5000개 넘으면 오류(아무것도 안 바뀜) · 파일 sid가 다른 과목이면 그 과목으로 옮겨서 맞춤.
  분류: **새 스토리**(지금 비어 있음 — 기본 선택) · **바꿈**(이미 있는 스토리, 내보낸 뒤 그대로 — 기본 보호) · **충돌**(지문이 없거나 다름 = 내보낸 뒤 JBL에서 고침/지움 — 기본 보호) · 변경 없음 · 빈 스토리 · 맞는 문제 없음(ID) · 파일 안 같은 ID 여러 번 · 문제 글 다름(q가 있으면 비교 — ID 엉킴 의심) · 목록에서 뺀 문제 · 형식 오류 → 앞 셋만 고를 수 있음. 바꿈·충돌은 '지금 스토리 | ChatGPT 스토리' 나란히 비교가 펼쳐진 채.
  - ChatGPT가 q(문제 글)를 돌려주지 않은 문제는 ID만으로 연결 — '새 스토리'여도 미리 고르지 않음(문제 글 없음 · 확인 필요). 내보낸 글(번호 '1.'·표 칸 ' | '·[그림]) 그대로 돌아오면 '변경 없음'(서식 그대로).
  적용: 넘버링 스토리만(`st`·`prev`·`u`) — 문제·답안·출처·연도 그대로 · 이미 있는 스토리를 바꾸면 확인 창(Enter는 포커스 단추 그대로 — '취소'에서 Enter = 취소) · 미리 보는 사이 이 창·다른 창에서 바뀐 문제(저장된 u가 더 새것)는 건너뜀 · 한 번에 쓰고 실패하면 모두 되돌림 · 허브 저장 실패 대기열(LSQ)·그 IndexedDB 비춤은 다 쓴 뒤에만 정리(`lqDrop` → `host.lqSync`) · 알림 '되돌리기'(같은 과목에서만) · 문제마다 ⋯ '마지막 수정 전으로'. ChatGPT 글의 `**굵게**`·`==형광펜==`은 서식으로.
- 편집 중인 문제를 다른 창에서 고치면: 지금 고치는 칸만 이 글로 저장하고 나머지 칸은 그 창의 글로 맞춤(`stale` → `reloadIt`). 대화창 칸의 서식 도구는 대화창 칸에만(뒤 문서 칸 아님) · 대화창은 칸에서 끌다 바깥에서 놓아도 안 닫힘 · 새 문제 창에 쓴 글이 있으면 닫기 전 확인.

## 인쇄 · PDF(10-10)
- 사이드바 '인쇄 · PDF'·선택 막대 '인쇄'·⌘/Ctrl P(내 넘버링 안에서) → 범위(과목 전체·지금 보이는 문제·고른 문제·강의) · 넣을 내용(문제+답안+스토리 / 문제+답안 / 문제만) · 배치(나란히/위아래) · 제작 상태 · 강의마다 새 쪽 → 브라우저 인쇄(PDF는 '대상 → PDF로 저장').
- `printRun`: 고른 문제만 `#nm-print`(body 바로 아래)에 따로 짜고 인쇄 CSS(`#nm-pcss` — A4·여백 12mm, 인쇄 때 나머지 화면 전부 숨김)를 그때만 넣었다가 afterprint에 치움 · 문제마다 쪽 안 나눔(break-inside:avoid) · 강의 머리 · 빈 스토리 칸은 손으로 쓸 자리.

## 5차 다듬기(10-10 · 피드백기록 넘버링 5)
- 편집 도구 막대 = 흰 반투명 미니(굵게·밑줄·글자색·⋯·✓) · ⋯ 안 = 형광펜 색 줄·번호·글머리표·기울임·서식 지우기·표(표 안이면 줄·칸 고치기, 밖이면 넣기)·그림·실행 취소/다시.
- 사이드바 순서 = 머리(⌂ JBL 홈 · 내 넘버링 · «) → 과목(접힌 목록) → 강의 바로 가기(접기·펼치기 — `num.cfg.ljc`) → ChatGPT · 인쇄 → 문제(새 문제·기존 문제 불러오기·Word) → 아래 진행률·넘버링 복습(추후)·[백업](허브 백업 창 `data-bkpop`). 접은 아이콘 줄 = 과목 칩(과목 메뉴)·강의 목록·도구 아이콘 · 위 막대 '과목 › 강의'도 과목 메뉴·강의 메뉴.
- 문제 아래 '참고:' 줄은 없앰(10-10 사용자) — 참고사항은 ⋯ '출처·연도·태그·참고'에서만.
- 기존 문제 불러오기 목록: 문제 글이나 [답안 보기]를 누르면 그 아래 답안(다시 누르면 접힘).
- 마지막 위치: 스크롤이 멈추고 0.9초 뒤 과목마다 `num.pos.<과목>`(화면 맨 위 문제 id·위치 — 한 점만 짚음) · 다시 열면 그 문제부터 + 알림 '맨 위로' · 거르기(상태·유형·출처·연도·칩 ✕·모두 해제)를 바꿔도 보던 문제(숨으면 바로 뒤 문제) 자리 그대로 · 검색은 결과 맨 위부터 · 오른쪽 아래 ↑ 맨 위로.
- 섞기: 전체 목록에서만 [섞기] → 화면 순서만 무작위(`S.shuf` id → 자리, 저장 안 함 — 문제 `o`·정렬 설정 그대로) · [다시 섞기] · [원래대로]·칩 ✕ · 거르기와 함께 · 강의별로 가거나 과목을 바꾸면 꺼짐 · 섞은 채 위/아래 옮기기는 막음 · 인쇄는 지금 화면 순서.
- 전체 점검(10-10 2차 배포): JB 불러오기 = 그림 문항 그림(`data-jbfig` 팩 그림 자리표) · 해설은 참고사항 · 첫 '답:' 글머리 뺌 · 미복원 자리표 문항은 묶어 넣기에서 뺌(골라 넣기만) · 유형 판정(서술·설명하고·모식도·n가지·한 줄 번호) · 창(`dlg`)을 열면 '이어서' 알림을 닫음(허브 `toastOff`) · 휴대폰 창 칸 폭 `minmax(0,1fr)` · 허브 홈 넘버링 칸 class `hnums`(과목 표 `.hnum`과 겹치던 것) · 회귀 `tools/tests/ux11_fix.py`.

## 넘버링 복습(10-11 · 피드백기록 넘버링 6)
- 들어가기: 허브 홈 ② · 넘버링 사이드바 위 '내 넘버링 ⇄ 넘버링 복습'(허브 왼쪽 메뉴에는 '내 넘버링'만 — 10-11 사용자 '어차피 내 넘버링으로 들어갈 수 있으니까' · 복습 중에도 그 칸이 표시됨)(같은 과목·같은 원본 — 다시 읽지 않음) · 주소 `#/_numr/<과목>`. 허브에서 들어오면 늘 **스크롤 복습**부터(새로고침·뒤로·화면 안 바꾸기는 마지막 방식 그대로).
- 원본 = 내 넘버링과 같은 `S.items`·`num.i.*` — 복습 화면은 **읽기 전용**(눌러도 편집 안 됨 · 가린 칸만 보임), '수정'을 누르면 내 넘버링과 **같은 편집기**(startEdit·도구 막대·서식·자동 저장 put) → 양쪽에 바로. 한 창에서 화면만 바꾸므로 사본이 생기지 않음(다른 창은 기존 storage 동기화).
- 스크롤 복습: 문제 → 정답 | 넘버링 스토리 2칸, '✍ 내 답안 쓰기' = 정답 | 스토리 | 내 답안 3칸 · 칸 경계(`.nm-rz`)를 끌면 모든 문제가 같은 너비(`#numv --wa·--ws`) · 두 번 누르면 처음대로 · 2칸·3칸 너비 따로 기억(`num.rcfg.w2·w3`) · 좁은 화면(본문 640 이하)은 위아래로.
  가리기 = 정답/스토리 '모두 가리기'(설정) + 문제마다 [가리기·보기] 또는 가린 칸 누르기(회차 `ov`에 — 새로고침·스크롤/카드 바꿔도 유지, '모두' 단추를 누르면 그 칸은 다시 전체를 따름).
  문제 아래 줄 = 작은 [모름|애매함|암기 완료](22px · 손가락 기기 28px) · 지난 평가(날짜) · 더 작은 '이력' · '내 넘버링에서 보기'(그 문제로 · 뒤로 = 복습).
- 카드 복습 화면(10-11 2차): 카드 아래 **한 줄** = [◀][뒤집기][▶] · [모름|애매함|암기 완료] · [+ 남은 하나] (28px — 스토리까지 펼쳐도 한 화면) · 카드 안 안내 글 없음(단추 title) · 위 막대 '✍ 내 답안 쓰기'로 오른쪽 답안 칸 켜기·끄기(`num.rcfg.cw`, 끄면 카드가 넓게 · W = 켜고 그 칸으로) · 켜면 카드 | 답안 경계(`.nm-crz`)를 끌어 카드 30~80%(`wc` · 두 번 누르면 56%) · 답안 칸에서 ⌘/Ctrl+Enter로 뒤집어도 그 칸에서 계속 쓰기.

## 넘버링 스토리 제작 Skill(10-11 · Claude Code 전용 · 피드백기록 '고품질 넘버링 제작 Skill')

- JBL 쪽은 고치지 않음 — 기존 가져오기(aiParse·aiPlan·applyStories)가 코드 블록째 붙여 넣기·id/q 확인·s0 충돌(내보낸 뒤 JBL에서 고친 스토리 = 충돌, 안 고름)·한 번에 적용·되돌리기를 이미 함.

- 도구가 지키는 것: 원본(source.json) 그대로 · 사용자 스토리가 있던 문제(story 또는 s0≠0) = keep(고치라고 한 id만 `--revise`) · 통과 저장은 괄호 키워드가 정답 원문에 있어야·G2 기록이 있어야 · 보류는 이유 필수·결과 밖 `hold.md` · 결과의 id·q·s0 원본 그대로(verify) · state.json 원자적 저장 · checkpoint 한 파일로 다른 세션에서 이어하기.

## 저장(허브와 같은 localStorage 이름 공간 `jblhub.v1.`)

- 레코드: `{id, k(kind), lec, q, a, st(스토리 HTML), note, tags[], yrs[](2025…), src[{t:'seed'|'jb'|'pred'|'user'|'word', s, id, lec, yrs, lab}], ref, q0/a0(JB·예상 원본 — 처음 고칠 때), done, del, o(순서), c(만든 때), u(고친 때), prev{f,h,at}(마지막 수정 전 한 칸), rv(검토 표시)·rvok}`.
  Word 기본 자료 문제는 바뀐 칸만 저장(원본은 seed 파일) — 원본과 같아지면 키를 지움.
- `num.x.<과목>` 과목 정보(내가 만든 강의 `ul`, 강의 이름 바꿈 `lt`, u) · `num.subj` 내가 만든 과목 · `num.cfg` 보기 설정 · `num.pos.<과목>` 마지막 위치.
- 백업 파일·자동 백업(dumpAll)에 그대로 들어감 · 합치기(mergeData)는 문제마다 `u`가 더 큰 것 · `bakSig`에 `num` → 넘버링을 고쳐도 자동 백업이 돈다.
- 상태: `done` → 완성 · 스토리 있음 → 작성 중 · 없음 → 미작성(완성은 사용자만 정함).

## Word 반영 규칙(docx.js)
- 글자는 Word 그대로 · 번호 목록의 번호(numbering.xml)도 글자로 넣음 · 서식은 굵게·기울임·밑줄·글자색·형광펜·위/아래 첨자·표(가로·세로 합침)·그림 · 그림 대체본(mc:Fallback)은 넣지 않음.
- 3칸 표(머리 줄 '문제 | 정답 | 암기법'): 칸 그대로. 암기법 칸의 회색 글 = 참고사항. 머리 줄 위 형광펜 범례(기출·수업시간 강조·과거기출) → 문제 형광펜 색으로 꼬리표.
- 2칸 표: 왼·오 첫 문단이 같은 줄 = 문제 줄(왼쪽 글로) · 그 뒤 줄 = 왼쪽 스토리(스토리 색 BF4E14) | 오른쪽 답. 왼쪽 검정 글·표·그림 = 문제(빈칸 표·보기·그림) · '(학습부:…)' = 참고사항 · 문제 줄 오른쪽에만 있는 그림 = 답 맨 앞.
- 한 칸짜리 줄 = 강의(머리) — '고홍섭_내분비, 임신' → 강의 '내분비, 임신'·교수 고홍섭 / '여기부터 BANK <Tooth Movement Biology>' → 강의 'Tooth Movement Biology'·BANK.
- 연도는 적힌 것만: 문제 글의 괄호 `(24,22)`·`(25탈)`·`(26출제예고,25,…)`(26은 '출제 예고' 꼬리표, 연도 아님)·`(24,과거)` · 줄머리 `25년도:` · `25 빈칸`(검토 표시). '(5가지)'·'(ADA criteria)'는 연도 아님.
- 기본 자료로 만들 때 칸이 어긋난 줄은 `seed_fix.json`에 이유와 함께(글자는 그대로, 칸만 옮김 — op `shift`·`years`).
- 검토 표시(⚠, 거르기 '⚠ 검토 필요'): 칸 어긋남 고침 · 왼/오 문제 글 다름 · 답 칸의 스토리 색 글씨(그대로 답에 둠) · 연도 표기 해석 · 문제 줄 오른쪽 그림 → 답. 사용자가 '확인했어요'를 누르면 사라짐.

## 기존 문제 불러오기
- 7과목 팩(`PACKS[s].cards` JB 기출 + `preds` 예상문제)에서 문제 글(.qtext/.pq)·답(.lines/.pre2)을 정리한 사본으로 넣음(원본은 그대로 · '원본 열기'로 JB 화면).
- 유형: 기존 자료에 유형 정보가 없어(예상문제 v/n = 짤 변형·미출제) 문제 글·보기·답 모양으로 판정 — 넘버링형(~가지·나열·답 3줄↑)·서술형·빈칸형·객관식(고르시오·옳은 것·보기 3개↑)·단답형. 판정은 완벽하지 않아 '전체 문제'로 직접 고를 수 있음.
- 중복: 같은 출처 = 이미 있음(건너뜀) · 문제 글이 같음(번호·연도 괄호 빼고) = 출처·연도만 연결 · 비슷함(75%↑) = 확인 창에서 사용자가 고름(기본 = 따로). 파일 가져오기는 문제·답이 모두 같을 때만 연결.
- 한꺼번에 넣을 때 기록을 먼저 다 만든 뒤 쓰고, 중간에 실패하면 이번에 쓴 키를 되돌림.

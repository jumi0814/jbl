## 3. 강의 정리본 — 사용자가 원하는 것 (원문)
- "개별 강의자료의 **전체적 정리 및 이해 + jb 문제 출제 내용 및 주변 범위 강조**" (← 반려: "오로지 핵심 요약 + jb 문제 언급 이 정도인 느낌")
- "정리본 젤 첫번째 탭에서 **쭉 스크롤하면서 내용이해하기 딱 좋은 총 정리본** … 윤혜정의 학습 정리 페이지와 전체정리표를 봐봐. 이 형식과 틀, 정돈된 정도와 강의내용 정리 + 중간중간 사진 및 분류, 내용 이해의 쉬움 정도와 가독성을 참고" → `reference/예시정리본_윤혜정_혈액질환.html`
- **가장 결정적인 지적**: "지금 정리본을 보면 드는 생각은 이건 그냥 **강의자료 및 필기를 그대로 갖다 붙인거고, 거기에 관련 jb 문제가 있으면 매치한 꼴**이야.. 내가 원하는건 강의자료 정리본을 보면서 관련 jb문제가 있으면 **이해+암기를 쉽게 하기 위한** 정리본 … 강의자료 정리본은 결국 **쑥쑥 넘기면서 내가 일단 대략적인 개념을 잡고, 또 읽으면서 디테일들을 잡고** 그러는 용도"
- "**필기는 내용 이해를 돕는 용도인거지 이게 절대 메인이 되면 안돼. 강의자료 위주의 내용**을 다루되 … 적절하게 그림 및 강의자료 캡처본 넣으면서!!"
- 승인: "강의자료 정리한 정도가 너무 좋아!" (구강외과1 카드형 재작성판) → 이후 모든 과목의 기준

```
### Cranial growth (p.7)
~ {r:80%} at birth, definitive size at {r:2.5-3 years} old
N: 이후 2.5-3세까지 계속 성장하므로 중요한 시기 → 두개유합이 나타나면 생후 6개월-1년 사이에 수술을 권함. (그래프: y축 두개골 외경 둘레, x축 나이 — 초기 급격한 성장)
### Fontanel closure (p.8)
- Anterior: {r:9-12 Ms} · Posterior: {r:3-6 Ms} {jb:Q02}
N: 완전히 fusion되는 것은 아니고 suture는 남아 밀접하게 연결된 정도 → closure 후에도 뼈 사이 gap을 통해 성장 지속. 3년 안에 급격히 성장하므로 …
```

## 5. 카드 작성 규칙 (구체)
1. **카드 = 의미 단위 주제 하나.** 슬라이드 1장=카드 1장이 아니다. 여러 쪽을 묶고, 한 쪽을 쪼개도 된다. 강의 하나에 대략 7~19장.
2. **> 한 줄 요지**: 이 카드를 한 문장으로(비유·대비 환영: "위에서 내려오는 cracked tooth vs 아래에서 올라오는 VRF").
3. **= 🔑 핵심**: 시험 직전에 이 줄만 봐도 되게 — 공식처럼 압축, 수치·이름은 {r:}.
4. **# 소제목**: 정의 / 분류 / 특징 / 진단 / 치료 / 예후처럼 **의미 단위**. 절대 "(p.7)" 식 쪽 순서 아님.
5. **- 항목**: 한 줄에 사실 하나. 영어 용어는 슬라이드 원문 그대로 + 괄호 한글 풀이. 나열은 ①②③.
6. **| 표**: 둘 이상을 나란히 비교할 때는 반드시 표(절대 vs 상대, Type 1~4, 증후군별 유전자, 재료별 장단점).
   - (10-04 사용자) **표에 들어갈 값을 줄글로 늘어놓지 않는다.** 바로 위·옆에 같은 대상의 표가 있으면 열·행을 덧붙여 표 안에 넣는다.
     ✗ `- 같은 표의 Eye(Topical)·Atropine antagonism 칸(p.27): ACh +·+++ / Methacholine +·+++ / Carbachol ++·+ / Bethanechol ++·+++.` · `- p.29 Table 9-1의 Muscarine 행: AChE −, cardiovascular ++, …`
     ✓ 위 Choline ester 표에 `Eye(Topical)`·`Atropine 길항` 열과 `Muscarine(치료에 안 씀)` 행을 덧붙이고 두 줄은 지움.
     같은 꼴: 'A: x / B: y / C: z'처럼 셋 이상을 같은 기준으로 견주는 한 줄 → 표. (①②③ 3개 이상 한 줄 나열은 화면이 '머리말 + 목록'으로 저절로 나누므로 원고를 쪼개지 않음 — 쪼개면 빈 머리 줄이 남고 내 표시 위치가 흔들림)
7. **E: ⭐ 시험포인트**: 해당 내용 바로 아래. "몇 년에 / 어떤 형식으로 / 무엇을 / 함정은". JB 답이 슬라이드와 다르면 여기 ⚠.
8. **P: 💬 교수님 강조**: 필기의 "시험문제", "외워라", 강조 페이지. **U: ✍ 이해**: 필기에서 이해를 돕는 한 줄만 — 문단 금지.
   - 본문·🔑·⚡·표·🎯의 필기에서만 나온 조각은 `{n:…}`로 앞에만 ✍(10-07 → 10-09 앞에만, RULES 9 — 구분 갈 때만·남발 금지·글자 불변 · 필기 뒤 강의 내용은 줄바꿈).
9. **F: 그림**: 그 내용을 설명하는 바로 아래. 캡션은 필기에 설명이 있을 때만(없으면 쪽 번호만), 캡션 안 쉼표 금지.
10. **M: ⚡ 암기 줄(10-05부터 카드당 보통 3~7줄 — 라벨·논리 순서·①②③, RULES.md 6절)**: 빈칸으로 가리고 떠올릴 수 있게 {r:}로. 번호 항목은 짧은 원문 풀 워딩·긴 문장은 핵심어 압축(10-07, RULES 6). 앞 줄과 이어지는 내용(구내/구외처럼 한 머리 아래 나뉜 것)은 한 줄에 ` / `로 — 화면에서 `• 머리:` 아래 ◦ 하위 목록(10-08, RULES 6).
   - 줄간격은 3층(서로 다른 줄 > 같은 줄 조각 > 안쪽 번호·하위) — 허브 CSS가 맞춤(10-08, QA 32).
11. **강의자료 전체를 다룬다** — 기출이 없는 부분도 카드로(주변부 확장·변형 대비). 수업에서 "넘어가심"인 증례·연구는 짧게 묶기.
12. 강의 첫 화면 @MAP은 강의 전체 흐름을 → 로 6~8단계.

## 6. JB 문제 쪽
- 카드 순서: 연도 배지 → 짤/탈 칩 → 교수(그 해 출제 교수 — 굵게 · 해마다 다르면 '교수 25·24 · 교수 22', 최근 해 먼저 — 10-16 RULES 13) → 📖 정리본 칩 → 대조 결과 → 문제 → JB 괄호·수록 위치 → 답·해설(JB 답안 원문 → 🔎 강의자료 대조 → 🧭 주변부 확장 → 📖 정리본 카드(🔑 핵심·⚡ 암기 3줄·이동) → 다른 판본 원문)
- 슬라이드 텍스트 추출이 깨진 자료(임영준처럼 폰트 매핑 오류)는 쪽 이미지를 직접 읽고 OCR로 보완하되, 본문 문장은 슬라이드 원문 그대로 옮긴다
- 대조 판정: 일치 / 부분 일치 / ⚠ 불일치 / 근거 없음 — 문장마다 [[강의키:쪽]] 출처
- **JB 해설 가독성(10-05 사용자 '인용이나 근거, 필기파트가 중구난방 … 슬라이드 원문 보는 버튼도 … 너무 크게' — 내용은 그대로, 구조만)**: annot.txt
  - `A:` 한 줄 = 근거 하나 — `A: <판정> — <위치> "<슬라이드 인용>" <설명>. [[키:쪽]]` → 화면: [판정 꼬리표] 위치 / 인용 상자(인용 안 ` / ` = 한 줄씩) / 설명 / 작은 '근거' 줄(강의명 한 번 + 쪽 링크).
  - `M:` 한 줄 = 한 종류, 라벨로 밝힘: `슬라이드 N:`·`앞 슬라이드 …:`(📄 같은·인접 슬라이드) · `26 필기:`·`필기(p.N):`(✍ 필기) · `변형 대비:`·`함정:`(🔁) — 화면이 이 순서의 소절로 묶음. 라벨 없는 줄은 앞 줄 종류를 이음. 슬라이드 인용과 필기를 한 줄에 섞지 않음.
  - `N:` = 연도·판본 메모만(`연도 — …`). 변형 대비·함정 문장은 M으로.
  - 검사: `tools/annot_diff.py <SID> --save` → 고친 뒤 `tools/annot_diff.py <SID>` 빠진 글자 0.
- **비교표·전체정리표(10-05 사용자 '정리표 및 비교표가 가장 최적으로 … 내용을 더할 순 있어도 덜어내진 말아줘')**: 견줄 축(행 = 대상·열 = 기준), 빽빽한 칸은 ` / `로 칸 안 줄바꿈 또는 새 열, 자료에 있는데 빠진 비교는 더함(근거 쪽), 기출 칸 {jb:}, 열 7개 이하. 기존 표 제목은 바꾸지 않음(표시 닻). 검사 `tools/text_diff.py tools/<sid>/tables.txt` 빠진 글자 0. 지침 `guide/handoff/review_final/TABLE_BRIEF.md`.

- 문항마다 🔎 대조(A:)를 직접 쓴다 — 슬라이드 문장 인용 + 문장마다 [[키:쪽]] + 판정. 자동 채움(7-3)은 예외 처리용
- 연도는 문항이 실린 칸 + 문항 첫머리 괄호 + **다른 판본에 실린 같은 문제의 괄호**까지 합친다. 괄호 변형 '(2019, 탈)'·'(24. 23)'·'(21’, 20’, 17’이전)'도 읽는다 → tools/check_years.py로 전수 확인
- 자료에 없는 약어 금지 → tools/check_abbr.py로 걸러 쪽 이미지까지 확인(그림 속 글자는 허용)
- 여러 작업자가 쓰면: 강의별 작성 → 다른 작업자가 사실 40개 이상 대조·수정(이번 42개 강의에서 2,848개 확인·436건 수정)

## 25 → 26 바뀐 곳 표시(10-09 사용자 — "25년도 자료에 비해 26년도 자료에서 변동사항 같은게 있으면 함께 표시 … 사라진 페이지 또는 특히 26년도 올해 추가된 페이지나 추가된 내용은 꼭!! 강조")
- 원고 `{u:…}` = 26에 새로 생기거나 바뀐 **슬라이드(자료) 원문** 내용(필기 아님 — 10-10 "필기 아님!! 슬라이드 원문 내용에서 새로 추가된 걸 말하는거임 … 모든 새로 추가된 필기가 26강조/new 26이 되는게 절대 아냐!!" · 26 수업 강조·시험 예고 필기 = `{e:{n:…}}` · 일반 26 필기 = 표시 없음(✍만)) → 화면 초록 **NEW 26** 배지 + 밑줄(글자 아님 — 형광펜·빈칸·플래시카드 그대로). 새 쪽이 통째로 새 묶음이면 `# {u:…}` 소제목만(아래 항목 왼쪽 초록 줄).
  - 예 ✓ `# {u:Post cementation 조합 — acidic monomer 기준 4가지(26 새 쪽 p.63)}` · `- 광조사 거리: {u:약 1 cm}(25: 1.5 cm) …` · `> {u:26 새 주제 — …}`(새 카드)
- 강의 머리 `@UPD` 줄 = 강의 틀 제목 줄의 접힌 초록 알약 '25 → 26 바뀐 점 펼치기 ▸'(누르면 펼침)(새 쪽 n · 바뀐 쪽 n · 빠진 25 쪽 n · 같은 쪽 · 26 수업 강조 · 교수 변경) + 26 새 내용 카드 바로가기(자동).
- 26 수업 강조·시험 예고는 `{e:…}`(보라 26 강조 — NEW 26과 글자·색·모양이 다름 · 25에도 강조했으면 `(25년도에도 강조함)`) · 26 새 강의는 `@UPD 26 새 강의 …` + 과목 홈 'NEW 26 강의' 칩 · 26 자료가 25 영어 PPT의 우리말판이면 우리말 메인 + (영어) 한 번 · 카드 목록 메뉴 ⭐ 옆 작은 NEW 26·26 강조(10-10).
- 빠진 25 내용은 지우지 않고 '(25 자료 — 26에서 빠짐)' → 회색 배지. 카드 머리 '🆕 26 바뀜' · 학습 화면 '🆕 26 바뀐 카드만' · 과목 홈 '🆕 26 바뀐 카드 n'.

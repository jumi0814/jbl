## 1. 이 시스템이 뭔가 (사용자 원문)
- "각 과목별 jb문제 풀기 및 해설과 이해, 내가 준 강의자료에서 어디서 출제된건지, 그리고 출제된 부분에서 관련된 추가 공부 및 복습을 할 수 있게끔 (이걸 jbl jb based learning이라고 할거야)"
- "jb문제를 풀면서 관련 강의자료내 부분을 공부하면서 이해하면서 풀 수 있고, 또 반대로 강의자료부터 시작해서 jb문제 출제 범위 및 출제경향 참고한, 다만 **강의자료를 다 다루는** 정리본을 먼저 보고 공부할 수도 있게끔" → **양방향**(JB→강의자료, 강의자료→JB)
- "jb 및 강의자료를 마스터하면 관련 비슷한 예상문제 및 해설까지"
- "jb 문제 자체는 … 하나하나 너무 중요하니까 **절대 문제 누락 없이**"

```
### Cranial growth (p.7)
~ {r:80%} at birth, definitive size at {r:2.5-3 years} old
N: 이후 2.5-3세까지 계속 성장하므로 중요한 시기 → 두개유합이 나타나면 생후 6개월-1년 사이에 수술을 권함. (그래프: y축 두개골 외경 둘레, x축 나이 — 초기 급격한 성장)
### Fontanel closure (p.8)
- Anterior: {r:9-12 Ms} · Posterior: {r:3-6 Ms} {jb:Q02}
N: 완전히 fusion되는 것은 아니고 suture는 남아 밀접하게 연결된 정도 → closure 후에도 뼈 사이 gap을 통해 성장 지속. 3년 안에 급격히 성장하므로 …

```
문제점: 소제목이 쪽 번호 순서, 필기(N:)가 문단째 들어가 본문을 차지, 핵심 한 줄·암기 줄이 없어 "쑥쑥 넘기며 틀 잡기"가 안 됨.

## 5. 카드 작성 규칙 (구체)
1. **카드 = 의미 단위 주제 하나.** 슬라이드 1장=카드 1장이 아니다. 여러 쪽을 묶고, 한 쪽을 쪼개도 된다. 강의 하나에 대략 7~19장.
2. **> 한 줄 요지**: 이 카드를 한 문장으로(비유·대비 환영: "위에서 내려오는 cracked tooth vs 아래에서 올라오는 VRF").
3. **= 🔑 핵심**: 시험 직전에 이 줄만 봐도 되게 — 공식처럼 압축, 수치·이름은 {r:}.
4. **# 소제목**: 정의 / 분류 / 특징 / 진단 / 치료 / 예후처럼 **의미 단위**. 절대 "(p.7)" 식 쪽 순서 아님.
5. **- 항목**: 한 줄에 사실 하나. 영어 용어는 슬라이드 원문 그대로 + 괄호 한글 풀이. 나열은 ①②③.
6. **| 표**: 둘 이상을 나란히 비교할 때는 반드시 표(절대 vs 상대, Type 1~4, 증후군별 유전자, 재료별 장단점).
7. **E: ⭐ 시험포인트**: 해당 내용 바로 아래. "몇 년에 / 어떤 형식으로 / 무엇을 / 함정은". JB 답이 슬라이드와 다르면 여기 ⚠.
8. **P: 💬 교수님 강조**: 필기의 "시험문제", "외워라", 강조 페이지. **U: ✍ 이해**: 필기에서 이해를 돕는 한 줄만 — 문단 금지.
9. **F: 그림**: 그 내용을 설명하는 바로 아래. 캡션은 필기에 설명이 있을 때만(없으면 쪽 번호만), 캡션 안 쉼표 금지.
10. **M: ⚡ 암기 줄 2~3개**: 빈칸으로 가리고 떠올릴 수 있게 {r:}로.
11. **강의자료 전체를 다룬다** — 기출이 없는 부분도 카드로(주변부 확장·변형 대비). 수업에서 "넘어가심"인 증례·연구는 짧게 묶기.
12. 강의 첫 화면 @MAP은 강의 전체 흐름을 → 로 6~8단계.

## 6. JB 문제 쪽
- 카드 순서: 연도 배지 → 짤/탈 칩 → 교수 → 📖 정리본 칩 → 대조 결과 → 문제 → JB 괄호·수록 위치 → 답·해설(JB 답안 원문 → 🔎 강의자료 대조 → 🧭 주변부 확장 → 📖 정리본 카드(🔑 핵심·⚡ 암기 3줄·이동) → 다른 판본 원문)
- 슬라이드 텍스트 추출이 깨진 자료(임영준처럼 폰트 매핑 오류)는 쪽 이미지를 직접 읽고 OCR로 보완하되, 본문 문장은 슬라이드 원문 그대로 옮긴다
- 대조 판정: 일치 / 부분 일치 / ⚠ 불일치 / 근거 없음 — 문장마다 [[강의키:쪽]] 출처
- 예상문제: 강의자료 문장으로만, "짤 변형"(기출이 걸린 카드의 다른 항목)과 "미출제"(기출 없는 카드)로 구분

## 7. 과거에 지적받아 고친 실수 (반복 금지)
1. 필사본형 정리본(위 4번 ✗)
2. 요약 + JB 언급만 있는 얇은 정리본
3. JB 답안 가독성(글자는 그대로, 줄바꿈만)
4. 판 연도("25판") 노출 — 사용자는 시험 연도만 원함
5. 자료에 없는 약어·지식 삽입(예: 'ITP')
6. 그림 확대창 버튼이 흰 바탕에 흰 글씨로 안 보임 — UI 색 대비 확인
7. JB 파일 형식 오해(처음 지침에 ZIP이라 잘못 적었음 → 실제는 PDF, `tools/jbx.py`로 해결)

## 7-1. 화면 디자인 원칙 (2026-09-25 사용자 지적으로 확정 — "가독성 떨어짐·색 눈아픔·규칙 없는 나열")
- 색은 세 가지만: 빨강({r:} 핵심어·수치), 형광 밑줄(==시험 문장==), 굵게(**용어**). 블록은 배경색 대신 **왼쪽 선 + 작은 라벨**로 구분(🔑 핵심만 옅은 바탕, ⚡ 암기만 옅은 초록). 과목 강조색(--acc) 하나로 통일
- 긴 줄은 구조로: 🔑 핵심·⭐ 시험포인트·💬 강조는 괄호 밖 ' / '에서 줄 나눔(각 조각 14자 이상일 때만), ①②③가 3개 이상이면 항목 목록으로. 항목(-)도 같은 규칙. ⚡ 암기 줄도 ' / '로 분리
- 한 카드에서 ⭐ 시험포인트가 여러 개면 한 블록의 목록으로 합침
- 본문 폭 최대 960px, 줄 간격 1.8, 소제목(#)은 과목색 + 밑줄, 항목은 작은 점
- 짧은 나열("1-1.5 times / 1/2-3/4 / 4-5 mm")은 나누지 않는다(조각 길이 기준)
- 아이패드 세로(≤860px): 사이드바는 ☰로 접고, 목차는 줄바꿈 허용
- (v6, 09-25 추가 지적: "보라 칸 글자 안 보임, 줄바꿈 안 된 곳, 줄간격 과도") → 그룹 제목은 채운 칸 대신 과목색 글자+밑줄, 줄간격 1.66, 블록 여백 축소
- 자동 구조화 우선순위: 번호(①·1.·A)) 3개 이상 → 번호 목록 / '라벨: 내용 / 라벨: 내용' 2개 이상 → 굵은 라벨 목록 / '앞머리: 긴 나열' → 굵은 앞머리 + 목록 / ' / '(조각 14자↑) → '; '(20자↑) → ' · '(22자↑, 110자 초과) → 문장(190자 초과) → '→' 5단계 이상은 번호 단계
- 분할이 형광(==)·빨강({r:})을 가로지르면 조각별로 짝을 맞춤(형광이 걸친 조각은 조각 전체 형광)
- 디자인 감사 스크립트 tools/audit_design.py: 전 페이지 명암 대비(3.0 미만)·230자 넘는 덩어리·가로 넘침을 찾음 — 빌드 후 매번 실행

## 7-2. 과목 홈 구성 (09-26 확정)
공부 순서 → 진행률 → 교수별 출제 경향(+📌 공부 전략) → **📣 교수님이 예고·강조한 것**(강의 원고 `!` 줄 중 시험·예고·강조·공개·keyword·별표·QUIZ가 들어간 줄을 모아 강의로 링크) → 강의 카드(읽음·기출 진행률·최근 해 짤/탈·힌트) → 2회 이상 출제 목록. 전임 교수 출제분(B)은 JB 카드에 '참고' 칩.

## 7-3. 대조 주석 자동 보완 (09-27)
annot.txt에 A/M/N이 없는 문항은 build4가 연결된 정리본 카드의 ⭐ 시험포인트 줄 + 카드 슬라이드 인용(최대 3장)을 '🔎 강의자료 대조'로 자동 채우고 v=ok로 둔다. 문항이 많은 과목(약물치료학 155)에서 쓰되, 근거가 강의자료 밖(논문·교과서)이거나 복원이 불확실하면 annot에 v=part/na를 직접 적는다.

## 7-4. 전면 개편(09-27, Claude Code)에서 굳힌 점검 기준
- 🔑 핵심은 짧은 한 줄(대략 120자 이내). 내용을 ' / '로 몰아넣지 않는다 — 풀어서 # 소제목 · - 항목 · | 표로(약물치료학·노인치과학 옛 원고의 반려 사유와 같음)
- 국문 부제에 출제연도를 나열하지 않는다(연도는 칩이 자동 표시). '(매년 출제)'처럼 사실과 다른 표현 금지
- ==형광==은 JB에 그대로 나온 문장에만. 시험에 안 나온 슬라이드 문장은 {r:} 빨강으로
- 문항마다 🔎 대조(A:)를 직접 쓴다 — 슬라이드 문장 인용 + 문장마다 [[키:쪽]] + 판정. 자동 채움(7-3)은 예외 처리용
- 연도는 문항이 실린 칸 + 문항 첫머리 괄호 + **다른 판본에 실린 같은 문제의 괄호**까지 합친다. 괄호 변형 '(2019, 탈)'·'(24. 23)'·'(21’, 20’, 17’이전)'도 읽는다 → tools/check_years.py로 전수 확인
- 자료에 없는 약어 금지 → tools/check_abbr.py로 걸러 쪽 이미지까지 확인(그림 속 글자는 허용)
- 여러 작업자가 쓰면: 강의별 작성 → 다른 작업자가 사실 40개 이상 대조·수정(이번 42개 강의에서 2,848개 확인·436건 수정)

## 8. 완료 전 자기검토 체크리스트 (하나라도 X면 고치고 다시)

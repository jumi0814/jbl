    1. 26년도 강의자료 및 JB 업데이트 — 최우선
    강의 정리본은 실제 변경 정도에 따라 차등 업데이트해줘. 모든 강의를 다시 작성하는 작업이 절대 아니야.
    
    * 동일 교수·경미한 PPT 변경: 기존 정리본의 반영 상태를 확인하고 실제 변경된 부분만 필요시 수정. 이미 잘 구성된 내용과 25·26년도 차이 표시는 유지하며 불필요한 전체 재작성은 하지 말 것.
    * 동일 교수·유사 강의지만 유의미한 변경: 기존 정리본을 유지하면서 추가·변경·삭제된 부분만 선별적으로 보완. 26년도 자료를 기준으로 삼고, 25년도에만 존재하지만 과거 JB 대비에 필요한 내용은 `26 자료에서 빠짐 · JB 짤 대비용`으로 명확히 구분.
    * 교수 변경 또는 강의 전면 개편: 26년도 강의자료를 기준으로 정리본을 새로 구성하고 무의미한 과거 내용이나 연도별 비교를 억지로 유지하지 말 것. 다만 교수만 변경되고 내용이 상당히 유사하다면 실제 개편 정도에 따라 불필요한 재작성을 피할 것.
    * 핵심 요약·암기 줄·정리표·비교표도 동일한 26년도 기준을 적용하되, 경미한 변경은 관련 부분만 갱신하고 실질적인 개편이 필요한 강의에서만 재구성.
    * 새 26년도 JB를 빠짐없이 통합하고 기존 JB의 원문·원래 답안·출제 이력은 보존. 관련 강의와 연결하면서 연도·교수·출제 형식 및 26년도 기준 답안과의 차이를 해설에서 구분.
    * 기존 JB 해설·참조가 오래된 25년도 정리본에 의존하거나 최신 자료와 충돌한다면 필요한 부분을 갱신. 과거 JB 원문은 임의로 변경하지 말 것.
    * 그림이 포함된 기존·신규 JB 문제는 해당 원본 그림도 문제에 직접 첨부해 별도로 JB PDF를 열지 않고 풀 수 있도록 개선. 그림의 번호·화살표·빈칸 등 출제에 필요한 정보를 보존.
    
    매우 중요: 정리본 수정과 예상문제 개선은 독립적으로 판단해줘.
    정리본은 변경된 만큼만 최소 수정하지만, 예상문제는 정리본을 수정하지 않는 강의까지 포함해 전체 강의를 대상으로 출제 적합성을 재평가해줘. 이미 완성도가 높은 정리본을 다시 작성하는 데 토큰을 낭비하지 말고, 실제 개편이 필요한 강의와 예상문제 품질 개선에 집중해줘.
    2. 교수별 출제 경향 기반 예상문제 전면 개선
    반드시 최신 26년도 강의자료와 JB를 먼저 반영한 뒤, 이를 토대로 교수별 출제 경향을 분석하고 기존 예상문제 전체를 개선해줘.
    
    * 교수별 JB의 실제 출제 형식(서술형·넘버링·단답·객관식·T/F·빈칸·그림), 완짤·짤·탈 및 변형 패턴, 답안 길이와 출제 방식을 분석.
    * PPT의 굵은 글씨·목록·표·그림·교수 강조 등이 실제 기출에서 어떻게 문제화되었는지 파악하여 교수의 출제 스타일에 맞게 예상문제를 구성.
    * 교수 변경 시 해당 강의의 현 교수 기출이 없더라도, 동일 과목의 다른 강의에서 해당 교수님이 출제한 JB를 적극 활용해 출제 형식·PPT 활용 방식·변형 경향 등을 파악하고, 새 강의자료에 맞는 예상문제에 적용. 과거 교수의 기출 내용과 현 교수의 출제 스타일은 구분할 것.
    * 강의당 문제 수나 유형 비율을 기계적으로 맞추지 말고, 실제 시험 대비 가치가 높은 고품질 문제만 선별. 기존 양질의 문제는 유지하고 중복·저품질·출제 경향에 맞지 않는 문제는 개선.
    * 예상문제별 출제 우선순위(상·중·하), 관련 JB, 간결한 출제 근거를 제공하되 근거가 약한 출제 가능성을 과장하지 말 것.
    * 그림이 필요한 일반 예상문제에는 관련 그림을 직접 첨부하고, 그림빵 출제 교수라면 최신 26년도 PPT에서 기출되지 않은 다른 그림까지 검토하여 새로운 그림 예상문제를 선별. 기출 그림의 무의미한 반복은 지양.
    
    교수 변경 관련 구체적인 사례 — 임상치과약물치료학
    다음 강의들은 교수님이 변경되었으므로, 제공된 26년도 강의자료가 있다면 1번의 업데이트 원칙에 따라 정리본을 갱신·재구성해줘.
    
    * 4차시: 우경미 교수님 → 김우진 교수님 (급성통증 치료제)
    * 5차시: 우경미 교수님 → 김우진 교수님 (만성통증 치료제)
    * 7차시: 조영단 교수님 (살균제와 소독제) → 김우진 교수님 (항불안제)
    
    이 강의들의 예상문제는 김우진 교수님이 같은 과목의 보톡스 강의 등에서 출제한 실제 JB를 분석하여 문제 형식과 출제 경향을 참고하고, 해당 강의의 26년도 내용에 맞게 구성해줘.
    특히 7차시 항불안제는 기존과 강의 주제 자체가 달라졌으며 다른 쿼터의 출제범위이므로, 이번 대화에 함께 첨부한 4큐 해당 족보도 참고해줘.
    이 원칙은 다른 과목의 교수 변경 사례에도 동일하게 적용하되, 교수별 기출이 부족할 때는 불확실성을 고려하고 실제 근거를 넘어선 추측은 하지 말 것.
    3. 예상문제 ↔ 넘버링 따기 연동
    
    * 예상문제를 넘버링 따기로 가져올 때 출제 우선순위·관련 JB·출제 근거를 확인하고 높은 우선순위 문제부터 간편하게 선별할 수 있도록 개선.
    * 기존 검색·필터 기능과 자연스럽게 통합하고, 태그는 짧고 직관적으로 표시하되 상세 근거는 필요할 때 확인하도록 구성. 문제보다 태그가 길어지지 않게 할 것.
    * 그림이 포함된 JB·예상문제를 가져올 때는 이미지도 함께 연결되어 문제 풀이와 복습에서 확인할 수 있도록 할 것.
    * 가져온 뒤에도 출처·우선순위 정보는 유지하되, 사용자가 수정한 문제·답안·넘버링 스토리와 복습 기록을 자동 갱신으로 덮어쓰지 말 것.
    * 문제 갱신으로 기존 넘버링과 학습 기록의 연결이 깨지지 않도록 처리.
    
    4. 교수별 그림빵 대비 기능
    
    * 실제 그림·빈칸 출제 이력이나 명확한 출제 근거가 있는 교수·강의에만 그림빵 기능을 제공. 필요 없는 강의에 별도 탭을 만들지 말 것.
    * 기출 그림빵: 원본 JB 그림과 실제 출제된 빈칸·번호·정답을 최대한 보존해 복습할 수 있도록 구성.
    * 예상 그림빵: 교수의 그림 출제 방식과 26년도 PPT를 분석해, 기출에 없던 다른 그림에서도 출제 가능성이 높은 문제를 선별. 기존 기출 그림을 기계적으로 재사용하지 말 것.
    * 그림 빈칸·번호를 가리고 개별/전체 정답을 확인하는 등 효율적인 복습 방식을 제공하고, 일반 빈칸빵에서도 필요한 그림을 활용할 수 있도록 할 것.
    * 강의 정리본·JB·예상문제·넘버링과 자연스럽게 연결하고, 유용하다면 그림빵 모아 풀기도 제공.
    * 기존 이미지 데이터와 처리 기능은 효율적으로 재사용하되, 예상문제의 출제 소재는 새로운 26년도 PPT 그림까지 확장해줘.
    * 과거 교수의 그림 기출과 현재 예상 그림을 구분하고, 26년도에서 빠진 그림은 과거 JB 대비용임을 명시.
    
    5. 저장 공간 및 기기 간 기록 이전 개선
    현재 localStorage가 약 4/5MB로 거의 가득 차며 공간 정리로도 해결되지 않는 문제가 있어.
    
    * 기존 저장·백업·복원 구조와 용량 점유 원인을 분석해 최소한의 안전한 수정으로 저장 공간을 효율화하고 용량 부족이 반복되지 않도록 개선.
    * 필요하면 기존 IndexedDB 등을 활용하되, 외부 서버 도입이나 불필요한 대규모 리팩터링은 지양.
    * 맥북·아이폰 간 기록 연동은 장기적으로 완전 자동화가 목표지만, 이번에는 기존 백업·복원 및 안전한 병합을 간편하게 개선하는 정도로 처리해도 돼. 복잡한 클라우드 시스템을 무리하게 구축하지 말 것.
    * 저장 구조 변경으로 기존 기록이나 백업·복원 기능이 손상되지 않도록 검증.
    
    6. 절대 조건 — 기존 사용자 학습 기록 보호
    사용자가 직접 작성·수정한 데이터는 어떤 업데이트에서도 소실되지 않아야 해.
    
    * 메모 최우선 보존: 기존 내용·서식을 유지하고 강의가 전면 개편되어도 삭제하지 말 것. 새 정리본에 연결되지 않는 메모도 별도로 확인·복구 가능하도록 보존.
    * 하이라이트·빈칸 표시: 카드 구조가 변경되더라도 동일 문구와 문맥이 남아 있으면 최대한 원래 위치에 복원. 위치를 확정할 수 없으면 잘못 연결하거나 삭제하지 말고 별도로 보존.
    * 기존 북마크·중요 표시·JB 채점·✓ 다 봄·넘버링 문제/답안/스토리·복습 이력·공부시간 등 사용자 기록 전부 보존.
    * 기록 보호를 위해 불필요한 25년도 내용을 억지로 유지하지 말 것. 콘텐츠 개선과 사용자 기록 보존은 분리해서 해결.
    * 데이터 이관·정리·삭제 전에 백업과 복구 수단을 확보하고, 변경 전후 데이터 무결성을 검증.

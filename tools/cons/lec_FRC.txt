## History · Concept of Post | 역사와 post의 개념 — 강화하지 않는다 | 3-6 | 개념
> 옛날엔 post가 치아를 강화한다고 믿었지만, 실제로는 강화하지 않고 어떤 치아는 약하게 만든다
= 과거 {r:Reinforce} → 현재 {r:Do not reinforce} · 어떤 치아는 {r:Weaken} / {n:현재 개념 = 코어의 유지}
# History — 나사 → 금 → 나무 → 금속+crown
- ① **Pierre Fauchard**({r:1728}): "Tenon"; {r:metal screw post} — {n:프랑스 외과의사이자 치과의사, 나사처럼 돌려 유지하는 post 개념을 처음 소개}.
- ② **Claude Mouton**({r:1746}): {r:Gold post}.
- ③ "Pivot crown"(mid-1800s): {r:Wooden post}.
- ④ "Richmond crown"({r:1879}): {r:Metal post + crown} — post와 crown이 하나로 연결.
- 최근에도 쓰는 것: Custom metal post + core → Prefabricated metal post → Non-metal post + core → **Fiber-Reinforced Composite (FRC) Post & Core**.
U: metal은 심미성이 떨어지고 파절 등 치아에 위해 → 금속이 아닌 FRC를 치아에 passive하게 위치시키고 접착으로 유지시키는 컨셉(필기).
F: 4=Fauchard의 tenon, 5=Post의 발전
# Concept of post — 강화 vs 코어 유지
- In the past: {r:Reinforce} endodontically treated teeth — {n:screw type metal post가 근관치료 치아를 강화해준다고 믿음}.
- However: {r:Do not reinforce} teeth / {r:Weaken} some teeth.
- 현재 개념: {n:코어를 유지하게 해주고 코어 부분과 치근을 이어주는 역할 → '치아 보강'보다 '코어의 유지'(필기)}.
- {n:screw type(active) metal post는 자체가 stiff해 apex 쪽에서 crack, fail이 나면 되돌릴 수 없음 → 잘못 식립하면 치아 수명을 줄임(필기)}.
- {n:Post는 근관치료 치아를 강화하는 장치가 아님 → 남아 있는 치질과 기능적 하중을 먼저 평가하고, 필요한 경우에만 core retention을 위해 사용(26 필기 p.3)}.

- ① ==Extensive loss of tooth structure== ({r:>1/2}) — {n:절반 이상의 치질 손상이 1차 적응증}.
- ② ==Consider amount of remaining coronal tooth structure & functional load on tooth== — {n:남은 양과 힘의 방향을 개별적으로(예: 기능 교두에서 남은 치질이 얼마 없는 경우)}.
- ③ ==Evaluation after tooth preparation== — {n:치아 삭제한 다음의 상황을 가정하거나 prep을 해놓고 평가}.

- 필기 기준 ②: {n:면(wall)을 4개로 봤을 때 2개보다 적으면 post 고려}.

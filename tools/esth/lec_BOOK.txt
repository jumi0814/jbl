# 길이를 정하는 기준
- 치아의 크기는 {r:안모와 조화}를 이루어야 함.
- 한 개의 전치 수복 = 인접치 또는 정중선을 기준으로 반대쪽 같은 위치의 치아와 비교 → 비교적 쉽게 크기와 형태 설정.
- 여러 개의 치아·정중선 기준 대칭 치아를 동시에 수복 = 기준이 없어 어려움 → 일반적으로 {r:윗입술과 절단연의 위치 관계}로 길이 결정.
- 교정 진단의 방법처럼 {r:안정위}에서 상순과 하순의 위치 = 전치의 길이를 결정하는 유용한 기준.
- 유년기: 상악 전치의 절단연이 상순선(upper lip line)보다 약 {r:2~3 mm} 길다 → 나이 증가 → 절단연 교모 → 상순선 아래로 보이는 양 감소.
- 상순선 아래로 보이는 양: 남성({r:1.91 mm})보다 여성({r:3.40 mm})이 많음.
- **미소선(smile line)** = 전치의 {r:치은측 경계}를 설정하는 기준.
- 중절치와 견치의 길이가 일반적으로 비슷 → 전치 길이 결정에 도움.

## Symmetry · Golden Proportion | 대칭성과 황금 비율 — 지나친 대칭은 작위적(교과서 p.134) | 6 | 기출 25 · 교과서 문장 그대로 | jb=P14
> 좌우 대칭·정중선 일치가 기본이지만 지나친 대칭은 작위적 — 황금분할은 절대 기준이 아니고 한국인에겐 그대로 못 쓴다
= 대칭성 = {r:균형(balance)}과 {r:조화(harmony)} · 지나친 대칭 → {r:작위적인 성형 감각} / 황금분할: 전면에서 인지되는 중절치:측절치:견치 폭 = {r:1.618 : 1 : 0.618} · {r:절대적인 기준 ✗}
# 대칭성
- 치아의 크기와 배열에서 대칭성 = 미적인 기준에 합치하는 {r:균형(balance)}과 {r:조화(harmony)}의 느낌.
- 인체는 좌우 대칭 → 치열의 {r:정중선}이 안모의 정중선과 일치해야 정렬된 가지런함.
- 개개 치아의 크기와 배열이 좌우 대칭 → 안모를 비롯한 전체적인 외모에서 균형이 잡힌 미적 충족감.
- 반면에 ==지나친 대칭성은 자연스러운 미적 충족감(자연미)보다는 작위적인 성형 감각을 강요하는 문제점==을 갖는다.
- 따라서 지나친 대칭성보다는 ==치아의 크기, 형태, 배열에서의 인위적인 변형을 자제하면서도 최소한의 균형과 조화를 얻을 수 있도록== 하여 편안한 안모를 구현 — 연습.
# 비율과 황금 분할
- 적절한 비율 = 아름다운 미소의 중요한 요소 → ① 개개의 치아 내 적절한 {r:길이와 폭의 비} ② 악궁 내에서 개개 치아가 차지하는 비율 ③ {r:입술과의 관계}도 고려.
- 유클리드의 황금분할 = 예술과 자연계에서 기하학적인 비율의 기준으로 인용.
- 치아에 적용: **실제 치아의 크기와 관계없이 전면에서 보았을 때 인지되는** 중절치:측절치:견치의 폭 비가 {r:1.618:1:0.618}일 경우 심미적으로 가장 균형 있는 폭의 비율로 인정.
- 그러나 ==황금분할의 개념은 모든 경우에 적용되는 절대적인 기준이 될 수는 없으며== — 개개인의 {r:개성} · 악궁 내 치아의 위치 · 안모와의 관계도 고려(그림 6-7).
- 한국인의 치열궁은 서구인의 치열궁보다 {r:넓음} → ==유클리드의 황금 분할비를 한국인의 치아 배열에 수정 없이 적용하기는 어렵다== → {r:측절치와 견치가 좀 더 보이게} 배열해야 얼굴형과 조화.

# Munsell
- {r:1905}년 Albert H Munsell — 모든 색을 {r:색상, 채도 및 명도의 3차원 요소}로 구분하여 수치화 → 기본적인 색 표현의 해석 방법으로 현재까지 사용(그림 6-15 Munsell의 입체 색표).

## Relationship among Colors — Visual Sensitivity · Adaptation · Contrast | 색상 간의 관계 — 시감도·순응·대비(교과서 p.139~141) | 11-13 | 개념 · 기출 25·24 보기
> 같은 색도 밝기·적응·배경에 따라 달리 보인다 — 오래 보면 회색이 되고, 어두운 배경 위에선 밝아진다
= 시감도 = 눈의 빛에 대한 느낌(최대 {r:100}) · {r:purkinje} 현상 / 순응 = {r:명암 순응}(암순응이 느림)·{r:색순응}·{r:부분적인 순응}({r:5초} 이상 ✗) / 대비 = 동시 대비(명암·색·면적) · {r:연속 대비}(계시대비 — 부 잔상)
# 색은 물리적 차이만이 아니다
- 눈은 광원 빛과 물체에서 반사·투과해 오는 빛의 {r:스펙트럼 분포 차이}로 색을 느낌 — 그러나 색을 보는 사람의 {r:감정 상태}와 {r:연령의 변화} 등으로도 달라짐.
# (1) 시감도(Visual sensitivity)
- 눈으로 느낄 수 있는 빛의 파장 범위 = 380~780 nm — 그러나 같은 파장의 색일지라도 {r:항상 같은 밝기로 느끼지는 않는다}.
- 시감도 = 이와 같은 눈의 빛에 대한 느낌 · 가장 밝게 느끼는 경우 = 최대 시감도 {r:100} → 같은 에너지를 갖는 파장의 느낌의 비를 그래프로 = {r:비시감도 곡선}.
- 주위의 밝기에 따라 느끼는 색의 밝기가 달라짐 — 어두워질수록 그림의 {r:청색} 부분이 밝고 선명 · {r:붉은} 부분은 어둡게 = **purkinje 현상**.
# (2) 순응(Adaptation)
- 순응 = 생명체가 외부로부터의 자극에 대응하는 방법을 변화시켜 자극에 의한 영향을 완화.
| 순응 | 내용 | 치과에서 |
| ① **명암 순응** | 빛의 밝기에 대한 순응 = {r:동공의 크기} + {r:망막의 감광성} 조절 · 어두운 영화관 = 동공 확대 + 감광성 증가 → {r:암순응} · 밝은 곳 = 신속히 동공 축소·감광성 낮아짐 → {r:명순응} | 암순응은 명순응보다 {r:상당히 느린} 반응 |
| ② **색순응** | 세 원색에 대한 망막 시세포의 상대적인 감광도 비율이 순응광의 분광 특성에 따라 변함 → 광원의 에너지 분포가 바뀌면 물체 색이 달라 보임(형광등 방 → 전열등 방: 백색판이 {r:주황} → 잠시 후 다시 백색) | 색조 선택의 조명광 = 반드시 {r:스펙트럼 분포가 균등한} 빛 |
| ③ **부분적인 순응** | 눈의 초점 범위가 극히 좁음 → 국소 부위의 밝기에 순응(밝은 태양광 아래 어두운 구강도 시선을 집중하면 잘 보임) · 같은 색을 오래 보면 그 색에 순응 → 본래보다 {r:회색}을 띰 → 감광도가 부분적으로 낮아져 식별 능력 저하 | {r:5초} 이상 한 가지 색깔을 바라보지 않음 → {r:첫 번째 인상}을 중요하게 여겨 색 결정 |
# (3) 대비(Contrast)
- 대비 = 물체의 색이 배경의 {r:명도 및 색상}과의 대비에 의해 다르게 보이는 현상.
- 대비 효과 = ① 동시 대비(동시에 2개 이상의 색을 볼 때) ② 연속 대비(어떤 색을 보고 나서 다른 색을 볼 때) ③ 면적 대비(다른 배경에서 같은 색을 볼 때).
| 대비 | 내용 | 치과 예 |
| ① 명암 대비 | 물체의 밝기는 {r:어두운 배경}에서 더 밝게 · {r:밝은 배경}에서 더 어둡게 | 도재 전장관: 밝은 석고모형 위 = 어둡게 · 구강(어두운 배경) = 더 밝게 / 치은 색소 침착이 심해 어두움 → 실제보다 밝게 · 인접치 착색·변색 → 밝게 |
| ② 색 대비 | 색상·채도에도 동시에 생김 — 배경색에 망막이 순응 → 물체의 색에서 배경색의 {r:보색} 느낌 | — |
| ③ 면적 대비 | 면적의 차이로 느낌이 달라짐 — 면적이 {r:클수록 밝고 선명} · {r:좁을수록 어둡고 탁해} 보임 | 커튼·벽지의 작은 견본 / 색본(shade guide)보다 작은 치아 = 같은 색조라도 {r:흐리고 어둡게} |
| ④ 계시대비(연속 대비) | 어떤 색을 보고 나서 다른 색을 볼 때 · {r:잔상} 현상과 밀접(명암 순응·색 순응과 같은 원리) · {r:정 잔상}(positive afterimage) = 원래 감각과 같은 색 · 단시간 강한 자극 / {r:부 잔상}(negative afterimage) = 반대의 색(보색) · 보통 밝기를 오래 응시 후 더 밝은 면 | 치과에서는 {r:부 잔상}이 더 큰 의미 → 진료실에 화려한 색채의 것을 두지 않음 · 보색 잔상과 색이 혼합되는 것을 고려 |
- 명암 대비·색 대비·면적 대비 등의 동시 대비 → 수복 시 치아의 {r:입체감} 표현에 이용.

# 왜 어려운가
- 색은 환경과 조건에 따라 느낌이 다양하게 변함 → 육안 판정 때는 환경과 조건을 일정하게.
- 치과 색조 선택의 어려움: ① {r:배경색}을 조작할 수 없음 ② 자연치와 색본이 {r:같은 평면}에 놓일 수 없음 ③ {r:크기}도 다른 경우가 많음 ④ 자연치의 색조가 색본과 일치하지 않는 경우가 대부분(중간 정도의 색조·변색·착색 → 경험적으로 {r:근사치}) ⑤ 동일 회사의 색본 사이에도 색조의 차이(그림 6-16 Vita shade guide · Z-100 · F-2000 색본).

- ==육안을 통해 적합한 색을 선택하기 위해서는 맑은 날 북쪽 창에서 들어오는 자연광을 이용하는 것이 가장 바람직하며, 인공광을 사용할 때는 모든 파장 범위를 포함하는 균등한 백색광을 조명광으로 사용해야 한다.==
- 인공조명 = 표준 광과 비교한 광원의 색 재현 능력 = {r:color-rendering index(CRI)} 값 {r:90} 이상인 형광등(fluorescent day-light lamp).

# 진료실 환경
- 벽, 천장, 바닥 및 커튼의 색 = 광선의 흡수와 반사 정도에 따라 색조 선택에 영향 → 진료실 내장재로 {r:강한 색}이나 {r:반사가 심한 재질}은 적합하지 않음.
- 술자의 가운도 {r:색상이 강한} 것은 좋지 않음.
- 가장 좋음 = {r:중등도의 회색 배경} + 적절한 밝기의 자연광.

# 아말감에서 아말감 이후로
- {r:1826}년 프랑스의 **Taveau** — 처음으로 {r:Ag-Hg paste} 소개 → 아말감 = 많은 논란에도 사용상의 {r:편이성}·재료 자체의 {r:변연 폐쇄 능력} → 오늘날까지 보존 영역에서 가장 널리 사용.
- 1955년 Buonocore의 법랑질 산부식법 + 대중 매체·생활 수준 → 심미적 치료에 대한 관심 증가 → 아말감의 시대를 마감하고 심미적인 수복재료와 접착수복 술식의 {r:post-amalgam age} 문턱.
- 그러나 교합압이 강하게 작용하는 {r:구치부}에서 아말감을 대체할 심미 수복재료는 현재까지 {r:없다}.
- 아말감 대체재료(amalgam substitute) = 시술 과정이 복잡·시간이 많이 소요 → {r:비용 상승} + 물성의 장점과 단점 → 재료의 종류와 물성을 이해하고 {r:적응증}을 잘 선택하는 것이 필수(적절한 변연 적합도·마모저항성·수명).
# 평가 기준 — 표 6-1 USPHS rating system
- 임상 평가 기준: ① {r:CDA}(California Dental Association) criteria ② {r:Cvar & Ryge} criteria ③ {r:USPHS}(United States Public Health Service) criteria.
- 공통 평가 항목: ① contour(wear) ② marginal integrity ③ marginal discoloration ④ color match ⑤ recurrent caries.

| Color match | Matches tooth | Acceptable mismatch | Unacceptable mismatch |
| Marginal discoloration | No discoloration | Discoloration without axial penetration | Discoloration with axial penetration |
| Secondary caries | No caries present | — | Caries present |
| Anatomic form(wear) | Continuous | Slight discontinuity, clinically acceptable | Discontinuous, failure |
| Marginal adaptation | Closely adapted, no detectable margin | Detectable margin, clinically acceptable | Marginal crevice, clinical |

| Other failure | None | — | Present |
- 심미 수복재가 가져야 할 성질: 물리적 성질 = 경도 · 탄성계수 · {r:마모저항성} · 압축 또는 인장강도 · {r:열팽창 계수} · 열확산도 / 생물학적인 특성 = 낮은 {r:세포 독성}.

# 잔존 치질 · 교합력 · 우식 활성도
- 잔존 치질의 양과 형태 = 수복물의 유지 + 수복물과 치질의 {r:파절에 대한 저항 능력}을 결정 → 가능한 한 보존적인 수복 방법.
- 구치부: 아말감·복합레진 충전 = 가장 보존적 · 임상에서 성공적 / 와동의 폭이나 깊이가 과도 → 교두 보호를 위해 {r:온레이 또는 전장관}.
  - 기준: 와동의 협설측 폭이 {r:교두정 거리의 1/2 이상} · 와동의 깊이가 과도하게 깊음(와동저에서 교두정까지 지렛대 길이↑) → 잔존 치질 파절 방지.
- 전치부: 인접면의 작은 와동 = {r:산부식법만으로도} 복합레진 충전의 유지 및 저항 형태 / 순측 치질이 과도하게 손상 → {r:설측 치질의 유무}에 따라 복합레진이나 도재를 이용한 라미네이트 또는 전장관.
- 잔존 치질로 수복물을 정하기 전에 {r:교합력 평가}가 선행 — 과도한 교합력·이갈이 같은 기능이상(parafunction)·교합압을 분산할 잔존 치아 수 부족 → 치관 내 충전물보다 강하고 마모저항성이 큰 {r:주조금 수복물}.

# 4) 도재 라미네이트, 인레이 및 온레이

# 6) 도재 전장관 — 금속 도재관 vs 전부 도재관
| | 금속 도재관 | 전부 도재관 |
| 구조·장점 | 하부의 {r:주조관} + 그 위에 축조된 도재층 → 금속의 강도 + 도재의 심미성 → 심미적인 목적으로 {r:가장 널리} 사용 · 장기간의 자료가 축적 | 탁월한 {r:chameleon 효과} → 보다 자연스러운 전장관 |
| 한계 | 하부의 금속 색조를 차단하는 {r:불투명 도재} → 수복된 치아의 {r:투명도 상실} | 강도가 금속 도재관의 {r:1/3~1/4} 정도 → 전치부에는 충분 → 심미성이 중요한 {r:전치부}에 한정 · 구치부에서 파절이 많이 일어나 전치부에서 수명이 김 |
# 전부 도재관의 세라믹 — 제조 공정에 따라 5가지
| 종류 | 제조 | 특징 · 적용 |
| ① {r:Sintered porcelain} | powder-slurry · 내화모형 상에서 condensation(축성) + sintering(소성) · 산화물을 함유한 장석 도재가 glass network | 수축이 심하고 기포 → 강도 낮음 / {r:투명도 우수} → 전치부 1개 치아 도재 전장관·온레이·라미네이트 · 다른 core 위의 {r:veneer porcelain} |
| ② {r:Infiltrated ceramic} | 내화모형 상 slip casting(alumina · spinell · zirconia slurry) → 소결 → {r:glass infiltration}으로 코어 + 장석 도재 veneer · In-Ceram(Vita): alumina porcelain·leucite 40% 이상 · 1120℃ 10시간 · 1150℃ 4시간 | 과도한 수축 → 적합도 저하 · 제작 과정 어려움 · 기포 → 파절 저항성 낮음 / sintered보다 강도·파절 저항성 크게 증가 → 전치부 {r:3개 치아 계속 가공 의치}가 가능해진 최초의 도재 system / alumina core 불투명 → 심미성 낮음 → magnesium oxide를 넣은 {r:spinell}(전치부) |
| ③ {r:Castable ceramic} | fine glass ceramic(tetrasilicic fluormica crystal을 함유한 glass matrix) · lost wax technique으로 주조 → 가열 처리({r:ceramming}) | 1개 치아의 전장관에만 · 물성뿐 아니라 색조도 {r:stain}을 통해서만 표현 → 다른 종류의 도재에 비해 {r:심미성도 떨어짐} · Dicor — 지금은 거의 사용되지 않음 |
| ④ {r:Pressed glass ceramic} | lithium disilicate glass ingot을 가열 가압 성형 제조법(heat pressed injection molding)으로 주조(p.23) · Ivoclar사의 Empress system(leucite-reinforced ceramic 주성분 glass ingot · Lost-wax and heat pressed technique · Injection molding technique) | Empress: 강도·파절 저항성 개선 ✗ · {r:투명도 우수} → 전치부 1개 치아 전부 도재 전장관 중 {r:가장 심미성이 우수} / Empress II(lithium disilicate) → 전치부 3본 계속 가공 의치·구치부 1개 |
| ⑤ {r:Machinable ceramic} | CAD/CAM 장비에서 절삭(milling)하도록 엄정한 공정을 거친 {r:도재괴(ceramic block)} · 처음 Dicor·Vitablok → 지금은 zirconia가 대부분 | 장석 단색 block(Vitabloc Mark II — 라미네이트·인레이용) → Vita TriLuxe Bloc · core용 Procera AllCeram · Synthoceram(CICERO) · {r:Y-TZP}(Yttrium tetragonal zirconia polycrystalline — Cercon · Lava · In-Ceram YZ) |
- Zirconia block = 강도가 높아 절삭이 어려움 → 두 종류: ① presintered된 block을 milling ② sintering 시의 수축을 고려해 {r:20~25%} 크게 milling → sintering으로 크기를 모형에 맞춤.
  - 완전히 sintering한 제품(DC-Zirkon 등) = 이후 소성 시 수축 ✗ → 변연 적합도 우수 · 절삭이 어려워 미세한 균열 가능 / milling 후 sintering 제품(Cercon, Lava 등) = 수축 보상 → 적합도 문제 가능 · 절삭이 빠르고 물성 유지 쉬움 → 대부분 이 방법.
- Y-TZP core = 독특한 {r:transformation toughening mechanism} → 인장력에 높은 굴곡강도·파절 저항성 → {r:구치부 계속 가공 의치} / 투명도 낮음 → 전치부 색조 맞추기 어려움 · 시간이 지나면 변연변색·적합도 문제.
# 고르는 법
- 모든 경우에 맞는 도재는 없음 → 적응증 고려 · 일반적으로 {r:강한 도재는 불투명}하며 심미성이 떨어짐.
- 심미성이 요구되는 곳 = {r:Empress} 같은 투명한 도재 / 교합압이 크게 작용하는 구치부 = {r:zirconia}.
- 파절 방지·수명 = 충분한 도재 두께가 확보되도록 적응증 선택 + 접착 시스템·레진 시멘트 · zirconia와 veneer ceramic 사이의 파절은 여전히 숙제 · 금속 도재 전장관 수명에 버금가는 전부 도재 전장관의 임상 보고는 아직 없음 → 선택 시 {r:환자의 동의}.

# Diastema 증례(필기)
- diastema가 있는 경우 치아 각각의 폭이 넓어질 수밖에 없음을 {r:환자에게 주지}시켜야 함 → 진단 왁스업해서 보여 주고 special effect를 적용해 볼 수 있음.
- 전장관·라미네이트 비니어라면 목업 상태로 환자에게 장착시키고 {r:1-2주 한달} 정도 지내 보게 하는 게 중요.
- 이 증례는 직접 충전이라 목업은 못 함 — 직접수복은 충전하고 shade 차이를 두거나 line angle 위치를 조정하는 수밖에 없음.
- #21 distal line angle을 보통보다 상당히 {r:distal} 쪽으로 위치시킴 — 넓어진 걸 상쇄시킬 수 있도록.
  - ⚠ 필기 방향 판단 불가(p.23): 원문대로 distal line angle을 더 distal로 옮긴다는 뜻일 수도, p.13 필기("line angle 위치를 안으로 모아 주면" 좁아 보임)·위 표(#11 distal로 → 좁아 보이게)와 맞추면 방향이 반대로 받아 적힌 것일 수도 — 원문 기준으로 외우고 두 방향 모두 알아볼 것.
- #11 쪽 치아 사이 shade는 {r:어둡게} — 그래도 11번보다 더 넓어 보이는 건 어쩔 수 없음.

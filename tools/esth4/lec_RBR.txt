## Resin-bonded Restoration — Overview | 강의 개관 — 유지형 vs 접착형 | 1-2 | 도입 · 필기 개관
> 유지형(Retentive type) vs 접착형(Adhesive type = 레진 시멘트) — {n:진료실 cement는 다 retentive type · 이 강의는 레진 시멘트로 정말 bonding하는 porcelain laminate veneer 위주}
= 시멘트 2갈래: {r:Retentive type}(유지형) vs {r:Adhesive type}(접착형 — {r:레진 시멘트}만) / {n:Resin bonded restoration = resin cement로 bonding해서 버팀 · routine은 porcelain laminate veneer}
# 표지
- **Resin-bonded restoration** — In-Sung Yeo · Professor · Seoul National University.
# {n:유지형 — 진료실에서 쓰고 보는 cement}
- 진료실에서 쓰고 보는 cement는 다 retentive type → 삭제한 form의 resistance & retention form으로 버팀.
- cement는 실제로 접착능력이 있는 게 아니라 그 사이를 메워 치밀하게 해서 안 빠져나오도록 하는 것 — 치아나 수복물에 화학적으로 bonding을 하는 게 아님.
- Retentive type의 한계: ① prep을 많이 하니 치질의 양 많이 날라감 ② 술자의 능력에 많이 의존(technical sensitive).
  - 수련의 입장에서는 좋겠지만 보편적 가치로 보았을 때 술자 능력에 의존하는 것은 별로 → 밸런스를 맞춰야.
# {n:접착형 — Resin bonded restoration}
- resin bonded restoration = resin cement에 의해서 정말 bonding이 이루어지고, 그걸로 버티는 수복물.
- 술자 의존성 줄여보려고 만든 것 — 하지만 bonding technique이 어려워 어느 정도는 술자에 의존 · 더 쉽게 치료할 수 있는 방향으로 개발되는 중.
- 이걸 많이 했었는데 요즘에는 거의 안 함 → 실제로 routine하게 쓰는 것은 딱 하나 = porcelain laminate veneer.
- (프렙)형성된 치아는 resistance를 잘 갖는 형태여야 함 — restoration 자체가 가져야 할 명확한 형태가 탈락에 대한 안정성을 줌.
- 라미네이트는 resistance를 잘 갖는 형태를 갖기 어렵고 bonding agent에 의존하는 형태 → 이 강의엔 작년까지 배운 resistance를 얻는 과정 등이 포함되지 않음.
- 접착제 5가지(permanent cement 5가지 종류): Zinc phosphate cement · Zinc polycarboxylate cement · Gi cement · Rmgi cement · Composite Resin cement.
  - 이 중 retentive type이 아닌 접착형은 레진 시멘트밖에 없음 → 오늘은 본딩 중심으로 이야기.
# {n:Porcelain laminate veneer — 이 강의의 초점}
- 반상치(fluoride colorization?) 또는 형태가 왜소치인 경우 등 → 모양·색을 정상적·밝게(치료 개념 + 미용 개념).
- 꽤 만족도 높고 체어사이드에서 크게 어렵지 않음(쉬우면서 효율이 좋은 치료방법) — 하지만 technique sensitive → 원칙을 잘 안 지키면 fail · Bonding procedure에 신경 많이 써야 함.
# {n:Delivery — 치아·시멘트·수복물의 계면}
- 고정성 보철물 마지막 과정 = delivery → 치아와 수복물 사이에 Cement → 치아-시멘트-수복물 층 · 각각의 계면(수복물-시멘트 접착 · 치아-시멘트 접착).
- 시멘트와의 접착을 위해 수복물과 치아에 각각 전처리 과정이 필요.
- Cement-수복물 결합 기전에 따라 cement 2가지: ① Retentive type ② Adhesive type(Resin bonded restoration = 이 두 번째 Adhesive type cement 이야기).

## Adhesive Type Restoration — Types · Maryland Bridge | 접착형 수복의 종류와 Maryland bridge | 3-4 | 종류 4 · 기출 24·23(이재현) | jb=R01
> Adhesive type restoration 종류 4 — {n:resistance form 없이 접착으로만 유지 · Maryland bridge는 wing 접착이 잘 떨어져 사라지고 지금은 laminate veneer}
= 접착형 수복 종류: ① {r:Rochette bridge} ② {r:Maryland bridge} ③ {r:Cast mesh fixed partial denture} ④ {r:Virginia bridge} / {n:Maryland bridge = Resin bonded metal restoration의 informal한 이름}
# 종류
- **Adhesive type restoration**: ① {r:Rochette bridge} ② {r:Maryland bridge} ③ {r:Cast mesh fixed partial denture} ④ {r:Virginia bridge}.
- {n:Maryland bridge = 대학 이름을 따온 것 · Resin bonded metal restoration의 informal한 이름 · retentive type이 아닌 adhesive type}.
- {n:history는 교과서에 있고 Maryland를 크게 한 이유는 한때 이것이 유행했기 때문 · 교과서에 임상 사진}.
# {n:접착형의 특징}
- 여태까지 배운 것은 retentive type restoration · 오늘 다룰 것은 adhesive type restoration(접착제에 의존) — porcelain laminate veneer도 prep을 생각해 봐도 resistance form이 없고 cement로 유지.
- resistance form 없고 오로지 수복물과 치아 사이 접착에 의해서만 유지 → 전체 prep 후 씌우는 기존 방법보다 약할 것처럼 보임 → 접착을 섬세히(치아-보철 · 보철-metal 모두).
- 교합력이 너무 강한 곳에서는 사용 X(사진에서도 전치부) — 하악 전치는 교합력이 강하게 작용 안 함.
- Resin bonded restoration은 꽤 오래 전부터 시도 → 접착제의 성능이 좋지 않아 실패 → 점차 향상 → 오늘날 포세린 라미네이트의 예후·유지 기간 향상.
- Dentino-enamel junction — 오늘까지도 둘의 결합에 대한 명확한 원리를 알지 못함 · Adhesive type restoration을 잘 수행하면 DEJ 같은 특징 — 마치 enamel처럼 기능하는 보철물.
# {n:왜 이 modality를 쓰나 — 치질 보존}
- Retentive type의 고정성 보철 = bridge(nn-X-nn 형태) · Adhesive type의 고정성 보철 = laminate veneer.
- Vital tooth의 prep은 마취부터 시작 ↔ adhesive type은 마취 시행하지 않음(∵ Enamel상에서 삭제) → 치질 손상이 덜함 · 치질 보존에 유리.
- 하악 측절치 MD dimension 5~5.5mm — 양쪽 1mm씩 깎으면 3mm밖에 안 남음 → lingual srf만 에나멜상에서 살짝 벗겨서 붙임 → 절대적으로 본딩이 중요.
# {n:Enamel bonding — 수업 퀴즈}
- Resistance & Retentive form이 전혀 없으면 bonding agent에 의존 → 퀴즈) bonding agent는 enamel/dentin/pulp 중 어디에 잘 붙는 게 좋을까? → 정답 Enamel.
- prep이 끝났을 때 dentin 노출이 많으면 안 됨 → prep 양을 신경 · 상아질 접착제가 7세대까지 나왔어도 결론적으로 Enamel bonding이 훨씬 강력 · 특히 border line은 반드시 enamel bonding.
- 프렙을 전혀 안 하면 혀가 두껍게 느껴 환자가 답답해함 → 조금은 벗겨내야 함.
- 본딩은 두 곳(메탈-접착제 · 접착제-치아) → 치아 쪽 이상적인 결합력은 에나멜에서 나옴 = 에나멜상에서 프렙이 이루어져야 하는 이유.
# {n:Maryland bridge가 사라진 이유}
- 치아와 wing 사이 접착이 잘 떨어짐 → 안 떨어지게 retention form(groove 등)을 넣다 보니 덴틴 쪽으로 들어가고 프렙 양이 늘어 치질 보존 취지가 약해짐.
- 그럴 거면 retentive form 하는 게 낫겠다 · 임플란트도 하면서 사라짐 · base metal을 설측에 붙여 metal shade가 비쳐 보임 → esthetic 장점이 없음.
- 최근 지르코니아(코어 세라믹)에 본딩되는 chemical(10MDP 등)이 나오는 중 — 진짜 chemical bonding인지는 연구가 더 필요.
- 포세린 라미네이트는 미용목적으로 요즘 적극적으로 활용되고 있음.

## Tooth Preparation — Preparation Principle | 프렙의 5원칙 | 5 | 원칙 5 · 필기 '외워두세요'

# Preparation principle
- ① {r:Preservation of tooth material}(치질 보존 — {n:가장 신경쓰는 부분}) ② {r:Resistance and retention} ③ {r:Structural durability} ④ {r:Marginal integrity} ⑤ {r:Preservation of periodontium}.

# {n:luting vs micromechanical — 차이}
- 기계적으로 걸리느냐(micromechanical) · 메꿔서 마찰력을 키우느냐(luting)의 차이 — luting은 "micromechanical이랑은 좀 다름 · 그냥 잘 파고들어서 메꾼다".
  - luting: 마찰이 면적 때문에 커지는 건 아니지만 듬성듬성 있으면 잘 미끄러지기 쉽고, 파고들면 마찰이 좀 더 커진다고 이해.
- 학습부 번호 9 풀이 글: "non-adhesive luting은 시멘트가 흘러서 계면 사이사이를 채우는 것으로 micromechanical interlocking이 생긴다."
- Luting에서는 잘 흘러들어가는 것이 중요 → powder/liquid ratio를 잘 맞춰서 시멘트를 믹스.
# {n:retentive type vs adhesive type}
- 치과용 시멘트의 결합기전은 주로 물리적인 interlocking(레진 시멘트 제외) → retentive type에서는 위 두 개(luting · micromechanical)밖에 기댈 게 없음.
- 결국 chemical bonding(molecular adhesion)을 추구 — 기본적으로 위 두 가지 작동기전이 들어가고 거기에 추가해서 adhesion이 큰 역할 · Adhesive type은 chemical bonding이 핵심.
- Adhesive type에서는 retentive form의 부재로 화학적 결합이 필요 → 레진 본딩 = molecular adhesion(화학적 결합)이 주 · micromechanical bonding·nonadhesive luting도 다 하지만 micromechanical bonding은 resistance form이 아무것도 없어서 의존하는 것 · nonadhesive luting은 부가적인 것.
- chemical bonding이 완벽하지 않음 → 잘 prep된 form과 치질 최대 보존으로 enamel bonding을 이뤄야만 오래감 · dentin은 사실상 본딩이 일어나지 않는다고 봐도 됨 · 특히 laminate의 가장자리는 모두 enamel bonding.
- 라면을 잘근잘근 씹어 먹는 것처럼 약한 힘으로 계속 두드려 맞는 것에 저항해야 함 → prep을 잘 해야 함.

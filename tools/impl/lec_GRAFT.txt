## Bone — Composition · Cells · Metabolism | 뼈의 구성·세포·대사 | 3-6 | 복습
> 무기질 65-70% + 유기질 21-26% — 매일 0.7%씩, 142일이면 전부 새 뼈
= Mineral {r:65-70%}(calcium phosphate 85%, calcium carbonate 10%) · Organic {r:21-26%}(collagen 20%, BMP·TGF-β 극소량) · Water 8% / 세포: osteoblast(형성·광화·osteoclast의 helper) → osteocyte(갇힘) · osteoclast / 대사: 하루 {r:0.7%} 흡수·대체, 전체 turnover {r:142일}
- 뼈의 무기질은 균일한 HA가 아니라 다양한 염이 섞여 있고, 유기질은 collagen이 대부분이나 TGF-β·BMP 같은 성장인자도 극소량(세포 분화에 필요) → 인공 합성이 어려움. Dynamic(지속적 변화), 기능 = 지지 + 항상성(인산염·탄산염, pH, calcium reservoir).
- 세포: Osteoblast는 골기질 형성·광화·growth factor 분비 + 정상 골흡수에 관여하는 osteoclast의 helper. 골기질에 묻히면 osteocyte, 쉴 때는 lining cell. ==Osteoblast가 기능하려면 osteoclast가 먼저 old bone을 녹이는 과정이 선행== — remodeling 시 흡수가 먼저.
- 대사 질환: 폐경(estrogen↓), Albers-Schönberg(osteoclast 결함 → old bone이 안 없어져 woven bone으로 남아 취약), cancer, hyperparathyroidism, Paget, osteoporosis(BMP). 골다공증 약 복용 시 골괴사가 많아 분자생물학적 지식이 필요 — 외과 환자의 절반이 MRONJ 관련(과장). 대사가 멈춰 old bone이 남아 생기는 문제 = MRONJ.
M: 뼈 = mineral {r:65-70%} + organic {r:21-26%}(collagen 20%) / 하루 {r:0.7%}, {r:142일} turnover
M: remodeling = {r:osteoclast 흡수가 먼저} → osteoblast 형성

## Bone Structure · Modeling vs Remodeling | 거시·미시·분자 구조와 골개조 | 7-10 | 복습
> Sharpey's fiber 때문에 골막 박리가 어렵다 — modeling은 모양이 바뀌고 remodeling은 대체된다
= 거시: cortical {r:85%}(Haversian·Volkmann), cancellous, periosteum·endosteum, {r:Sharpey's fiber} / 미시: {r:woven}(미성숙·약함·불규칙) → {r:composite}(치환 중) → {r:lamellar}(성숙, 하루 {r:0.6-1 μm}) · bundle bone(발치 직후 잠시) / 분자: type I collagen + H2O + 저결정성 탄산 apatite Ca10(PO4)6(OH)2 / {r:Modeling}(성장 완료 후 크기·모양 변화, 흡수 선행 없음) vs {r:Remodeling}(Oc·Ob 합동, old bone 대체, 평생, 크기·모양 불변)
- 골막하 박리 시 Sharpey's fiber와 elastin fiber 때문에 저절로 박리되지 않고 출혈이 많음 → 조심(골 가까이 혈관이 많음).
- 분자: 판상 apatite가 자기조직화된 세라믹/고분자 나노복합체 — collagen이 유연성, apatite가 강도·경도. Ca가 다른 원소로 치환되면 결합력이 달라져 강도·경도가 변함 → 고결정성 합성 HA(고온 소결)는 자가골 성질을 얻지 못함 → 합성골이 자가골·동종골보다 좋을 수 없음.
- Bone stress: 지속적 역학 스트레스는 골 모양 변화에 관여, 압박 부위 음전하 → 조골세포 활성(torus).
M: 골막 박리가 어려운 이유 = {r:Sharpey's fiber} / 골 종류: {r:woven → composite → lamellar}(+ bundle)
M: {r:Modeling} = 모양 변화 / {r:Remodeling} = old bone {r:대체}, 모양 불변

## Healing after Bone Graft · Osseointegration | (자가)골이식 후 치유 기전 — Phase I·II | 11-13 | 원리
> 처음 3주는 이식재 안의 살아있는 세포가 뼈를 만든다 — 그래서 phase I은 자가골에만
= 시간표: 수시간 내 platelet의 {r:PDGF·TGF-β} → 1-2주 macrophage growth factor → 2-3주 {r:재혈관화} → 3-4개월 완전 유착 후 remodeling / {r:Phase I}(처음 3주: 이식재 내부 생존 세포에 의한 골형성 — {r:자가골만}) → {r:Phase II}(4-8주: 파골세포가 1단계 골을 흡수, BMP·IGF 유리 → lamellar bone)

M: Phase I(3주) = 이식재 내 {r:생존 세포}의 골형성 → {r:자가골만} / Phase II(4-8주) = 흡수 후 {r:BMP·IGF} → lamellar
M: 이식 직후 {r:PDGF·TGF-β}(platelet) → 2-3주 {r:재혈관화} → 3-4개월 유착

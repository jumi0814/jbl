# 거시 구조(슬라이드 16)
- Compact(cortical) bone = 뼈의 단단한 바깥층, 공간이 거의 없음 / Trabecular(spongy) bone = 내부, trabeculae 사이 red marrow-filled space. 뼈는 안(endosteum)과 밖(periosteum)이 막으로 둘러싸임.
- 필기: 하악은 compact bone이라 침윤마취만으로 부족한 경우가 많음 → 사랑니 발치는 block 마취.
# Mature bone — osteon(슬라이드 17~19, ★ "작년에 나왔으므로 올해도")
- Osteon(Haversian system): ==Haversian canal — central canal, vascular and nerve supply of the osteon== / concentric lamellae / canaliculi system(osteocyte process가 canal을 향해 방사상, osteocyte–혈관 물질 이동) / ==Between the osteons: remnants of previous concentric lamellae = interstitial lamellae==.
- {r:Volkmann canal}: Haversian canal에 {r:직각}으로 주행, 내측으로 periosteum에 도달. 하나의 osteon 안 canaliculi는 평행, 다른 osteon끼리는 평행하지 않음.
- Periosteum은 blood supply가 좋아 벗기면 안쪽 뼈가 흡수될 수 있음 → block graft가 많이 흡수되는 이유.

## Periosteum · Endosteum | 골막과 골내막 | 22-23 | 구조

= Periosteum = {r:outer fibrous} + {r:inner cellular}(osteoprogenitor → 자극 시 osteoblast), {r:Sharpey's fiber}가 골기질을 관통 / Endosteum = {r:단층} connective cell, osteoprogenitor → osteoblast·bone-lining cell / 기능 = ① 골조직 {r:영양} ② 수복·성장을 위한 {r:새 osteoblast 공급}

# 두 분류(슬라이드 29~30)
- **Lekholm & Zarb**: 1 = 거의 cortical / 2 = cortical + marrow가 어느 정도 촘촘 / 3 = cortical 얇은데 spongy가 촘촘 / 4 = cortical 매우 얇고 marrow 성김(골다공증·고령) → 초기 고정 어려움, immediate loading 피하고 1·2차 수술 나눠 충분한 치유기간.
- 무턱대고 1번이 좋은 게 아님 — cortical이 너무 두꺼우면(골수염 흔적 등 sclerosing) 드릴 저항·열 발생·marrow 부족으로 혈액 공급이 적어 remodeling 불량 → {r:2·3번이 가장 좋다}.
- **Misch**(무치악): D1 dense cortical(oak, 전방 하악) → D2 porous cortical + coarse trabecular(pine, 후방 하악·전방 상악) → D3 porous cortical + fine trabecular(balsa, 전방·후방 상악) → D4 fine trabecular(styrofoam, 후방 상악). CT Hounsfield unit으로도 평가. 숫자를 외울 필요는 없고 상대적 구분.
E: Q13 | 24년 탈 — Lekholm-Zarb Type 1은 적절(×), Type 3 적절(○). E: R14 | "골질이 불량하여 초기 고정력을 얻기 어려운 경우의 테크닉" → undersized drilling(명훈 예고 문항).
# 술식 조정(슬라이드 31~33)
- D4 같은 뼈: {r:underdrilling}(4.5 mm 임플란트에 3.8까지만) — 단단한 뼈에서 그렇게 하면 mounter가 부러지고 압축 압력으로 bone loss → cortical drill이나 4.3까지 드릴링. 뼈가 약하면 driver로 mounter를 뺄 때 fixture가 딸려 나올 수 있음 → 식립 전 mounter를 한 번 풀었다 조이기. Sinus elevation 후에도 underdrilling.
- D1처럼 된 이유: 부분적 osteosclerosis 또는 염증이 심해 sclerotic osteomyelitis처럼 된 것 — 발치해도 그대로, 혈액 공급 나쁘고 열 발생 → 미리 설명. D4는 임플란트가 marrow로 쑥 빠져 nerve 손상 가능.

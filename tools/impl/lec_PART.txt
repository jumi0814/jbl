## Implant System · Structure | 임플란트 시스템 3부분과 구조 | 2-3 | 용어
> 임플란트 – 지대주(transmucosal) – 상부 보철물 / bone-level vs tissue-level
= 3부분 = {r:임플란트}(옛 용어 fixture) · {r:지대주}(transmucosal area) · {r:상부 보철물}(suprastructure) / Bone-level = {r:external}(hex) 또는 {r:internal}(hex·octa) connection / Tissue-level = internal(넓게 보면)
- 옛날엔 fixture라 불렀으나 지금은 '임플란트'로. 지대주 = 중간 구조물(transmucosal), 위는 suprastructure.
- 예전엔 bone-level external의 대표가 Branemark, tissue-level이 Straumann — 지금은 모든 회사에서 다양하게 나와 그런 구분은 지나감. External = 바깥으로 볼록(hex), Internal = hex가 안쪽.

## Superstructure Connection — Screw · Cement · SCRP | 상부 보철물 연결 3방식 | 4-8 | 분류
> 나사로, 시멘트로, 둘 다(SCRP — 요즘 가장 많이 보는 것)
= ① {r:Screw-retained}: restoration–abutment 사이(전통적 {r:2-piece}: abutment screw + gold/prosthetic screw) 또는 restoration–implant 직접({r:1-piece = UCLA abutment}) ② {r:Cement-retained} ③ {r:SCRP}(screw- and cement-retained): 지대주는 나사, 상부 보철물은 지대주에 시멘트 → screw hole로 한 번에 체결·분리
| 방식 | 구조 | 비고 |
| Screw-retained (2-piece) | 지대주를 abutment screw로 임플란트에 → 상부 보철물을 지대주에 또 나사로 | 전통적, "나사에 나사" |
| Screw-retained (1-piece) | 지대주+상부 보철물이 하나, 임플란트에 나사 하나로 직접 | = ==UCLA abutment==(colloquially) |
| Cement-retained | 상부 구조물을 지대주에 시멘트로 | |
| {r:SCRP} | 지대주는 abutment screw, 상부 보철물은 시멘트로 붙인 뒤 screw hole로 한 번에 연결 — 결과는 screw-retained와 같은 꼴 | 쓰이는 지대주는 cement type과 동일, 요즘 가장 많이 봄 |

## Single-unit · Multi-unit · Full-arch | 단일·다수·전악 고정성 보철 | 9-12 | 계획
> 여러 개를 묶을 땐 평행이 문제 — 그래서 multi-unit abutment
= 고려 2 = {r:implant type}(bone/tissue level, ext/int) + {r:superstructure connection type} / Multi-unit: internal type을 평행하지 않게 심으면 한 덩어리가 안 들어감 → SCRP는 abutment만 체결 후 위에서 붙여 가능(단, 뺄 때 안 빠지기도) / 전악 = {r:implant-supported fixed prosthesis}(전치부·양 구치부 3 piece) vs {r:fixed hybrid prosthesis}(덴처 형태, 구멍으로 연결)
- Single은 대부분 문제없지만 multiple case에서 고려사항이 많아짐(3차원적으로 꼬이면 안 들어감).
- Multi-unit abutment(Glidewell): 보철물을 임플란트에 직접 붙이거나 multi-unit abutment에 연결 — 순면 screw access hole과 깊어서 보기 어려운 연결부를 피하고, straight/angled multi-unit abutment가 연결부 높이를 올림.

M: 전악 고정성 2: {r:implant-supported fixed}(3 piece) · {r:fixed hybrid}(덴처형)

## Impression — Pick-up vs Transfer · Scan Body ★ | 인상 — pick-up(open tray)·transfer(closed tray)·scan body (23·24 기출) | 14-18 | 기출 23·24 | jb=R11,Q08
> 인상체에 파묻혀 딸려 나오면 pick-up, 입에 남아 옮겨 끼우면 transfer, 디지털이면 scan body
= {r:Pick-up} impression coping = {r:open tray}(구멍 뚫린 개인 트레이, 인상체 떼기 전 나사를 풀어 코핑이 인상체에 딸려 나옴, complicated case) / {r:Transfer} = {r:closed tray}(코핑이 입에 남아 풀어서 인상체에 딸깍 끼움, simple case) / {r:Lab analog}로 모델에 임플란트 재현 / {r:Scan body} = 디지털 인상용, {r:hex/non-hex}, 메탈·PEEK
| | Pick-up (Open tray, direct) | Transfer (Closed tray, indirect) |
| 트레이 | 개인 트레이에 구멍 | 막힌 트레이 |
| 순서 | 코핑 장착·long screw → 인상 → 트레이 떼기 전 나사를 풀어 코핑이 인상체에 파묻혀 딸려 나옴 → analog 연결 → stone | 인상 → 코핑은 입에 남음 → 풀어서 인상체에 딸깍 끼움 |
| 주의 | 너무 세게 잠그면 인상체 내에서 돌아갈 수 있음 — 적당히 | 끼울 때 저항감이 있어 덜 끼우면 보철물이 높게 나옴(교수님 군 복무 시 두 번 재제작 일화) |
| 적응 | complicated case | simple case |
- Scan body(17~18): 디지털 임프레션용, hex/non-hex, 형태·재료 다양(메탈, PEEK 레진, 혼합) — 연결부까지 PEEK면 세게 돌릴 때 뭉개지며 계속 들어가는 느낌. 스캔바디 없이 한 번, 꽂고 한 번 떠서 정합 → 임플란트 위치를 디지털로 시뮬레이션.

E: Q08 | 23·24년 "(그림) 구강 스캔 시 fixture에 끼우는 장치" → Scan body.

## Abutments — Types | 어버트먼트의 종류 — 기성·custom·UCLA·temporary·multi-unit·convertible | 19-30 | 분류
> 이름은 회사마다 다르다 — 만드는 방식(기성/밀링/주조)과 쓰임으로 기억
= Abutment-level impression = {r:combi·dual abutment}(closed tray), hex/non-hex — {r:one-body}는 hex가 없음 / {r:Ready-made}(기성) · {r:Custom}(판봉 밀링, 아랫부분은 규격 호환) · {r:UCLA}(왁스업 → 주조: gold·NP cast) · {r:Temporary}(레진으로 기계적 유지, temp shell 리라이닝) · {r:Multi-unit}(연결부를 잇몸 레벨 위로 올려 prosthetic screw, 전용 outer driver) · {r:Convertible}(internal → external-like)
| 종류 | 요점 |
| Abutment-level impression | combi·dual abutment 위에서 closed tray. hex(정해진 위치)·non-hex(모든 각, multiple case에서 끼웠다 뺄 때 유리하나 체결이 어려워 비선호). {r:one-body}는 안에서 돌아야 하므로 hex가 없고 screw hole도 없어 흔들릴 때 찾기 어려움 → 두꺼운 보철물을 갈아야 |
| Ready-made(기성) | Osstem 기성 어버트먼트, one-body 형태도 있음(쓸 일은 없으나 한 번씩 나타남) |
| Cast(UCLA type) | gold cast / NP(비귀금속) cast — 왁스업 후 주조, PFM처럼 포세린 빌드업 |
| Custom | 판봉을 밀링, 아랫부분은 임플란트 규격 호환, 윗부분만 깎음 — 요즘 제일 많이 봄 |
| Temporary | 레진으로 채워 기계적 유지, temp shell 리라이닝으로 temp crown |
| Link(OneFit) | 체결부만 기성, 잇몸 통과 부위까지 보철물이 담당 — 유럽에서 많이 씀 |
| Multi-unit | multiple case에서 깊은 연결부를 잇몸 레벨 이상으로 올려 {r:prosthetic screw}로 연결, 전용 outer driver로 통째로 체결, 위에 crown·fixed hybrid |
| Screw-retained용 2-piece | 지대주는 outer driver로, abutment screw 안쪽 홈에 prosthetic screw가 잠김 — 복잡해 많이 안 하지만 multi-unit을 하려면 알아야 |
| Convertible | internal type을 심었는데 external처럼 쓰고 싶을 때 — outer driver로 체결, prosthetic screw로 보철 연결 |

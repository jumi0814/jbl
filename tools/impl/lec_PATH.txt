# Osteogenesis Imperfecta (OI, 골형성부전증)
- 원인 불명 — {r:osteogenesis가 잘 되지 않는 것} → 뼈가 약해지고 {r:뚝뚝 부러진다}.

- {r:dentinogenesis imperfecta}가 동반되는 경우가 많음, {r:blue sclera} — mineralized 조직 상태가 좋지 않다.

# Paget's Disease
- **Ugly Duchess** — bone metabolism에 문제가 생기는 것, 뼈가 곳곳에서 마구 변해 사람이 원숭이처럼 변한다.
- {r:osteoclast의 활성이 대단히 이상} → 좀 먹은 것같이 파고드는 부분이 많이 생김 → {r:bone remodelling 예측 불가}.
- 한쪽은 골조직이 파괴되어 나가고 다른 쪽은 형성되기 시작 → {r:reversal line}이 많이 보임.
- 본 형성과 분해가 비전형적이지만 결국 본 remodeling이 일어나기 때문에 임플란트 식립이 가능은 하다 — 그럼에도 식립한 케이스, challenging하지만 성공.

# JBL 과목 팩 제작 스펙 (구강악안면외과학1에서 확정)

## 폴더
- `parse_jb.py` JB(23·24·25판, `tools/jbx.py`로 `work/jb/OMS1_20xx/`에 푼 텍스트) → 문항 블록 분해 (경로·출력은 `tools/SPEC.md` 폴더 구조 참고)
- `assemble.py` 문항 정규화·연도 산출·주석 병합·이미지 준비 (annot.txt / tables.txt / pred.txt 읽음)
- `reflow.py` JB 원문 줄바꿈 정리(글자 불변 검증 포함)
- `emph.py` 빨간 핵심어·수치 강조 처리
- `lecparse.py` 강의 정리본 원고(lec_<키>.txt) 파서
- `trend.py` 짤/탈·형식·탈 성격·공부 전략 산출
- `build2.py` 문항 카드·기출 한눈표·기출 대장 렌더러
- `build4.py` 과목 팩 조립(정리본·비교표·예상·경향) + 허브·단일 파일판 출력  ← **실행 진입점**
- `shell.html` 허브 템플릿(도구·검색·백업·과목 홈 포함)
- `lec_*.txt` 강의별 정리본 원고, `annot.txt` 문항 주석, `tables.txt` 비교표, `pred.txt` 예상문제, `gists.py`(구버전 요지, 미사용)

## 한 과목 작업 순서
1. `python tools/jbx.py OMS1`로 JB 3판본 추출 → `parse_jb.py` 섹션 패턴을 그 과목에 맞게 수정 → `jb_blocks.json`
2. `assemble.py`의 `OTHER`(판본 간 중복 매핑)·`CROPS`(그림 문항 자르기)·`LECMAP`(강의 키)·tier 규칙 채우기
3. 강의자료: `pymupdf`로 쪽 텍스트·이미지(폭 1100px) 추출, `tesseract -l kor+eng` OCR → 정독
4. `annot.txt` 작성(문항마다 v= / yrs= / lec= / A: M: N: 줄, 출처 [[키:쪽]])
5. `lec_<키>.txt` 작성(아래 문법) — 카드마다 =, #, -, |, E:, P:, U:, F:, M:
6. `tables.txt`, `pred.txt` 작성 → `python3 build4.py` → 검증 출력 확인(연결 누락 0)
7. 헤드리스 브라우저(playwright)로 화면·도구 동작 확인

## lec_<키>.txt 문법
```
#LEC 키 | 제목 | 교수 | 연도 | 파일 설명 | 쪽수
! 머리말(자료 출처·강조 쪽)
@MAP 흐름 → 흐름 → 흐름
@G ① 분류 이름
## 영문 제목 | 국문 부제 | 쪽범위 | 태그 | jb=Q01,Q02
> 한 줄 요지
= 🔑 핵심 한 줄  ({r:빨강} ==형광== **굵게**)
# 소제목
- 항목 (① ② ③, 영어 뒤 한글 풀이)
| 표 머리 | ... |
| 행 | ... |
E: Q01,Q02 | ⭐ 시험포인트 — 몇 년에 어떻게, 함정
P: 💬 교수님 강조
U: ✍ 이해(필기 한 줄)
F: 19=캡션, 20=캡션, 21
M: ⚡ 암기 줄({r:} 포함)
```

## 지켜야 할 규칙
- 답·해설·정리본 내용은 강의자료와 JB에서만. 근거 없으면 "근거 없음". 자료에 없는 약어·사실 금지
- 출제연도 = 괄호 ∪ 문항이 실린 연도 칸 ∪ 다른 연도 칸의 같은 문제. 실리지 않은 해 금지
- JB 답안 글자 불변(줄바꿈만 정리). 그림 문항은 블록 단위로 잘라 잘리지 않게
- 그림 캡션은 필기에 설명이 있을 때만
- 강의자료 우선순위 26 > 25, 둘 다 없으면 사용자에게 요청

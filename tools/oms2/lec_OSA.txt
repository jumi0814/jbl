# 기전 도식 — Primary events → Physiological consequences → Clinical features
- **Primary events**: Sleep onset → {r:Apnea} → {r:↓O2, ↑CO2, ↓pH} → {r:Arousal from sleep} → Resumption of airflow → Return to sleep

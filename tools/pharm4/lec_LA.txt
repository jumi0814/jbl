- 아민(Amine) = **작용기**.
- A, {r:Ester type} = Procaine · B, {r:Amide type} = Lidocaine.
- {n:마취제는 크게 연결부의 차이로 에스터와 아마이드 타입으로 나뉨 · 지용성 고리는 벤젠 고리 형태 · 아민 그룹이 마취 효과를 나타내는 기능기}.

## Distribution of a LA during Nerve Block | 비이온형 RN vs 양이온형 RNH+ — 막 통과와 채널 결합 | 7 | 기전 · pKa
> 막은 비이온형(RN)이 지나고, 채널은 양이온형(RNH+)이 막는다 — 축삭 안(약간 산성)에서 다시 양이온형으로
= {r:RN}(비이온형) = 막 통과 → {r:발현 속도} / {r:RNH+}(양이온형) = Na+ 채널 결합 → {r:차단 강도·지속시간} / pKa 7.5~9.0 — pH↑ → 비이온형↑ · pH↓ → 양이온형↑
# RNH+ ⇌ RN + H+
- **RNH+(양이온형)** — Na+ 채널 결합 담당 → {r:차단 강도·지속시간} 결정(Cationic acid).
- **RN(비이온형)** — 막 통과 담당 → {r:발현 속도} 좌우(Nonionized base).
- 각 약물의 **pKa가 {r:7.5~9.0}** 정도로 설정되어 있어, pH가 높아지면 **비이온형이 증가**하고, pH가 낮아지면 **양이온형이 증가**.
- Henderson-Hasselbalch equation: Log Base/Acid = pH − pKa.
- For lidocaine (pKa = {r:7.8}) at tissue pH (7.4): Base/Acid = 0.4 → 약 {r:29 %} RN.
# 신경 안으로 — 막 통과 → 재양성화
- 비이온형 RN만이 지질성 신경초·슈반 세포 막을 관통해 축삭 내로 확산(Lipoid barriers (nerve sheath) → Nerve membrane).
- 축삭 내부는 약간 산성(pH ≈ {r:7.1}) → RN 일부가 다시 **RNH+로 재양성화**.
- {n:이온형태 = 실제 기능을 나타내지만 지질막 통과는 어려움 · 비이온형태 = 지질막을 쉽게 통과하지만 기능은 없음}.
- {n:마취제는 약한 base(pKa 7.5~9) · 리도카인은 pKa 약 7.8 → 생리적 pH 7.4에서 약 30% 정도가 비이온형}.
- {n:주사 뒤 비이온형으로 신경세포 막 통과 → 세포질 pH 7.0~7.1(상대적 산성)에서 다시 양이온 형태 → 마취 작용}.

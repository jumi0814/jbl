1. **Opacity vs Translucency 카드 · Q18 짧은 ⭐** — JB 답(3), 4))과 보기가 빠진 채 "(두 카드 뒤)"만 있던 것 → 보기 ST·TB·XL·OA·WE와 답 3), 4), 이 쪽 필기(XL = 투명한 쪽 enamel · opaque = dentin), 정답 근거 p.12를 적고 함정을 붙임. 근거 p.10·12, Q18.
2. **Opacity vs Translucency 카드** — 디스크 사진 필기 중 "가운데 두개 거의 안 보임 / 끝에 있는, 두번째 - 투명해서 잘 보임"이 빠져 있던 것 → 앞 줄과 합쳐 한 줄로(가운데 = Z350 Dentin·Body, 끝·두 번째 = Bulk-fill). p.10 아래 shade 시편 사진(A1·A2·B1…·WT·DT·CT·NT·CVT)도 한 줄 추가(캡션 필기 없음 표시). 근거 p.10.
3. **Special Enamel Shade 카드 · Q18 ⭐** — 따옴표 안의 JB 해설이 바꿔 쓴 말("이후 PPT 표에 보기의 모든 shade가 있어…")이었던 것 → JB 원문 그대로 인용하고 "25 자료 표에는 ST·TB가 없고 OA는 dentin 쪽 → 답 유지"로 결론을 분명히. 근거 p.12~15, JB 2025 6쪽.
4. **Composite Products & Shades 카드 구조** — 제품 표 3개(20줄)가 맨 앞이라 시험에 쓰는 '약자 읽기'와 'Q18 보기를 표에서 찾으면'·⭐가 카드 끝에 묻혀 있던 것 → 약자 읽기 → Q18 대조표·⭐ → 제품 표(참고)·그림 순으로 재배치(글자 변경 없음).

## 사용자 확인 필요 (4건)
1. **Q16 근거 자료 없음(v=none 유지)** — porcelain 5종(sintered·infiltrated·castable·pressed glass·machinable)의 응용범위·색조 재현 표는 24년도 자료 '241018(1)_이창하pf_심미수복재료 p.17'에만 있음. 25 자료·다른 ESTH 자료 전체에 castable·machinable 등이 한 번도 안 나옴(텍스트 검색 확인). 24년도 파일을 주시면 대조 가능.
2. **p.6 텍스트층의 숨은 ⭐** — p.6(흐름도) 쪽 왼쪽 위 바깥(y<0)에 화면에는 안 보이는 ⭐ 글자가 텍스트층에 있음(FUN 250912 p.19에도 같은 자리). 학습부가 강조 쪽 표시로 넣은 것인지 알 수 없어 원고에는 반영하지 않음.
3. **분홍 글씨의 뜻(p.6)** — 범례가 없음. 원고는 "lack of·poor·concern처럼 약점을 가리키는 말이 대부분"이라고 적어 둠(All-Ceramic의 'Long-term, fracture resistance'도 분홍). 해석이라 확인 필요(작성자 보고와 같음).
4. **Q18 XL 논란** — JB 답 3), 4) 유지(근거 p.12 목록). 다만 XL은 Premisa에서 'Enamel shade' 칸, 필기 "투명한 쪽 = enamel … xl (extra light)" → 'enamel 쪽 shade 전체'로 넓게 묻는다면 논란 가능. 카드에 함정으로 적어 둠.

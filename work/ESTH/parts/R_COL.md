## JB 답 ↔ 슬라이드 불일치
1. **R06(FUN 담당, 23년)**: JB 답은 "1) opalescence: 빛의 산란으로 나타나는 현상"을 틀린 설명으로 봄(근거 이창하 Fundamentals p.25) ↔ 이 강의 p.89 슬라이드 "Opalescence – Scattering of the shorter wavelengths of the visible spectrum of light (opal effect)". 안진수 자료로는 ①이 틀리지 않음 → FUN 작업자·검토자가 FUN 슬라이드 원문과 함께 확인 필요. (COL 원고에는 짧은 ⭐에 ⚠로만 적음)
2. **Q26 옛 판 답**: 23판 2021 칸 답 "Hue를 L로 표시하고, chroma를 a,b로 표시"는 강의와 다름(p.60: L = lightness, hue = 각도 h_ab, chroma = 거리 C*ab). 24판 같은 칸은 "Value를 L로 … Hue, Chroma를 a,b로" — 강의와 맞음.
3. **S14**: JB 답(22년판에서 바뀐 답)의 "산란 = 파동이나 입자선이 물체와 충돌하여 여러 방향으로 흩어지는 현상", "대기 중의 질소, 산소 분자"는 자료에 없음. 필기는 "공기 중 입자 가운데 나노보다 작은 입자가 있어서 산란". 핵심 기전(짧은 파장일수록 강한 산란 · 노을은 비스듬히 긴 경로)은 일치.
4. **T20**: JB 해설의 영어 정의(when two colors that are not actually the same … appear the same under certain lighting conditions)는 슬라이드에 없음(JB "참고: X"). 뜻은 p.70 필기와 같음.
5. **Q27**: JB 답이 두 교수 답 병기("Thickness, Saturation (이창하pf) Reflectance, Thickness (안진수pf)") — 안진수 쪽은 p.82-83 "Reflectance / Thickness" 슬라이드 제목 그대로. JB는 이창하 출제로 추정.

## 사용자 확인이 필요한 것 (필기 판독·해석)
1. p.21 공간적 대조 방향: 두 필기는 "초록 옆 노랑 = 약간 붉게 / 빨강 옆 노랑 = 약간 초록끼", 한 필기는 반대("좌측 푸르스름·우측 붉으스름") — 원고는 두 필기 쪽을 표에 쓰고 ✍에 차이를 적음.
2. p.57 필기 "현재는 4도 관찰자를 쓴다 (중요하진 않음)" — 슬라이드는 "1931 : 2-degree observer (1~4°) / 1964 : > 4 degrees". 필기를 그대로 인용만 함.
3. p.5 광중합기 파장: 필기마다 "450-470 nm 정도" vs "480~490nm" — 원고는 450-470을 본문, 480~490을 괄호.
4. p.47 필기 "지금은 100단계 원래는 10단계였다"(Munsell value? 슬라이드는 Value (0~10)) — 무엇을 말하는지 불분명해 원고에 넣지 않음.
5. p.51 필기에 "D65(형광등)"라는 표현이 있으나 슬라이드는 "D65 : surface color" — 원고는 "60년대 형광등이 개발되며 … D65가 새 표준"으로만 씀.
6. p.81 슬라이드 철자 'Trnasmittance' — 원고는 Transmittance로 쓰고 슬라이드 철자를 괄호로 표기.
7. p.70 tungsten 아래 공 색을 '자홍'으로 적은 것은 사진 묘사(슬라이드 글자 아님).
8. p.40 슬라이드에는 글자가 없고(노을 사진), 필기 일부는 상자에 가려 이미지에서는 안 보임 — 텍스트층 필기로 확인.

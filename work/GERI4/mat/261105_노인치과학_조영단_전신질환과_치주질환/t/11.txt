술후
치주질환의치료
GBR과 GTR의 차이점은? -> 대상이 다르다.
- GTR (guided tissue regeneration)은 치아가 있는 경우이고, PDL을 재생하는 것.
- 그렇지 않고 발치를 하고 나서 꺼져있는 부분에 임플란트를 하고 싶다 하면 GBR이라고 함. 
- PDL을 만들거냐 안 만들거냐의 차이.
스케일링만으로 불충분하면 flap을 열어서 flap surgery, GTR로 넘어가게됨.
잇몸을 열어서 하는 건 비수술적으로 해결이 안되는 부분들을 해결하고자 하는거고, 잇몸을 열면 명확하게 문제를 볼 수 있고 기구도 쉽게 도달한다.
잇몸을 열어서 보면 환상형으로 골이 녹아있고 
염증 조직이 많다. 여기다가 안에 있는 물질을 
깨끗하게 제거하고 bone material을 넣고 꼬
매주면 GTR이다.
도저히 잇몸치료만으로는 안되겠다 싶어서 치근을 노출시켜보니 뼈가 많이 녹아있다
우선 염증, 치석 등을 다 제거하고 골이식재를 넣어
주고 차폐막으로 덮어줘서 GBR을 시행해준다
그러면 옆의 영상처럼 골이 재생하게 된다
그렇다면 GBR과 GTR의 차이는 무엇일까?
GBR은 대상이 치아이다 -> 치아 주변에 골이식재와 차폐막을 넣어 치아 
주위 조직을 재생시켜주는 것
GTR은 대상이 치아가 아니고 임플란트 등을 위해 나중에 뼈를 이식할 공
간을 만들기 위함 등을 이유로 치아가 소실된 부위를 재생시키는 것
비수술적 치료만으로 해결 안되면 잇몸을 열어야 한다
GTR과 GBR은 기본적으로 guided regeneration이고 차폐막을 사용하는 것은 똑같다
뼈를 사용하는 것은 필수는 아니다 공간이 너무 많다 싶으면 뼈를 넣어주는 것
제일 핵심은 차폐막의 사용이다 
-> 막으로 osteoblast보다 이주 속도가 더 빠른 fibroblast를 막아주지 않으면 뼈가 차야할 공
간에 fibrblast가 차서 뼈가 차지 않는다
앞의 비수술적 치료로 했을 때 나으면 좋지만 이 과정은 tactile sense에 의존하여 치은연하치석을제거하는 것
아무래도 보이지 않는 치석을 감각에 의존해서 제거하는 것이다보니 다 제거가 안될 수 있음
염증으로 인해 뼈가 계속 녹으면 잇몸을 열고 확실히 긁어내줘야 할 것
플랩 열면 안의 치석 잘 보임-단점은 잇몸에 칼을 대는 순간 잇몸은 좀 내려갈 수밖에 없음
GBR후 좌측에서 우측으로 변화
뼈랑 치아 사이 검은 line(PDL) 생김
-이로부터 치아 주변 뼈가 생겨났고 GBR이 성공적으로 이루어졌다는 것을 알 수 있음

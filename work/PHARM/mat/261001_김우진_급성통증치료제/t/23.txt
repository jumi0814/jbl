통증관리약물: COX 억제(Inhibition of COXs)
▣프로스타글란딘의 역할 
말초: 조직손상→ 아라키돈산
유리→ COX-2에의한PGE 합성
→ 통각수용기활성화→ 말초
감작(일차통각과민)
중추(척수·CNS): IL-1β 등사이토
카인→ COX·NOS 상향조절, PG
E·NO 합성증가+ NMDA 활성
화·Ca²⁺ 유입→ 중추감작(이차
통각과민) → 신경·신경교재형성
→ 만성통증
※ PGE는 말초와 중추 모두에서 
작용함
- NSAIDs의 주요 타겟은 COX이고, 
 COX는 PG pathway의 주된 요소입니다. 
- 조직 손상 -> 면역세포 유입 
  -> 면역세포 신호로 arachidonic acid 분비 
  -> PGE 합성 -> 말초 감작 
- 급성 통증이 중추 감작으로 이행 
  -> COX, NOS 활성화 
  -> PGE, NO, SO 합성 증가 
  -> 만성 통증 
- "정리하자면 PG는 말초에서만 작용하는 게 
아니라 중추에서도 작용하며, COX의 조절은 
중추에서도 효과를 낼 수 있습니다."

[주석] - NSAIDs의 주요 타겟은 COX이고, COX는 PG pathway의 주된 요소입니다.- 조직 손상 -> 면역세포 유입  -> 면역세포 신호로 arachidonic acid 분비  -> PGE 합성 -> 말초 감작- 급성 통증이 중추 감작으로 이행  -> COX, NOS 활성화  -> PGE, NO, SO 합성 증가  -> 만성 통증- "정리하자면 PG는 말초에서만 작용하는 게 아니라 중추에서도 작용하며, COX의 조절은 중추에서도 효과를 낼 수 있습니다."

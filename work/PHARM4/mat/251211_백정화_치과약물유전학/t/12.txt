Characterization
Phenotype
Homozygous for two no-function alleles (e.g., CYP2C19*2/*2, or CYP2D6 *4/*5) 
or, in the case of CYP2C9 , a combination of two no function alleles and/or 
decreased function alleles (e.g., CYP2C9*2/*3)
Poor metabolizer (PM) 
(individuals with little to no enzyme function)
Combination of one normal function allele with a no function or decreased function 
allele (e.g., CYP2C19*1/*2, CYP2C9*1/*2) or the combination of two decreased 
function alleles (e.g., CYP2C9*2/*2, CYP2D6*4/*10)
Intermediate metabolizer (IM) (individuals with 
reduced enzyme function compared to normal 
metabolizers)
Two normal function alleles (e.g., CYP2C19*1/*1) or, for CYP2D6, combination of 
a normal function and a decreased function allele (e.g., CYP2D6*1/*41)
Normal (formerly called extensive) metabolizer 
(NM) (individuals with normal, fully functional 
enzyme function)
One normal function and one increased function allele (e.g., CYP2C19*1/*17)
Rapid metabolizer (RM) (individuals with 
increased enzyme function compared to normal 
metabolizers)
Two increased function alleles (e.g., CYP2C19*17/*17) or multiple (>2) copies of 
normal function alleles (CYP2D6*1/*2 x N)
Ultra-rapid metabolizer (UM) (individuals with 
increased enzyme function compared to rapid 
metabolizers)
